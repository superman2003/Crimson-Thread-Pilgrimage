# 撤除关卡陷阱：验证记录

`native/ch01-clear.jpg` 至 `ch06-clear.jpg` 及 `world-clear.jpg` 为 Godot 4.6.1 实际 GLCompatibility 场景截图。使用 Dummy 音频输出、独立用户目录；截图前等待 30 个物理帧并检查主角已进入镜头。入口截图不代表自然通关。

`validation/summary.json` 汇总最终原生套件、源文件指纹及静态检查。`validation/runtime-asset-dependencies.json` 记录实际选择的角色 manifest、攻击阶段、资源闭包和单列的动态模板。

原生检查验证六个章节与实际 World 入口没有陷阱实例、旧贴图或反弹面，并向已退役工厂和接触回调注入已知及未知类型，确认不能创建节点或扣血。原奖励存档、配装、普通攻击和前两章流程也参与回归。

归途结专项保留 9 项真实物理检查：永久地面可记录安全点，升降篮、可破坏地板、能力门和相位门不作为安全点。撤除地刺后，其旧位置的永久地面可正常记录；全量 CI 暴露的旧危险区断言已据此更新，并加入撤陷阱合同。

反向对照临时将旧工厂改为创建 Area2D：41 项静靴检查中 9 项按预期失败，退出 1，源文件随后按字节恢复。该失败是故障注入的预期结果，不是最终代码的运行失败。

静态闭包检查覆盖具体资源路径。带格式占位的动态路径另列，不能据此承诺任意动态组合都已加载。这里不提供六章自然通关或帧率基准的结论。

`validation/generated-geometry-baseline.json` 单列额外生成地图几何审计：父版本与当前版本同为 54 项恢复点问题，地形、恢复点和错误列表相同；完整 `test:generated-maps` 因此仍失败，结构及第一章生成路线检查通过。实际运行地图的几何审计在 `npm test` 中通过。

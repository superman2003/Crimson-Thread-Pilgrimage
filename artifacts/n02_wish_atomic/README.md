The production World wish callback now prepares counts, consumption, item reward, completion/acceptance flags, a fully read pending dialogue's derived flags and money, testimony-chain completion, wish-board claims/currency and the candidate Build in private containers. It builds one complete checkpoint through the same preparation helper used by ordinary World saves, then performs one write. Before that write, it does not call the mutating inventory or story helpers, apply Player stats, announce a reward, or alter live conversation indices. A failed prepare/write leaves live gameplay and original disk bytes unchanged; the UI shows a retry toast while preserving the original dialogue for retry. Only a successful write publishes the candidate, updates inventory categories and Build, applies derived capacities, and announces the reward. Repeated topics do not repay or write another checkpoint. Invalid zero, negative, fractional, nonnumeric or boolean offering counts are not sufficient possessions. Existing non-World reward behavior is retained.

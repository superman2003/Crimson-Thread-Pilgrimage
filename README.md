# Crimson Thread Pilgrimage / 绯线巡礼

以针、线与旧铜遗物探索失声世界的原创二维动作冒险。玩家穿过六个互联地区，取得永久探索能力，回访旧路，寻找证词和失名者，并用契印、线术与战具组成自己的打法。

本页整体整理于 **2026-10-15**，说明对应 **PR #67 的 `5cf7303` 开发代码**，承接 PR #65 的保存候选与文档基线。它是开发分支说明，不是 main 或正式发行版的发布公告。当前进度、使用指南和历史交付分开维护，完整目录见[文档导航](docs/README.md)。

## 启动源码工程

需要 **Godot 4.6.1 stable**、Git和Git LFS。工程使用 Compatibility 渲染器，设计视口1280×720。Python 3.10+用于验证和构建工具，Node.js 18+用于npm命令与旧浏览器原型。

```sh
git clone https://github.com/superman2003/Crimson-Thread-Pilgrimage.git
cd Crimson-Thread-Pilgrimage
git lfs install
git lfs pull --include='godot/assets/**'
godot --path godot --editor
```

先等待资源导入完成，再运行工程，或执行 `godot --path godot`。默认入口为 `godot/scenes/World.tscn`。要复现本文功能，请检出相应开发分支；默认克隆得到的main可能与本文基线不同。

`Main.tscn`、生成地图场景与 `--demo-config=...` 保留独立试玩路径，不等同World旅途。桌面候选ZIP的解压、启动、存档备份与问题反馈见[玩家指南](docs/RELEASE_PLAYER_GUIDE.md)；玩家运行独立包无需安装Godot。

## 探索、地图与回程

初期可从苔钟庭进入铸雨渠取得攀壁，再向盐白书库取得双线跃，回访苔钟庭的盐风封门与证词支路。此路线是已有回访闭环，不要求先清空所有敌人或逐区击败Boss。更多侧路与能力工房允许后续回访；六区完整自然带伤流程仍需验证。

六区各有指定售图NPC，当前每区底图20枚松脂碎钱。购买不等于补绘：途中发现记入笔记，安坐钟龛后补到已购地图；未购与未补绘的秘密不因此曝光。M先打开本区图，Tab切换统一世界坐标总览；滚轮缩放，左键拖动，复位使用地图界面控件。

区域图和世界图右键可在**已购且已补绘的房间**放置个人图钉，也可通过上方按钮标记当前位置。目标／留意／回访三种类型共用12个上限，图上编号与删除列表对应。图钉跨区及重启保存；失败时撤回本次图钉操作。未知嵌套密室不能借用外层房间的补绘状态。

首条苔钟庭↔铸雨渠排水钟管可实际往返和折返，但仍是独立内容块，出口执行整区装载；其他成对入口与交通也各有现有实现边界，不能称为六区完全共享物理空间。

## 构筑、补给与旅途记录

钟龛用于休息、补绘和调整配置。构筑页区分战具、战斗铭饰、行旅铭饰与绯线技能，按契印布局检查兼容、锁定与容量。途中只能切换已装备项，切换不恢复生命、绯线、次数或冷却；旧装备迁移后的休眠状态须在钟龛重新分配。

休息恢复生命与绯线，战具需要另看报价并确认补给。补给消耗松脂碎钱与对应可再生材料，资源不足可补当前负担得起的部分次数；永久技艺、饰品和剧情遗物不会当材料扣除。制作／补给保存失败会回滚该事务。

人物对话完整读完才提交相关进度，未领奖可按既有完成态重访。旅记只透露已遇线索；终局条件显示已知信息与尚未发现的线索数量。世界记录保存区域拾取、捷径、探索、Boss和钟龛，跨区保留当前状态，重启按记录恢复。升级前退出游戏并备份整个用户数据目录，位置与恢复说明见[玩家指南](docs/RELEASE_PLAYER_GUIDE.md)。

## 验证与已知限制

```sh
npm test
npm run test:campaign
python3 tools/run_godot_import.py --engine /absolute/path/to/godot --recovery-mode --log-dir /tmp/pilgrimage-import
python3 tools/run_godot_regressions.py --engine /absolute/path/to/godot --software-gl --log-dir /tmp/pilgrimage-regressions
```

软件GL回归需要Linux的Xvfb和Mesa。运行器逐套隔离存档，缺脚本、超时、非零退出、缺成功标记及引擎ERROR均失败，退出码0不能替代检查日志。[完整命令、分项选择与证据边界](docs/VALIDATION.md)。

图钉基线默认清单为99套；本地13套相关回归通过，新专项64项，独立重复并截两图时66项。它不是本地全99套通过，也不代替精确提交的远端结果；请查看[PR #67](https://github.com/superman2003/Crimson-Thread-Pilgrimage/pull/67)及其检查。历史报告中的41／58／80／98套均属于各自当时版本。

当前仍有ObjectDB退出警告待归因，保存JSON与盘写等同步成本未消除。旧生成地图严格检查曾记录54处恢复点嵌入平台的缺陷，属于另一套生成管线，不能拿活动六区检查通过替代。自然六区带伤通关、所有结局、陌生玩家、真实手柄、长时性能、混音和最终发布包验收继续待办。

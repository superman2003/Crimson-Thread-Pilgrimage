## 动作约束

- 两只固定长度的短足；大腿与膝部藏在布摆下，左右使用同一结构。
- 保留贴地跑跳、身体承重与起伏；支撑足锁在地面，摆动足绕回，不用拉长短足追地面。
- 躯干压低、腾起和倾斜表达重心，布尾与线头滞后表达速度。不可让身体全程平移或靠遮挡掩盖脚滑。
- 攻击用手臂和缝锥形成明确蓄力、出手与收势；钩索由胸口绯线延展，治疗缝合自己的裂口。
- 新身体要统一覆盖所有动作再切换默认外观，避免跑步是小偶、攻击又变回人形。独立验证武器、碰撞体、受击、下劈、壁滑与镜头的可读性。

# 主角整身待机与重击：原稿比例修正

本批接入 8 张完整身体待机画稿与 6 张重击画稿。选定源图是 `sources/idle.png`、`sources/attack_2_v5.png`；各自同名 `.txt` 保存实际生成提示词。其他版本只留作过程档案，不算新增运行时姿势。

用户指出中途改稿显矮、显胖。原因是我把躯干和腿压短，同时保留较大的头、肩和衣服宽度。`idle_v2`、`attack_2_v4` 等紧凑身形候选已撤出正式绑定；修正版重新以原站姿为身形依据，恢复原来的瘦长躯干与腿长。`requests.json` 逐项标明未选稿；它们不能作为后续身形参考。

`identity_reference.json` 记录原站姿与哈希。`calibration.json` 以原站姿 131 设计像素身高为参考，每个动作只用一个固定缩放系数；重击以最后一格自然站姿校准，避免把举起的剑算进身体高度。没有逐格拉长腿、挤压身体、肢体变形或生成插帧。

`audit_sources.py --check` 检查透明背景、实际切格和源图／提示词哈希。`tools/build_hero_motion_v9.py --check` 检查 14 张正式图片的解码像素、固定比例、足底注册与动画绑定。注册只裁切、统一缩放、清理孤立背景与整体平移。两只靴底实际像素用于站位校准，不修改姿势。

正式待机使用 8 张整身画稿、5fps、1.6 秒循环，退出原来的固定身体与独立衣摆组合。重击为 6 张、15fps、标称 0.4 秒；实际前摇／有效／收招仍由原 0.48 秒控制器管理。详见 [报告](../../docs/report/20261105_hero_motion_v9.md)。

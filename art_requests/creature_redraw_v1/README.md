全部地面 `walk` 使用 #602 通用步态守卫：片段共同轮廓框下方 35% 的固定区域，相邻帧（含首尾）平均 1−IoU 至少 0.15，按未四舍五入的数值判定。`stride_pending.json` 仅暂缓固定的 11 个历史片段和对应原始 source SHA256，名单拒绝新增、改绑和重复，换用新原画不能继承旧豁免。重画通过后删除相应条目；局部攻击帧工具保留清单覆盖、共享原图比例与修复验收。`stride_reviewed: true` 保留明确复审步态的量测记录，前后动画及报告在 `artifacts/creature_redraw_batch11/`。

局部交付在 `target_frames` 中登记具体帧号，必须覆盖清单的全部标记帧；同一原图的所有片段共享统一注册比例，以冻结参考板全部对应原帧的中位身体面积为目标；完整片段体量误差保持 4% 以内。完整动作（含保留邻帧）参与跳帧检查，重测后 `--verify-repairs` 确认原先标记的尺寸异常已消除。`guides/` 冻结参考姿态、校正比例／支点和源图集指纹，可用 `tools/creature_redraw_guides.py --recipe ... --out ...` 重建参考图；参考校正仅帮助图像模型绘制，最终原画来自 image_gen。

全部新姿势来自内置 image_gen；`sources/` 保留选中的原始透明 PNG 和
实际提示词，`jobs/` 记录原图、提示词及输入参考的 SHA256。
首版待机因贴边拒收，仅保留缩略图和收据。

`tools/creature_redraw_art.py` 只裁切、统一整张图的注册比例、打包图集。
整张图的比例按“身体面积”定：重画片段的中位身体面积与被替换的原片段一致（误差 4% 以内，否则拒绝打包）。
不按高度定——同样高度下翅膀、披风、武器画得更宽，角色就会比没重画的攻击、受击动作大一圈，切换动作时忽大忽小。
`jobs/` 里的 `reference_height` 只作出图时的参考记录，不再决定比例。
地面角色固定落脚，悬浮角色按原画的格内坐标注册以保留绘制的垂直运动和翼部变化；
不会生成姿势，不会逐帧调大小，不会复制或混合端点来补帧。
每格边缘须真实透明，防止低于轮廓阈值的半透明雾状背景混入。铃光虫首版背景、
蜡蜂及延迟之影首版面积漂移、召唤纸页首版越出画布均拒收重画，收据保留。
每个片段保留原帧数、帧率、循环规则，运行画布、节点比例和偏移不变。
`motion_redraw_manifest.json` 继承完整生产图层，仅替换明确登记的片段；
旧原画及 v7/v8 可重复构建输入保留。

重建与复核：

```sh
python tools/creature_redraw_art.py --kind rust_crown_guardian
python tools/creature_redraw_art.py --all --check
python tools/build_creature_frame_fit.py --only rust_crown_guardian
python tools/build_creature_frame_fit.py --check
python tools/audit_motion_scale_consistency.py
```

# 小怪技能与预警素材审计

2026-10-23，基于 `ea33475c` 的六章实际运行配置、`original_creature_combat.json`、攻击效果绘制器和 v1 源图对照核对。结构化逐招结果在 [audit.json](audit.json)。这里描述补绘前的缺口，源图交付和运行时接入结果另行登记。

六章实际放置 **40 种普通敌人、85 个出生点**，其中 10 个出生点启用 `elite: true`。每种 2 招基础攻击，另有 10 招精英攻击，合计 **90 个不同攻击 ID**。40 种及 10 招精英均有真实出生点，没有把仅登记、未启用的角色算进完成范围。`enemy_actor.configure` 合并原始种族战斗档案，再接受出生点 `encounter_profile` 覆写；当前覆写只调整既有攻击 ID 的节奏、数量或距离，不增加其他招式。

## 逐类缺口

- **90 招的随身前摇材质均缺失**：现有 `_spawn_windup_vfx`／`_original_attack_arc` 仍绘制通用线条、刀弧、箭头或类型标记。人物自身有动作帧不代表外层技能素材已齐。
- **40 招近战与移动技能缺少生效材质**：10 招 `melee`、12 招 `lunge`、5 招 `dive`、2 招 `guard`、5 招 `combo`、4 招 `vault`、1 招 `feint`、1 招 `retreat`。完整 ID、名字和尺寸参数逐项写入 JSON；生效不能复用预警的静止轮廓。
- **50 招远程／范围技能已有 v1 源图与运行图集**，无需重画弹体、陷阱、地波、根刺和光束。这个数字包含 2 招 `blink` 的发射刃，因此与“额外缺失闪移表现”的数量重叠，不能相加成 92 招。
- **2 招闪移还缺局部离开／到达表现**：`censor_blink` 和 `shadow_blink` 的弹体可复用 `FX_P_blade`，但人物闪移仍没有独立裂隙／残影材质。
- **19 招有单独的地面或通道预警缺口**：10 招 `pool`、6 招 `rootline`、3 招 `beam`。应在每个实际落点、根刺延迟点或遮挡裁短后的光束通道绘制材质；随身蓄势不能代替这些位置预警。

## 容易漏掉的额外技能

- `wax_charge` 的 `trail: true` 在生效期间每约 0.16 秒留下一个危险池，前摇 0.35 秒，生效 1.1 秒，默认半径 11。它没有 `wax_lancer` 地面家族映射，仍回退为代码圆圈；需要熔蜡地面预警与生效材质，不能只给冲枪本体画一条轨迹。
- `pipe_mortar` 的管弹撞地后转换为铁渣池，重新经历 0.55 秒预警，总寿命 1.4 秒、半径 32。铁渣生效已有 `FX_A_slag`，但转换后的预警也须补素材。
- `ash_banner_imp` 有攻击表之外的治疗支援：0.9 秒引导，260 像素支援半径，成功为受伤同伴恢复 1 HP。当前仅以 `Line2D` 连向同伴，成功没有独立材质反馈；需要引导／连接与完成素材。不能在引导未结束、被打断或目标失效时显示治疗成功。
- `summoned_page` 是 CH03 E08 正常放置的敌人，未发现由其他敌人运行时召唤它的技能；不要因内部名称虚增召唤特效需求。

## 映射错误

`shadow_blink` 在 v1 明确归入 `P_blade`，但 `projectile_art.gd` 没有 `delayed_shadow` 的 `thorn → blade` 兼容映射，实际取到通用绿刺；需要修正映射而非重复生成已有影刃。`phase_censor` 的同类映射已正确。`wax_lancer` 的缺失地面家族属于真正的新材质缺口。

## 参考与额外边界

每个种族参考列在 JSON 的 `reference`，对应 `art_requests/creature_attacks_v1/refs/<kind>.png`；备用生产人物清单在 `runtime_manifest`，材质文字参照 `original_creature_designs.json` 的 `concept`。参考只约束主题和颜色，独立特效不应包含人物或完整武器。出图前需确保 PNG 已从 Git LFS 还原，不能把 131 字节指针作为图片参考。

`world_routes.json` 另有无伤害的战具练习傀儡，2 个不同 ID `practice_shove`／`practice_beam`，3 处使用点，均非这 40 种敌人的攻击。JSON 的附录单独登记；练习光束也缺材质映射，可复用合适的已绘素材，不能把练习对象算进“90 招小怪”统计。

普通接触伤害不是带前摇的主动技能，不为持续身体接触伪造技能范围预警。格挡成功通用可访问性标识、人物受击及死亡表现与本次主动技能缺口分开核对。

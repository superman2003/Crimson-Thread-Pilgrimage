## 来源、透明度和切帧

风格参考为 refs/00_style_run_v4_8frames.png，是仓库 generated_hero_motion_v4/run_sheet.png 的原样副本。人物沿用黑马尾、红围巾、青色破边披风、深色衣裤、棕靴和金色剑柄短剑。

每张 PNG 保留选定 image_gen 输出的原始字节。没有通过重复旧帧、像素变形、插值或混合端点来合成新动作。图像空白区使用实际 alpha 通道；alpha=0 位置的隐藏 RGB 可能带有颜色，不参与正常透明合成。以 alpha 轮廓核查切帧，不应仅根据忽略透明度的 RGB 预览判断。

**必须使用 generation_manifest.json 的 regions，不要把全部图片直接等分。** 每个 region 是 [x,y,width,height] 原图像素坐标，按先行后列读取。下落循环分界为 x=930；地面前攻的下排分界为 x=570、1030；地面轻下劈的下排分界为 x=545、1024。下攻→上攻过渡的右列上下分界为 y=490。它们避开完整剑尖和相邻披风。每格另附 alpha≥128 轮廓、留白和 RGBA 哈希。PNG、提示词哈希及替换历史保留在同一清单。

## 审查状态和接入边界

A 已再次重画，但仍是候选素材，**尚未通过“与两个原端点构成准确中间形状”的艺术验收**。源图集编号从 0 开始，4 列 2 行；接入时必须在相同领口锚点和比例下连播原端点与新帧。不能仅因生成了三张相似披风就认定过渡合格。

D 两组围绕同组固定腿部姿势重画，以布料变化形成循环；仍需按身体锚点注册对齐后检查细微漂移。源图不是逐像素锁定身体的分层动画。

本 PR 交付动作源素材、提示词与切帧清单；尚未修改运行时 SpriteFrames、动画状态机、方向选择或攻击判定，未运行游戏内播放测试。静态方向和完整切帧检查不等同于游戏内无抖动验收。B 和 C 重斩沿用已保留版本；C 剑波不烘焙独立飞行剑气，战具不烘焙独立飞瓶。

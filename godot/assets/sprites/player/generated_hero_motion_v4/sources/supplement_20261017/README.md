## 切帧与透明度

图片保留 image_gen 工具输出的原始 PNG 字节和 RGBA 通道。未用像素变形、插值或重复导出旧图制作新帧。空白区域有实际透明通道；低透明度抗锯齿边缘的范围可能大于 alpha≥128 的结构轮廓。

**切帧请使用 `generation_manifest.json` 的 `regions`，不要直接等分网格。** 按从左到右、从上到下读取，每个 region 使用 `[x, y, width, height]` 原图像素坐标。尤其下落图的两帧分界在 x=930，而非画布中线，避免切断第 1 帧剑尖。

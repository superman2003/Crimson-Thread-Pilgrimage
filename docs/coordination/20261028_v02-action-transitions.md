## 认领主题

**V02**：动作表达：契印针击、下击、疗伤、线术、战具与 NPC 交互的姿态接缝。

## 用户可见目标

为三契印及线术、战具、NPC 交互登记实际动作状态、接触锚点、命中/收势边界和取消规则。动作素材缺失时必须保留明确回退，不用复制帧冒充独特动作。

## 文件边界

后续实现应从最新 main（本次基线 $baseSha）创建独立分支，优先修改：动作选择与锚点注册、技能/交互播放、资源清单和独立动作回归。本说明不占用其他 agent 的实现分支；新的接续记录必须使用唯一 continuation 路径 $cont，不得覆盖既有记录。

实现 PR 需附基线 SHA、head SHA、独立非文档改动行数和路径交集检查。不能把修复旧 PR、继承改动、静态截图或仅文档行数计作新的台账升级。

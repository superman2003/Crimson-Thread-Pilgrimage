## 认领主题

**T04**：真实流程验收：新存档、伤害开启、两种探索顺序、三契印与缺资源边界。

## 用户可见目标

建立一套不依赖预置背包、静态图搜索或自动补给的真实流程记录：新档开启伤害、正常赚钱购图、两种探索顺序、三契印切换、缺材料、无定位和漏绘 NPC 等边界都要可复演。

## 文件边界

后续实现应从最新 main（本次基线 $baseSha）创建独立分支，优先修改：自然流程记录格式、种子/输入脚本、状态快照与验收报告模板。本说明不占用其他 agent 的实现分支；新的接续记录必须使用唯一 continuation 路径 $cont，不得覆盖既有记录。

## 避让范围

已有功能 PR 的局部回归与静态套件；本范围不替代玩法实现，只登记可复现的自然流程记录格式与证据边界

开工前必须重新读取所有 open PR 的当前 head、改动文件和 canonical ledger title；若同一主题或生产入口已被认领，则放弃本范围并选择下一个未认领候选。

## 验证要求

每条流程记录输入步骤、实际扣血/疗伤/死亡、钱包/物品/世界状态和重启恢复；显式夹具与自然流程分开。不能把单房回归、截图或旧 PR 继承结果当作完整通关。

实现 PR 需附基线 SHA、head SHA、独立非文档改动行数和路径交集检查。不能把修复旧 PR、继承改动、静态截图或仅文档行数计作新的台账升级。

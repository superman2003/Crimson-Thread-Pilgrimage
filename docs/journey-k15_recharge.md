# 绯线回充

累计观察到的绯线正增量；不会追补开启前的变化。

在设置中的旅途工作台打开本页，保存下次目标，点击开始后返回游戏。
观察只涉及开始后的实际快照；辅助历史最多四十条，按主档槽隔离。

- 菜单与过渡期间不累计；恢复时先建立新的观察基线。
- 超过半秒的观察间隔不会追补进度；跨地区位移与超过六百像素的单步不计里程。
- 倒下、切槽、损坏数据均不能产生成功记录；每次有效观察最多十分钟。
- 关闭页签不会取消练习；手动结束保存为取消，不会奖励或修改主档。
- 辅助写入失败保留待保存状态，五秒重试；导出遵守当前地区/原因与状态筛选。
- 本工具约十赫兹采样，不声称捕获两次观察间的全部伤害、动作或自然通关证据。

验证包含本项目实际 GDScript、独立用户数据中的写入/重载，以及原生控件构建。
此隔离测试不替代完整世界场景、GPU 和发布导出验证；既有 CI 保持有效。

本地运行：

```bash
python3 tools/run_observation_challenge.py --engine /path/to/godot --module k15_recharge --log-dir /tmp/k15_recharge
```

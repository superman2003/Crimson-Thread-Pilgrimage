# W02 第一批：苔钟庭五间房重构

> 文档状态校准（2026-10-15）：本文是第一章五间原房间重构的历史范围；下文“其它五区仍需”是当时状态。之后六区镜头和局部体验已有子项，重复结构与逐房用途／奖励闭环仍需深化，现状按[剩余总清单](REMAINING_UPGRADE_ROADMAP.md)核对。

本批承接 UI 改版，处理第一章审查中共用单平台轮廓的五间原房间。W02 仍为部分完成；其余原房间、能力工坊和其他五区需要继续逐间审查。

## 房间交付

| 房间 | 用途与灾变 | 可玩路线、遭遇与回报 |
| --- | --- | --- |
| 东庭露台 | 吊钟运输停摆，旧铜环连接检修支线 | 下层宽台与东侧单向观察台；盾卫移至东端并限制追击范围；西侧钩索工坊入口保留安全落脚 |
| 雨眺台 | 倾斜观雨拱，提示东面铸雨渠 | 下层继续通行，上层单跳眺望，落回原路；保留 NPC，不新增敌人或强制奖励 |
| 水窖深廊 | 沉钟基座保存织线者的纺锤 | 冲刺门后先落在西侧宽台；单跳取纺锤，再跳回西侧；没有新增强制落井 |
| 迷园歇脚 | 根须包围旧碑，苔灯仍供朝圣者休息 | 扩宽整备地面，西侧增加可登断石凳；原检查点位置不变，保留竖井和祭坛方向 |
| 殿前钟龛 | 三钟祈愿碑失声，门后仍有守母 | 下层地面与缓坡直通殿门，右侧可登观察台；原检查点和 Boss 门不变 |

各房间数据含 `design_card`，明确用途、灾变、实际落脚平台及敌人/奖励引用。地标复用项目现有手绘图集，增加显式图集变体与透明度选择，避免不同房间由随机哈希选到不合用途的装饰。装饰不参与碰撞。

碰撞是实际运行时数据变更：新增五个可站立台面，调整两处地面宽度，移动水窖纺锤，调整露台盾卫位置/巡逻/追击范围。洞穴实体只在这五间房的上方空气范围局部开凿，保留原有十条步行连接及实体升降笼；没有重放全区洞穴生成器。

## 验证

```sh
npm test
python3 tools/validate_world_routes.py
python3 tools/validate_world_upgrade.py
python3 tools/run_godot_regressions.py --engine /path/to/godot \
  --suite ch01_room_reconstruction --suite cave_route_walk \
  --suite cave_exploration --suite chapter_route_regression \
  --suite world_route_walk --suite world_map --suite inventory_map
```

Godot 4.6.1 实测：房间检查 63 项通过；六区洞穴步行 78 次双向穿行通过；六区洞穴探索 170 项、章节回归 270 项、世界路线 25 步、世界地图 19 项及背包地图回归通过。`npm test`、世界路线和升级数据校验通过。

新增 `ch01_room_reconstruction` 使用真实玩家、初始单跳和实际碰撞，检查五间房的双向下层行走、观察台与基座起跳、纺锤获得及返回、冲刺门阻挡、两个原检查点和钩索工坊的落脚。几何部分禁用敌人更新并抑制伤害；最后仅启用露台实际盾卫、开启玩家受伤，验证工坊回程落点停留四秒不受击。不会删除盾卫来制造安全入口。

回归中修复过的具体问题：新增台面的 `collision_role` 必须为 `one_way`；殿前地面延长会与旧缓坡形成台阶，已恢复原端点；露台观察台与盾卫出生净空相交会触发运行时位置修正，已将台面向东错开并验证实际出生位置。

实机截图见 [重构前后画廊](gallery/20261011_ch01_rooms.md)。截图来自 World 场景、隔离存档及真实渲染，展示房间构图；不是完整游玩录像。可用图形模式重拍当前五间房：

```sh
godot --path godot --script res://scripts/capture_ch01_rooms.gd -- \
  --capture-output=/absolute/output/directory
```

`--config-path=res://data/your_baseline.json --prefix=before` 可指定自行准备的旧版本章节数据。对比图使用本批父提交的第一章数据；世界叠加配置仍使用当前版本。

# 战斗、契印与治疗资源循环

承接工房第二组 PR #85。本批修改 Player、现有 HUD 和独立正式回归入口；不改世界路线、叙事数据、敌人攻击配置或存档格式。

## 可见行为与结算

HUD在契印状态下方显示实际治疗绑定、费用与当前阻塞原因：缺少多少绯线、生命已满、需要落地/停稳、动作中、冷却、等待复生或治疗剩余时间。提示与实际治疗动作共同读取 Player 的 `get_heal_readiness()`；反复查询不扣费、不建预留、不改冷却。治疗说明显示当前恢复量、准备时间与中断损失；打开地图等模态页时隐藏。状态行、进度条和追踪目标具有独立纵向位置，状态行加深色底提高洞穴背景上的可读性。

线势显示剩余时间；钟压保留层数；盐记按目标数显示，避免把目标数误写成有容量的层数。未修复机制显示明确状态。缝名的疾行和司铸的一次抗击退显示剩余效果时间。

治疗开始时先建立费用、开始时损失比例和计时预留，再扣费发信号，阻止扣费回调重入而重复开始。中断先清预留并设置冷却，再返还剩余费用；重复中断不能多次退款。切换构筑先按原配置、原能量上限结算旧预留，再应用新配置与容量。当前目录的中断损失比例仍为100%，没有增加免费治疗；25%损失的专项夹具覆盖配置变更边界。受击仍按原规则回充绯线，测试按这项原有收益计算受击后的余额。

## 三种契印

| 契印 | 专属机制 | 治疗完成后的目录规则 |
|---|---|---|
| 缝名 crimson | 修复后积累线势，下一技能消耗强化 | 按 `heal_move_duration`，当前2秒地面疾行 |
| 司铸 bell | 修复后精准防御积钟压，重击/震波消耗 | 按 `heal_knockback_duration`，当前3秒内一次抗击退；仍受伤 |
| 校录 salt | 修复后回声针施盐记，缚线消耗 | 按 `heal_mark_extension`，当前附近已有盐记延长2秒，每个标记至多一次 |

原运行时把前两种效果写死为2.5/4秒，与目录2/3秒不一致；现在读取实际构筑配置。独立旧夹具未提供字段时保留兼容默认值。三种专属机制统一核对 `mechanism_unlocked`，缝名同时保留原 `crimson_repaired` 条件；普通付费格挡与回声针伤害仍可用，缺失修复不能提前获得钟压或盐记。

## 验证与边界

新增 `combat_resource_cycle` 接入默认严格运行器与专项CI。实际Player普攻输入命中生产敌人，逐个检查回能，再实际治疗输入、延迟恢复、契印附加效果、强化一级的真实装备技能命中与独立扣费/冷却、拒绝重施放、受伤中断且不会延迟补血。另检查旧配置预留结算、扣费/退款信号重入、查询纯读、缺能量/移动/空中/冷却/满血拒绝，以及三种机制未修复的边界。

World HUD专项使用真实World、真实钟龛地面与Player，验证实际费用、缺口、生命/能量主表一致、治疗进度、效果窗口、未修复显示、改键以及地图遮罩。三张World截图来自预置契印的局部夹具，等待真实绘制后保存，供CI上传；不声称自然解锁证据。

测试对手使用生产enemy_actor与实际命中判定，但冻结AI及接触伤害以隔离资源结算；受伤中断另调用真实Player伤害入口，关闭调试无敌。强化等级和装备作为夹具预置；本批不替代自然材料获取/付费强化验证、六区带伤流程、Boss治疗窗口、人类手柄体验或最终难度平衡。

## PR #86 远端集成失败修复

首轮远端总集成执行了96个套件，只有 `world_host` 失败；`combat_resource_cycle` 为119项、0失败。失败日志来自 Actions run `38846511045`：治疗取消退款断言及后续42次跨区资源保留断言失败。

根因是旧的 `world_host_validation.gd` 手工治疗夹具只设置了计时、预留费用和当前构筑损失比例，没有设置新增的 `heal_reserved_loss_ratio`。默认100%损失导致20点预留不退款，余额维持58，而夹具期待按50%损失退款10点、余额68。运行时按治疗开始时的预留比例结算是预期行为。

夹具现补齐50%的预留比例，并将当前构筑比例改成100%，明确验证跨区取消仍按开始时比例结算。保留原有10点退款及42次资源保留断言，不放宽通过标准。战斗资源专项CI增加 `world_host` 套件及其脚本路径触发，覆盖本次漏测的兼容边界。

本次按用户要求未运行本地测试；修复后的运行结果以新提交触发的远端CI为准。PR上的Codex代码审查与安全审查另因用量上限/可用额度不足而未启动，不属于上述运行时断言失败。

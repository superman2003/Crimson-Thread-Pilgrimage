# 用户音量、静音与混音覆盖

基线：`main` / `03b4919c6fa0e755349d5b303c0f984f81ac64dc`。

四档音量归零时，现在设置对应 AudioServer 总线的真实 mute 状态；恢复正值会解除该状态，并保留原有对数增益和各总线基础电平。SFXDry 继续直接发送到 Master，避免濒死心跳吃章节混响，同时同步音效滑块的增益和静音，不再绕过音效设置。独立 UI 总线仍由总音量控制。

用户修改音量会中止该总线用旧值创建的对话/转场渐变；音乐还保留原有的拾取 duck 取消。当前对话开启时仍按新的滑块数值叠加原有对话压低量，因此旧 Tween 不会稍后把音量拉回。对话关闭或新的混音状态也不能解除用户的零音量静音。

运行时 setter 拒绝 NaN/无穷值，既不改变总线，也不改写配置；有限越界值继续限制在 0–100。配置格式和默认 `user://audio_settings.cfg` 路径不变。可注入 `settings_path` 用于隔离验证，重建音频导演时继续读取用户设置并应用静音。

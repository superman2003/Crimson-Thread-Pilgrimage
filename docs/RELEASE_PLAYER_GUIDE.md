# 绯线巡礼 · 玩家指南

这是开发中的互联世界银河恶魔城原型。本指南对应当前源码中的操作、地图、构筑与存档功能；如果使用候选下载包，请同时核对包内 `BUILD_MANIFEST.json` 的版本和检查范围。当前源码说明不代表所有旧包都包含新功能，也不代表已完成六区自然通关、全部结局、目标硬件与完整手柄体验验收。

## 启动与第一段旅途

完整解压候选包后，Windows 运行 `CrimsonThreadPilgrimage.exe`，Linux 运行 `./CrimsonThreadPilgrimage.x86_64`。Linux 若未保留执行权限，可先执行 `chmod +x CrimsonThreadPilgrimage.x86_64`。可执行文件与同名 `.pck` 必须放在一起；运行导出包不需要安装 Godot 或下载源码。

候选导出目标为 Windows/Linux x86_64，需要支持 Godot 4.6 Compatibility 渲染器的图形环境；Windows 包未签名。macOS、移动端和 Web 不在这份候选包说明范围内。

首次游玩可以先熟悉移动、攻击和治疗，沿路牌探索苔钟庭；在钟龛用 F 休息并记录归途，向本区地图 NPC 购买底图。能力与装备通过实际探索、遗物和对话获得；文档截图中的“SHOWCASE”授予档不是自然开局配置。

## 默认键鼠操作

下表是未重映射时的默认绑定。已经获得对应能力后才能使用；设置页与屏幕提示显示当前实际绑定。

| 操作 | 默认输入 |
| --- | --- |
| 移动；上下瞄准 | A/D 或左右方向键；W/S 或上下方向键 |
| 跳跃；冲刺 | 空格；Shift |
| 普通攻击 | J 或鼠标左键 |
| 治疗 | H 或鼠标右键 |
| 钩索 | K 或 X |
| 当前线技；切换已装线技 | L；C |
| 使用当前战具；切换已装战具 | T；G |
| 钟守 / 灯相穿越 / 王冠共鸣 | Q / E / R |
| 交谈、钟龛、门和其他交互 | F |
| 旅囊 | Tab 或 I |
| 地图；地图内切区域图/世界图 | M；Tab |
| 构筑；设置；关闭界面 | B；V；Esc |
| 新旅途确认 | F9 |

E 是探索能力“灯相穿越”，不是当前战斗线技的施放键。打开地图后右键用于自定义图钉，左键用于拖动；关闭地图后鼠标右键仍是治疗。

F9 会打开新旅途确认，不会免确认直接清档。开始新旅途、切换存档槽或更换游戏版本前，建议退出游戏并备份整个用户数据目录。

## 默认手柄与设置

按 Xbox 式按钮名称：左摇杆移动/瞄准，A 跳跃，B 冲刺，X 攻击，Y 施放线技；LB 治疗，RB 钩索，LT/RT 切换已装线技/战具。方向键左/右/上分别对应钟守、灯相穿越、王冠共鸣，方向键下使用战具。

左摇杆按压打开构筑，右摇杆按压打开地图，Start 打开旅囊，Back/View 交互。界面中使用方向键移动焦点，A 确认，B 返回。设备按钮印字可能不同，请以设置页和实际提示核对。

V 打开的设置可调整音量、字幕、闪光、震动及可重映射动作。B、Tab/I、M、V、F9 等界面入口和部分手柄菜单按钮保留给界面使用。地图当前用 Tab 切换区域/世界；图钉工具栏和缩放按钮提供可聚焦操作路径，完整无键盘手柄流程仍需实际设备验收。

## 地图：购图、探索与补绘

1. 靠近本区地图 NPC，用 F 打开购买/交谈选项。底图需要20枚松脂碎钱；已经购买后无需重复购买。
2. 探索房间会留下待补绘笔记。安坐钟龛后，途中笔记才成为已补绘的地图细节。
3. M 打开区域图，Tab 切换世界总览。滚轮或右上角 −/+ 缩放，左键拖动，复位按钮恢复完整视图。

底图可能显示公开房间轮廓，但这不代表细节已经补绘。秘密口袋和回访工房有独立知识记录；探索外层大厅不会自动揭示嵌套秘密房间。世界总览沿固定世界坐标显示六区位置，购图、补绘和缩放不会改变它们的相对布局。

自定义图钉有“目标、留意、回访”三类，最多保存12个：

- 在上方类型框选择一种，右键点击**已购且已补绘**的房间即可标记；世界总览也可在对应的已知房间放置。
- 键盘/手柄可聚焦“标记当前位置”，不必精准点击地图。未购、未绘、未知嵌套房间及地图外位置不能放置；附近重复点会被拒绝。
- 从上方图钉列表选择一项，再点“删除图钉”。地图符号和列表共用编号，例如“★1 / 目标1”，用于分辨同类或同房间标记。
- 图钉跨区保留并随存档恢复；区域图只显示本区，世界总览显示已知地区的标记。它们不会替你探索或补绘房间。
- 地图面板内会显示操作结果。保存失败时撤回这次图钉修改；暂停保存时不允许增删。损坏、越界或不符合地图知识的旧记录会被安全忽略，不占可用容量。

这里提供的是小容量地图注记，不包含自定义文字、楼层筛选、路线规划或自动寻路。

## 四类槽位与付费补给

B 打开“契印与构筑”。四类槽位分别是**战具、战斗饰件、行旅饰件、线技**，不是四个可以混装一切的通用槽。选择契印后，以界面显示的槽位解锁、兼容类型和容量为准；“铭饰”页可切换战斗饰件与行旅饰件。

在钟龛调整需要休息点的配置，制作/强化按提示寻找对应工匠。途中可以切换已经装入的线技或战具；切换不会恢复生命、绯线、战具次数或冷却。

切换契印或迁移旧存档后，某些原位置装备可能保留为“休眠”。锁定或不兼容的装备不生效，也不计入有效装备数量；回到钟龛可以重新分配到兼容位置。休眠不是免费补充次数或刷新冷却的方式。

安坐钟龛恢复生命与绯线，**战具次数需要另行付费补给**：

1. 在钟龛打开战具页，先“查看补给报价”。查看不会扣费。
2. 报价列出实际补充的次数、碎钱和所需材料，再决定是否确认。
3. 资源不足时，可以只购买当前能够负担的部分次数；具体补充项目以报价为准。

补给使用松脂碎钱和相应的可再生敌人材料，不把饰品、永久能力或剧情遗物当耗材。真实保存失败时，已进入交易流程的制作、补给等操作会撤回本次构筑和钱包变更；暂停保存时，交易入口会直接拒绝。确认提示、检查磁盘空间与目录权限后再重试，避免把失败当成已经购买。

## 归途、读档与备份

世界会在重要进展、钟龛和完成区域到达等边界记录旅途。读档恢复保存的检查点与区域，不保证回到退出瞬间的任意位置。步行通道的中途位置不会被当作目的地区域的完成检查点；取消装载时保留源区进度。

倒下会留下保存部分碎钱的归途结；再次倒下会替换旧结。沿提示返回拾取可收回遗留碎钱，永久能力和装备不会因此清空。

设置页提供三个存档槽。正常默认文件名为：

- 槽1：`pilgrimage_world.json`
- 槽2：`pilgrimage_world_slot_2.json`
- 槽3：`pilgrimage_world_slot_3.json`

记录位于 Godot 用户数据目录，通常是：

- Windows：`%APPDATA%/Godot/app_userdata/绯线巡礼 - 互联世界/`
- Linux：`~/.local/share/godot/app_userdata/绯线巡礼 - 互联世界/`；设置了 `XDG_DATA_HOME` 时使用该目录下的对应位置。

升级前退出游戏并备份整个目录，其中还可能包含 `pilgrimage_accessibility.cfg`、`.bak`、`.previous` 和恢复保留文件。不要只复制一个 JSON，也不要在游戏运行中手改文件或把旧版本直接覆盖到新档。

写入会先验证临时文件并保留可用的上一份记录；损坏主档不会被自动当作正常记录覆盖。设置中的备份恢复会验证该槽 `.bak`，并在替换前保留原主档为 `.before_restore_…` 文件。恢复可能回到较早进度，操作前仍应自行备份。若主档或备份损坏、版本不兼容或写入被暂停，按界面提示处理；不要删除错误证据来强行继续覆盖保存。

旧版记录有兼容迁移路径，但不保证所有未来或损坏数据可读，也不保证新档可被旧版本读取。共享的地图图钉属于存档进度；换槽、重启和恢复备份时一起遵循对应旅途记录。

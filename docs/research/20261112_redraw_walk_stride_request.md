# 重画走路循环缺少迈步：需要重新出图的清单（2026-11-12）

量法：每帧按运行时画布摆放，取 alpha>128 的轮廓；“变化”= 相邻两帧轮廓的 1 − 交集／并集，循环首尾也算；“腿部”只看轮廓下方 35% 的高度。原画的数值含忽大忽小的抖动，所以不要求回到原值，只看重画后腿是否还在动。数据来自 main（0ad1d4f9）上已合并的 57 段重画中的 27 段地面走路；飞行角色不在此列（翅膀由着色器摆动，见 #600）。

## 出图要求（给 image_gen 的提示词要点）

1. 一张图内画完整一个步态周期，帧数与原片段相同（16 或 32），保持现有画布、朝向、帧率与循环。
2. 明确写出关键姿势而不是“轻微走动”：接触（前脚落地、后脚蹬直）→ 承重下沉 → 过渡（两脚交错）→ 抬升，左右脚各一次；多足角色写明“对角腿成组交替，组间相差半个周期”。
3. 身体上下起伏为画布高度的 2–4%，头、披挂、尾部滞后半拍，不要每帧同一个躯干姿势。
4. 脚落地帧的脚底贴同一条地面线；全片轮廓面积最大／最小 ≤ 1.15（现有守卫）。
5. 验收数值：腿部变化 ≥ 0.15，循环接缝 ≤ 0.25，轮廓变化／平移 2px 比 < 3（后两项是现有守卫）。建议把“腿部变化下限”加进 `tools/creature_redraw_art.py` 的走路片段守卫。

## 不需要出图、已用程序解决的

- 重画片段比原动作大一圈（中位 1.16 倍）：#598 按身体面积重新对齐。
- 飞行角色翅膀不动：#600 着色器绕翅根摆动（7 种 12 段）。

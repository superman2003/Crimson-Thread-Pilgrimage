# 输入设备与操作提示

基线：`main` / `e79adaf975b10af6a57e136a2399ba362dace7ec`（含 #68、#74）。本批改善操作提示，不修改动作映射、攻击、移动或存档格式。

## 玩家可见行为

此前 `_short_binding` 总是取 InputMap 中第一个事件：手柄操作时路牌、跳跃教学和技能卡仍显示键盘键；对话继续/离开固定写着 F / Esc。现在这些入口统一读取实时映射，优先显示最近使用的设备对应绑定。对话使用实际 `interact` 与 `close_overlay` 动作，保持面板打开也能刷新；两行提示放在肖像下方，长组合键可悬停查看全文。

| 情况 | 显示/处理 |
| --- | --- |
| 有效键盘按下、鼠标按钮按下 | 切换到键鼠提示 |
| 手柄按钮按下、明显摇杆/扳机输入 | 切换到该手柄的提示 |
| 按键释放、键盘重复、鼠标移动、轻微摇杆漂移 | 保持原设备，避免闪动 |
| 扳机负向静止值、非有限轴值 | 不切换设备 |
| 活动手柄断开 | 回到键鼠提示；重新连接本身不抢占设备 |
| 其他手柄断开 | 保持当前设备 |
| 当前手柄缺少绑定、存在键鼠绑定 | 显式显示键盘或鼠标绑定 |
| 仅有其他手柄专属绑定、动作缺失或没有有效事件 | 显示“未设置” |

轴切换阈值为 0.65；它只影响提示，不改变 InputMap 死区或玩家移动。手柄按钮采用 Godot 标准 A/B/X/Y、Back、L3/R3 等文本，不推断厂商品牌。方向轴显示左/右摇杆和方向箭头；键盘组合键保留修饰键，鼠标侧键和滚轮有独立名称。

输入上下文只保存会话内设备编号，不保存 UI、World 或 Player 引用。静态连接监听断连信号，因此地区 UI 释放/重建间隙也能处理断连。每次显示均读取 InputMap，重映射后不用清空提示缓存。现有路牌距离、最近交互对象选择与遮挡面板规则保持原样。首次教学的**新提示**使用当前绑定；已显示的叙事/历史 toast 不重新改写，散落在旧剧情文案里的固定按键也未在本批全面改写。

## 验证

新增 `input_prompt` 套件并接入默认回归和独立完成标记；默认套件总数由 92 增至 93。定向 workflow 使用相同严格运行器，保留零退出码之外的脚本/资源错误检查。

专项实例化真实 World / UI / Player，通过 `Input.parse_input_event` 进入实际 UI 输入回调，检查真实钟龛路牌、教学栏、打开中的对话、即时重映射、其他设备绑定排除、噪声过滤和断连。路牌附近的位置是夹具，不代表自然探索通关。UI 重建用替换 UI 节点检查共享状态；断连窗口通过临时移除 UI 自身信号回调模拟。

- `input_prompt`：默认 **36 项、0 失败**；开启可选截图检查时 **38 项、0 失败**。键盘/手柄各一张真实 GL 画面已检查，两行提示位于独立列，不覆盖交谈按钮。
- `input_settings_regression`、`ui_build_accessibility`、`world_wayfinding` 为相关回归；精确结果以本批最终日志和 PR 为准。
- 反向移除 UI 的输入观察接线后，36 项中检出 **15 处失败**；恢复后复验。该变异未保留。
- `npm test` / campaign 和两轮恢复模式资源导入作为提交检查，结果见 PR。

首轮本地探针因两个动态表达式的类型推断报错，未计为通过，已补明确类型。下一轮夹具错误假设设备 7 可以使用默认设备 0 的普攻绑定，出现一项失败；改用明确的设备无关夹具，并保留对其他设备专属绑定的拒绝检查。接入新套件时运行器单测先检出了旧的 92 套精确计数，已更新到 93，并检查新入口存在；未放宽完成标记、引擎错误或超时检查。

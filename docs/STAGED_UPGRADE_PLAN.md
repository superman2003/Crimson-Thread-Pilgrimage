### W00a 具体边界

`world_layout.json` v1 固定六区原点及 authored world 外包尺寸（包含现有回访工房）。单位是运行时像素；坐标平移不旋转或缩放。原点分隔现有区域，通道间隙尚未生成实体地形，不能称为已可步行连接。区域地图继续使用 #17 的既有绘图坐标，没有被重排。

`world_coordinates.gd` 是坐标转换的唯一注册表；未知区域返回非有限坐标而不是悄悄当作原点。`Main.player_world_position()` 提供真实当前玩家的统一位置，当前 Player 仍在区域场景内模拟。

存档 v3 的 `world_location` 是当前恢复钟龛的世界坐标，不是半空即时位置。`entry` 和每区 `checkpoint` 保留原有本地坐标；全局捕获自动原子推导 `world_location`，读取用它反算本地出生点。不一致坐标、未知布局版本和损坏内容拒绝读取/覆盖。旧单章和测试中的非注册区域保持原存档契约，不虚构对应世界位置。死亡遗留物仍保存 region_id + 本地位置，未改掉已有恢复规则。

v1/v2 迁移只在内存中进行；首次成功写回才生成 v3，`.bak` 保留原始磁盘内容。迁移保留原有地图 owned/charted/pending、能力/货币/剧情/每区状态；v2 还保留构筑和遗留物。未来改变原点必须新增显式布局迁移，不能直接改 v1 原点。

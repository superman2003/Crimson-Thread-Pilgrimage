# 叙事重设计：先把一个名字带回去

这次改稿以实际人物遭遇组织信息，不按 JSON 行数或追问数量验收。主线、支线与结局继续使用既有状态、奖励和六证词条件；不新增身世定论、章节先后锁或隐藏结局门槛。

## 主线的递进

开场先给一个能够复述的请求：雨渠孩子记得父亲阿禾，登记却说没有这个人。学徒不承诺救回死者，巡礼者不承诺一定查全。玩家从工牌背面的铆痕、孩子的生活记忆、书记署名的抄页，完成一次可追溯的调查；回到钟庭后，名单变成需要有人按住布角才能缝下的一针。

六城允许任意探索顺序。下面是信息逐步互证的关系，不是强制关卡顺序；跨城人物、物件和消息只在已有取得条件满足后提及。

- 苔钟庭：井壁两次刻痕，把献心者与后来被牵入的孩子分开。学徒怕把名字缝错，司事记得自己拒绝过一次敲门，斥候量的是背着伤员能否走回来的台阶。
- 铸雨渠：把抽象的收声制度落到阿禾身上。柳凭修过的铆钉认人，孩子要真实消息，工头承认自己为了留名而留下的空位被用来继续征工。
- 盐白书库：查清改约手法，也追问传递记录的人。书记抄过错误副本，不再以保原件抵销自己的责任；叶从守柜子转为让原件能被核查；读者坚持找完祖母的小注。
- 断弦温室：亲眼区分旧接弦与新铜箍。歌守徽想试着停一拍，园丁先修西门，囚徒先要自己放稳左脚。救援的完成不等于立刻接到新的劳动义务。
- 黑曜道：军册、木条和灯号解释如何把归乡变成召回。骑士会替死者应声，修女误补过一拍，逃旗手离队后身体仍认军号。完成任务后保留这些习惯的余波。
- 无声王冠：把六城不同经历摊在一张桌上。司钥没有替门外无名者补写动机；守望者核对六份原件，也保留玩家选择自己不赞同道路的权利；回声承认它也曾盼后来者替它做完。

## 写作与交互约束

每个问题要改变玩家对一件事或一个人的理解，不能只给旧主题换设施名。回答可以两句、三句，停顿的位置跟随角色；删去重复追问，比补足统一篇幅优先。追加回答说明眼下的一点变化，不把战胜 Boss 写成消除全部创伤。

NPC 只声称自己做过、见过或正在打算的事。未来的维修计划用打算表达；不凭台词宣称新关卡、新动画或物理世界改造已实现。具体取证与任务线索仍由真实物品、场景见闻和状态解锁。

巡礼者手记用第一人称或现场记录，写手、脚、物件、听见的话与尚未确定的地方。不出现“主角应当”“结局需要体现”等作者评语。能力成长带来一次新处境，不自动证明失忆前的师承与身份。

## 三种结局

重鸣同时呈现水位退下和仍然失声的人，人物继续处理旧约留下的事；断冠同时呈现第一声呼喊和越过水尺的潮，新生活包含缺人、争论与具体协作；改写用可撤回的签名、副本核对和反复试过的领扣呈现持续维护，不保证所有人从此都能轻易拒绝。

支线回收只在任务与奖励都已成功提交后出现。阿禾的名字被送回，不意味着父亲本人归来；任何结局都不能凭尾声复活或补全未知下落。未完成支线的尾声不引用相关私下交谈。

文案修订保留旧回答的原始快照，供已确认的旅记恢复。旧稿不再进入可选问题；新版需要重新阅读确认，旧版记忆不会被新版覆盖。

## 验证边界

静态检查核对真实来源、条件与文案形状；原生夹具核对解锁、逐句确认、版本记忆、存档失败回滚以及旧稿迁移。它们不证明陌生玩家理解、自然通关或角色感染力；这些仍需实际试玩反馈。

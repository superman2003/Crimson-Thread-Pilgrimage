# 第一章箱庭重设计落地记录

日期：2026-07-26
上游设计：`docs/spec/20260726150000000_绯线巡礼互联世界拓扑设计.md`、`docs/spec/20260726150500000_苔钟庭箱庭重设计.md`

## 本次变更

**地图数据**：`godot/data/demo_ch01_moss_bell_court.json` 由 13 房 / 54 平台（5740×2922）重做为 **42 房 / 138 平台（7660×6446）** 的丝之歌式箱庭。生成器为新增的 `tools/handcraft_ch01_boxgarden.mjs`（旧 `handcraft_ch01_2d.mjs` 保留不再使用）。结构：中央钟庭 2800px 垂直枢纽 + 钟塔/钟冠上环 + 东上露台环带（冲刺捷径直落 Boss 翼）+ 水窖下环（假苔穴、25 级后门升梯井）+ 西苔脉迷园（精英战获得绯线冲刺）+ 井喉终局门。主线全程不依赖冲刺（间隙 ≤160、上升 ≤96），冲刺只开捷径与秘密。

**能力门系统首次接入运行时**：9 座 `locked_gates`（dash×4、silk_wall_grip、double_thread_jump、thorn_downstrike、lantern_phase、crown_resonance），6 个 `kind:"item"` 收集品（thread_dash、静靴、能量纺锤、地图残页、心结、证词其一），catalog 相应扩充。跨章回访锚点：盐风走廊(ch3)、钟髓密室(ch4)、苔壁竖井(ch2)、苔脉裂缝(ch5)、井喉(ch6)、朝圣阶封门(ch5 捷径)、钟骨长梯站厅（世界纵轴，封存态）。

**引擎**：`player_controller.gd` 新增 `dash_unlocked` 门控；`main_level.gd` 新增 `_sync_player_abilities()`，由 `ability_gated_start` 配置驱动——第一章开局冲刺锁定，拾取 thread_dash 后即时解锁并打开全部冲刺门。ch02–ch06 未设该字段，冲刺照旧无限制，行为不变。

**验证脚本口径更新**：`demo_validation.gd`（收集品由"必须为空"改为"仅限 catalog 内 item"，存档点 2→2–4，新增能力门拾取/解锁运行时断言）；`all_chapters_demo_validation.gd`（收集品数量按配置 item 数核对，存档点 ≤4）；`inventory_map_validation.gd`（gear_gallery→hub_gallery）；`tmp_check_contracts.mjs` 同步。

**唯一性**：生成器内置 `deduplicate()` 确定性变奏循环，镜像 `audit_map_uniqueness.py` 的节奏/尺寸 token 算法，消除全部主路 3-gram 重复（收敛于 17 次迭代，尺寸重复率 0.15 < 0.25）。

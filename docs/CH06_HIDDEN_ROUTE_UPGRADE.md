# CH06 钟舌库可选支路

本批为 W04 的小范围补强：在实际运行的 `demo_ch06_silent_crown_core` 中，旧王钟舌的「问问道路」回答会指出钟舌库地面的可选冠下回声碎片、向西折回西环廊以及向东通往王座前廊。可选物仍使用既有的 `col_branch_bell_tongue_vault`，拾取 `crown_echo_shard` ×5，不改变主线门槛。章节摘要同步记录钟舌库的可选奖励和路线提示。

`godot/scripts/ch06_hidden_route_validation.gd` 从核心竖井已有落脚平台建立测试夹具，其余验证使用玩家移动、碰撞、NPC 交互和拾取流程：实际落入钟舌库，读出 NPC 路线回答，拾取奖励，向东步行进入王座前廊，再重载存档并返回拾取点，检查奖励数量不增加且拾取物不重生。脚本只在测试中压制敌人造成的伤害，不跳过移动或房间碰撞。

本批没有新增平台或传送点。测试没有实走西向折返线，因此只把它作为 NPC 的现有路线提示；向东进入王座前廊是实际输入验证的出口。验证器不覆盖开启伤害下的战斗难度或完整第六章通关。Godot 4.6.1 的独立 CI workflow 会在精确 PR head 上运行该场景测试并检查退出码与 `failures=0` 标记；本地未安装 Godot，不能把脚本的静态检查称为 Godot 运行通过。

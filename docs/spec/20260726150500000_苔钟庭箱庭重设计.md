## 1. 空间总纲

世界尺寸约 7400 × 6800（旧版 5740 × 2922，垂直体量扩 2.3 倍）。整章是一个以中央钟庭为枢纽的立体箱庭，六个子区按剖面咬合：

```
上带 (y  400–2200)   [钟塔上域 C]      [上东回环 G]
中带 (y 2200–4400)   [入庭断崖 A] [中央钟庭枢纽 B] [东翼锈冠殿 F]
下带 (y 4400–6400)   [西苔脉迷园 E]   [根须水窖 D]
```

主线动线（main_visit_order 概要）：入庭 A → 窄苔缝挤入 → 中央钟庭 B（豁然展开）→ 上钟塔 C 绕冠悬廊坠回枢纽 → 下水窖 D 拉开后门升梯 → 西迷园 E 打精英拿绯线冲刺 → 回枢纽 → 东翼 F 清路、击败苔钟守母 → 排水钟管去第二章。combat_clear 规则不变：清完普通敌人开 Boss 门。

### 柳暗花明节点（压缩—释放节奏）

1. **窄苔缝 → 中央钟庭**：104px 净空贴顶匍匐 12 秒，出口突然打开成 2800px 高的垂直巨腔，钟骨长梯站厅的青铜剪影在头顶。
2. **钟冠悬廊坠回**：爬完折梯到达世界最高处，从钟冠边缘一跃，穿过钟身裂缝直接落回枢纽顶层露台——第一次"原来是通的"。
3. **假苔地板 → 假苔穴**：水窖环廊一段苔面是陷阱地板，踩碎跌进隐藏石穴，穴内有货藏与暗河入口。
4. **缠根迷径 → 断枝祭坛**：西迷园越走越窄、垂藤井一路向下压迫，底部忽然展开成祭坛巨窟，精英守卫与绯线冲刺在此。
5. **闸厅升梯**：水窖尽头拉杆，升梯轰然接通枢纽下沿——第二次"绕回来了"。

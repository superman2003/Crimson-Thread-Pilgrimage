## 0. 给主控的落地摘要

- 全作音乐建立在**一个三音核心动机（缄钟动机）+ 两个卫星主题（绯线主题 / 黑潮低语）**之上，六区 BGM、七首 Boss 曲、三结局曲全部是这三者的变奏网络——对标丝之歌 Christopher Larkin 用少量主题贯穿全谱（空洞骑士主标题四音下行动机贯穿 *Hollow Knight / Sealed Vessel / Radiance*；Hornet 主题从初代 Boss 曲一路延续到丝之歌）的做法。
- 全部声音资产归入**三大声音家族**：钟（安全/反击/存档）、线（主角一切能力）、潮（危险/深处/结局 B）。任何新音效先归家族再做设计，保证十小时游玩后玩家能"用耳朵读世界"。
- 混音走 Godot 总线分层（Master/Music/SFX/Ambience/UI），区域混响按世界海拔 L+3→L-2 递变，战斗 ducking、濒死低通心跳齐备（§5）。

## 1. 音乐总纲：缄钟动机与变奏网络

### 1.1 设计参照（丝之歌手法拆解）

Christopher Larkin 在空洞骑士/丝之歌里的三个可复用手法：

1. **小动机大网络**。初代主标题的四音下行小调动机以不同配器、速度、调式出现在开场、圣巢各处直至 *Sealed Vessel* 与 *Radiance*；Hornet 的主题在初代 *Hornet* Boss 曲确立后，在丝之歌中随主角身份延续。玩家不需要懂乐理，但"这段旋律我听过"的既视感就是世界的黏合剂。
2. **区域乐器化**。丝之歌各区靠配器而非旋律区分：深坞（Deep Docks）用工业金属质感、圣咏堂（Choral Chambers）用真实合唱、钟心镇（Bellhart）让钟声同时充当环境声与音乐、法雅山（Mount Fay）音响稀薄如缺氧；快速旅行钟兽（Bellway 的 Bell Beast）有自己欢快的小主题。区域=音色，主题=血缘。
3. **Boss 曲乐章式推进**。初代 *Mantis Lords* 二阶段加入声部、*Grimm* 用三拍舞曲写恶魔戏班、终战曲目再现主标题动机完成闭环。Boss 曲不是循环垫乐，而是"有结构的乐章"，P2 用转调/加层/变拍标记阶段。

### 1.2 缄钟动机（Motif of the Silent Toll）——全作 DNA

**音乐学定义**（默认调性中心 D）：

```
音列：  D4 ──→ A3 ──→ B♭3 ──→ (休止)
音程：   下行纯四度    上行小二度    不解决
节奏：  6/8 中 ♩.（附点四分）─ ♪（八分）─ ♩.~（附点二分延音）─ 休止一拍
和声：  悬在 D–A 空五度持续音上，B♭ 制造小调阴影但从不落回 D
```

三个语义绑定：

| 音程/手势 | 语义 | 世界观对应 |
|---|---|---|
| 下行纯四度 D→A | 钟摆坠落、重量 | 倒扣巨钟压住深井 |
| 上行小二度 A→B♭ | 钟舌被绊住、欲响未响 | 王冠钉住钟舌，声音被缝走 |
| 结尾休止（终止式回避） | 缄默；乐句永远"没敲完" | 主角代号"缄"；六城失声 |

**全作只有三处允许动机完整解决**（B♭→A→D 落回主音，"钟敲完了"）：结局 A 重鸣、结局 C 真结局二重奏、以及钟骨长梯全站点开通时的一次性彩蛋钟声。除此之外任何曲目中的动机都必须停在 B♭ 或休止上——这是作曲铁律，保证终局解决的情绪兑付。

### 1.3 两个卫星主题

**绯线主题（缄的主题，对标 Hornet 主题的角色贯穿）**：

```
音列：  D4 ↗ B♭4（上行小六度大跳）→ A4–G4–F4–E4（级进下行收针）
节奏：  3+2 分组（5/8 感），大跳=抛线，级进下行=收针缝合
音色：  始终由"拨/挑"类乐器演奏（竖琴、拨弦、扬琴质感），与钟的"敲"对立
```

出现位：治疗引导音（纺线声的音高化）、能力获得 jingle、每首 Boss 曲 P2 的对题、结局 C 与缄钟动机的对位二重奏。

**黑潮低语（反主题，非旋律）**：

```
材料：  全音阶四音簇（如 C–D–E–F♯）+ 微分音下滑 + 倒放包络（音头在尾部）
节奏：  无节拍，呼吸式涌动（8–13 秒一涌，斐波那契间隔避免可预测）
音色：  倒放钟声采样、水下低频 drone、多层耳语（听不清词）
```

出现位：井喉/深井黑潮隐藏区、黑潮童声 NPC 靠近时、结局 B、任何"敲三下"伏笔场景（ch2 铁匠柳台词）。

### 1.4 三大声音家族（SFX 与音乐共用的音色宪法）

| 家族 | 音色特征 | 覆盖内容 | 玩家习得的语义 |
|---|---|---|---|
| **钟族** | 青铜敲击、泛音长尾、纯四/五度 | 钟龛存档、bell_guard 格挡成功、下劈 pogo 命中、快速旅行、章节印记拾取 | 听到钟=安全、反击成功、进度确认 |
| **线族** | 拨弦、丝线摩擦、绷紧/释放瞬态 | thread_dash、echo_hook、double_thread_jump、缝补回血、crown_resonance | 听到线=主角自己的力量 |
| **潮族** | 倒放、水下低通、簇音、耳语 | 深井、黑潮敌意、结局 B、危险水域 | 听到潮=禁区与代价 |

### 1.6 全局调性/海拔规划

调性随世界剖面移动，海拔越高音区越高、织体越稀：

| 海拔 | 区域 | 调中心/调式 | 主奏音区 | 织体密度 |
|---|---|---|---|---|
| L+3 | ch6 寂冠核心 | D（无功能和声，纯白键） | C5–C6 童声 | 1 声部 |
| L+2 | ch3 档案馆 | A 利底亚色小调 | C4–C6 | 2–3 声部严格对位 |
| L+2 | ch4 温室 | E 小调（提琴空弦 E–A–D–G 泛音） | G3–E5 | 断续 2 声部 |
| L+1 | ch1 苔钟庭 | D 多利亚 | D3–D5 | 3 声部 |
| L0 | ch2 铸雨渠 | G 小调 | G2–G4 | 打击主导 |
| L-1 | ch5 巡礼路 | D 弗里几亚（同主音变暗） | D2–D4 | 齐奏块状 |
| L-2 | 深井黑潮 | 无调性，D1 倒影 drone | D1–D2 | 非乐音 |

相邻区域调性均为近关系或同主音（D 多利亚↔G 小调↔D 弗里几亚↔A/E），保证跨区 crossfade 不打架。

## 2. 六区 BGM 规格

### 2.1 通用技术口径

- **双层结构**：每区 `explore_loop`（全编制探索层）+ `combat_layer`（同 BPM 同调、等长的战斗加层 stem，只含鼓组/低音/紧张声部）。运行时用 `AudioStreamSynchronized`（Godot 4.6 内置）同步播放两条流，进战斗 0.8s 把 combat_layer 音量从 -60dB 拉到 0dB，脱战 2.5s 退回——对标丝之歌"探索安静、遇敌起鼓"的无缝感。
- **循环**：OGG 导入开启 loop，显式写 loop point（不用"播完重播"的 `finished` 手动循环，消灭当前 BGM 的接缝断音）。探索层循环 88–128 秒，避免 40 分钟首访期听腻。
- **save 房（钟龛）摇篮曲**：全球统一旋律"龛中眠"= 缄钟动机的**大调增值版**（D–A–B♮，小二度翻成大二度，唯一日常听到"接近解决"的地方），每区用该区主奏乐器演奏 16–24 秒小循环。进入 save 房 crossfade 1.2s，音乐层全退、只留摇篮曲+微量环境——对标丝之歌"长椅=听觉安全屋"：坐下的一刻战斗与环境压力从混音里消失。
- **房间类型→音乐状态映射**（数据侧用房间 `kind` 驱动，ch1 42 房已有 kind 字段）：

| 房间 kind | 音乐状态 |
|---|---|
| entry/corridor/shaft/hub/vista | explore_loop（vista 额外开大混响 send +20%，加 shimmer 单音） |
| arena / 敌人激活 | explore_loop + combat_layer 淡入 |
| save | shrine_lullaby 独占 |
| secret / treasure | explore 层减配（只留主奏与垫底，-6dB），营造"屏息" |
| gate（能力门房） | explore 层 + 门族提示单音（对应能力所属章节的主奏乐器长音） |
| boss | 章 Boss 曲（§3） |
| transit（钟骨长梯站厅） | bellway_transit_loop（§2.9） |
| exit / chapter_transition | explore 层淡出 4s → 下一章入场 stinger |

## 3. Boss 音乐（六章 Boss + 终 Boss）

### 3.1 通用曲式与技术口径

对标丝之歌 Boss 曲三原则：**入场 stinger 确立威压 → A/B 段乐章推进 → P2 转调或加声部标记阶段**；击杀瞬间音乐骤停（hard stop），只留一记钟族余韵 + Boss 死亡音——"战斗结束"永远由静默宣告。

- 结构统一记法：`Intro(stinger) → A → B → A' → [P2 触发点] → C(转调) → 循环 B/C`。
- P1/P2 用 `AudioStreamInteractive`（Godot 4.6 内置）做小节边界切换，切换等待 ≤1 小节。
- 每首 Boss 曲的 P2 必须让**绯线主题作为对题**进入（玩家的力量在音乐里正面迎战），这是全系列 Boss 曲的签名。
- Boss 名以运行时 demo JSON 为准（campaign_chapters.json 中"锈冠守卫/沉锤铁匠/盐白契约官/百钥守门人"为同一 Boss 的旧别名，作曲以下表为准）。

## 4. SFX 全目录

### 4.1 通用口径

- **命名**：延续 manifest 现有无前缀风格按域分组：`player_*` / `enemy_*` / `boss_XX_*` / `ui_*` / `amb_chXX_*`。变体文件 `_01.._04` 后缀。
- **随机变奏**：所有高频动作音（脚步/劈砍/受击）用 `AudioStreamRandomizer` 装 3–4 个变体 + 随机音高 ±4%（丝之歌式"连打不重样"的最低成本实现），替代当前"每键单文件无变调"。

- **播放限流**：同 key 最小间隔 40ms，同 key 最大同时 3 声部，超限按优先级抢占（§5.4）。

## 5. 动态混音系统

### 5.1 Godot 总线布局（default_bus_layout.tres）

```
Master
├── Music          （限幅器 Limiter）
│   ├── MusicExplore   （explore_loop + shrine_lullaby）
│   ├── MusicCombat    （combat_layer / boss 曲）
│   └── MusicStinger   （jingle / 结局曲）
├── SFX            （压缩器 Compressor，轻，ratio 2:1）
│   ├── SFXPlayer
│   ├── SFXEnemy
│   └── SFXWorld       （机关/拾取/场景）
├── Ambience       （发送至 ReverbZone）
├── UI             （不进混响，永远干声）
└── ReverbZone     （AudioEffectReverb，参数随区域切换，见 5.2）
```

- 现状迁移：现有代码 bus 全走 "Master"，第 0 期把 `_switch_bgm` 的 BgmPlayer 指到 MusicExplore、玩家/敌人 `_play_sfx` 分别指到 SFXPlayer/SFXEnemy、`main_level` 的 UI 音指到 UI。
- 音量选项数据字段：`master/music/sfx/ambience` 四档 0–100，存入用户设置；headless 静音规则（`_should_play_sfx`）原样保留。

### 5.4 声部管理

- 每 key 最大同时发声 3；全局 SFX 上限 24 声部；抢占顺序 P0>P1>P2，同级抢最旧。
- 同 key 最小重触发间隔 40ms（铃雨/钥匙雨类弹幕音单独限 6 声部+自动音量递减）。
- 距离衰减：沿用 AudioStreamPlayer2D max_distance 900，敌人音 attenuation 曲线加陡（1.5），环境 one-shot 用 2D 声像随机 ±0.6。

### 5.5 濒死状态（对标丝之歌把危机做进混音）

HP=1 时进入濒死混音态，HP 回升或死亡时退出：

1. Music 总线插入低通：2kHz 起步，2s 内滑到 800Hz；
2. `player_low_hp_heartbeat` 循环淡入（55–60 BPM，不与音乐 BPM 同步——生理与音乐脱轨的不安）；
3. Ambience −6dB，SFXPlayer +2dB（自己的动作声变近）；
4. 死亡瞬间：全总线急速低通到 300Hz+混响 freeze 0.9s（与 `_hard_respawn` 的 0.9s 对齐），复活时由 `player_respawn` 龛铃三音破开。

其他滤波状态：水下（ch2 泵井/水窖暗河）全局低通 600Hz+气泡；lantern_phase 期间 Music 低通 1.2kHz+反相 chorus；窄苔缝低通 1.2kHz（§2.2）。

### 6.2 免费音源采购清单（符合 CC0 / PD / Apache-2.0 兼容政策）

授权总则：**首选 CC0 与 Public Domain**；Pixabay/Sonniss 类"免费商用但非 CC"许可属于 manifest 政策中的 "equivalent free commercial-use"，可用但须逐条在 `NOTICE.md` 登记来源与许可文本；**CC-BY 4.0 仅当确认可在 NOTICE.md 署名时作候补**；CC-BY-SA / CC-BY-NC / GPL 音源一律不收。freesound 检索务必开 license 过滤器选 "Creative Commons 0"。

## 附：设计红线（Do / Don't）

- **Do**：任何新音效先问"属于钟/线/潮哪个家族"；任何新旋律先问"是缄钟动机的第几种变奏"。
- **Don't**：终局三豁免点之外，任何曲目不得让动机解决回主音 D。
- **Don't**：ch6 不加常规战斗层——无声之城靠"抽走音乐"制造压迫，加鼓即失败。
- **Do**：Boss 招式 windup 音必须与琥珀 telegraph VFX 同帧，active 音与判定帧同帧——听觉预警与视觉预警是同一条数据（ai_profiles 的 windup/active 时间轴）。
- **Don't**：不引入任何 CC-BY-SA / NC / 未知授权素材；freesound 下载页截图与许可文本随资产入库存档。

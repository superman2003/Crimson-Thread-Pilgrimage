# 绯线巡礼互联世界拓扑设计（Silksong 式箱庭改造）

日期：2026-07-26
状态：设计定稿，第一章先行落地
取代：`20260615161147827_绯线远征6章RouteGraph规划.md` 中的线性串联结构

## 1. 设计目标与参考拆解

当前六章是"线性串联的横版关卡"：每章一条主路加一个上环一个下环，房间沿 x 轴排队，探索感平。本次改造参考《丝之歌》的三个核心手法：

**手法一：垂直剖面世界。** 丝之歌的法鲁姆世界是一张垂直剖面图——苔穴在底部，圣堡在顶部，所有区域按海拔咬合。玩家对"我在世界的哪里"有身体记忆。我们的世界观天然适配：旧王朝建立在一口倒扣巨钟之上，巨钟压住深井黑潮。因此世界剖面从上到下是：钟冠 → 钟肩 → 钟腹 → 钟裙 → 钟口 → 深井。

**手法二：柳暗花明的房间语法。** 丝之歌大量使用"窄口—豁然"节奏：一条压抑的匍匐通道突然打开成巨大的垂直空腔；一个看似死路的瀑布后面藏着整条暗河；打通一个捷径闸门，发现绕回了一小时前路过的存档点。房间不是走廊的串联，而是"压缩—释放"的呼吸。

**手法三：能力门驱动的回访。** 每个区域在首访时保留 20–30% 的不可达内容（能看见、够不着），由后续章节获得的能力解锁。玩家带着新能力回访旧区域时，旧地图长出新路线。

## 3. 区域咬合与跨区通道

互联原则：每个区域至少 3 个出入口（丝之歌平均 3–4 个），其中 1 个是首访主入口，1 个是能力门锁住的"回访入口"，1 个以上是打通后的捷径。

### 3.2 钟骨长梯（世界纵轴）

参考丝之歌 Bellway/Ventrica 的"交通骨架"设计，增加一条贯穿世界的垂直竖井——**钟骨长梯**，沿巨钟内壁铸造，站点：ch6 冠室 / ch3 档案层 / ch1 钟庭层 / ch2 水线层 / ch5 钟口层。每个站点由该区域内一个拉杆机关独立开启（首访不可用，打通即为永久快速通道）。第一章先落地"钟庭层站厅"作为封存状态的场景锚点，让玩家第一小时就看见这条纵轴，理解世界是垂直的。

## 5. 存档、快旅与节奏

存档点（钟龛）密度按丝之歌标准收紧：每区 3–4 个，其中 1 个藏在支线里作为探索奖励。快速旅行由钟骨长梯承担，站点解锁本身就是每区的一个探索小目标。节奏模型：每区首访 40–60 分钟，其中主线 60%、可选 25%、当次不可达（回访钩子）15%。

## 物理和加载边界

旧钟管的两端延长碰撞保持同一高度，在新坡道上会与实际坡面错位。现在延长段、端帽和背景基座沿同一坡率计算，坡面在标记处经过正确支撑高度；两向入口标识按真实世界坐标计算方向。

继续保留通道独立碰撞层、来源区冻结、资源/奖励隔离、原检查点存档、折返/取消、目的区预检失败与取消后的显式重试，以及到达前暂停角色、到达后恢复普通碰撞。没有新增传送式中途出口或通道内存档。

这不是共享房间洞口或六区同时物理驻留。长通道目前没有遭遇、交通收费或独立设施动画；它们仍是有区域石材区别的独立内容块。终点仍加载目的地区域，不能将本批计为 W00/T03/T04 整包完成。

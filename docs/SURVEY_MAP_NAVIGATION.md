# 地图键盘与手柄浏览

基线：main / 64ec26851e6d664b54d14bf4347cadb4a9d4cfe6。

区域图和世界图现在可直接使用 WASD / 左摇杆平移，PgUp/PgDn 或 RB/LB 缩放，Home / Y 复位。保留鼠标滚轮、拖动和原有缩放按钮；方向键与十字键继续服务 GUI 导航。图内显示简短操作提示，视口悬停说明复位操作。地图未显示时忽略新增快捷键。

平移按基准 1280×720 界面中每秒 560 像素计算，斜向限速，摇杆采用 0.25 死区；平移仅改变地图绘制容器，不改变房间、图钉或玩家世界坐标。缩放仍限制在 1–4 倍并保持锚点，非法倍率不进入变换。

关闭/重开地图、切换区域图与世界图、应用失焦均清空按键、摇杆和鼠标拖动状态。活动手柄断连会停止其平移，另一手柄断连不打断当前设备。执行复位也会终止旧导航。未新增持久化字段，未购买或未补绘的内容仍由既有知识规则过滤。

新增 survey_navigation_validation.gd 接入现有 world_map，22 项（包含真实 Main 输入轮询下的复位/地图开关键兼容）直接向正常输入分派注入键盘/手柄事件，并检查真实 World 地图视口的缩放、移动、停止、临界状态和 30/60/120 Hz 一致速度。对同帧注入显式 flush_buffered_events，确保输入已派发再断言；生产逻辑无需测试专用分支。Godot 4.6.1 / llvmpipe：world_map 679/0，survey_map_knowledge 17/0；双轮严格导入通过。cartography 购图、补绘和跨区域重启回归通过，input_settings_regression 93/0；npm/campaign 通过。完整远端 CI 以 PR 最终提交为准。保留既有 ObjectDB 退出警告。

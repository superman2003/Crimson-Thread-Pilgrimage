# 首批契印系统验收

本页记录自动验收的范围与实际证据；自动场景测试不能替代陌生玩家体验、完整动画审核或耳机试听。

## 可复现命令

```bash
python3 tools/validate_seal_catalog.py
python3 tools/run_godot_regressions.py --engine /path/to/godot --suite seal_acceptance --suite player_upgrade_regression --suite save_product --suite upgrade_integration --log-dir /tmp/seal-logs
```

引擎：Godot 4.6.1。每个套件独立使用临时用户目录，不读取玩家存档。

## 已验证行为

| 验收项 | 实际测试与证据 |
| --- | --- |
| 两技能、两战具配装 | `seal_acceptance` 实例化完整 World，触发真实构筑页按钮，将回声针、绊线钉装备到第二位置；拒绝相同技能重复占槽。 |
| 切换不能刷新资源 | 将玩家设为 3 生命、63 能量、投罐 1 次、穿刺冷却 2.75 秒，再通过契印页按钮切换司铸，四项数值保持。 |
| 无重复加成与残留 | 同步五次基础属性保持；重复铭饰被拒绝；换校录时按容量移除溢出铭饰；敌人复活清除盐记、绊住等临时状态。 |
| 技能练习空间 | 六技能均有练习计划；起始区两个真实针架生成并由物理射线验证底部支撑，避免悬空练习目标。 |
| 战具练习空间 | 四件主战具均有练习计划与遭遇提示；起始区铜铃投罐练习架与技能针架并存，meta 分离以免抬高技能练习计数。 |
| 永久探索能力保留 | 授予八项永久能力后切换校录，四项移动能力和四项后续动作的启用条件保持；跨区后移动能力保留。 |
| 真实战斗判定 | 使用实际 Player 与 enemy_actor，关闭调试无敌；针击确实减少敌人生命，敌人的可见近战攻击确实减少玩家生命。 |
| 死亡、跨区与重启 | 记录死亡遗留物不会改配装和冷却；执行 `_travel_world` 替换为铸雨渠；再释放场景并从磁盘重新加载，完整构筑序列化数据逐项相等，遗留损失保留。 |
| 获得条件 | 新存档无法装备尚未获得的回声针；永久探索能力不再自动解锁装备；显式学习、修复与遗物事件授予解锁。人物获得流程由剧情套件另外验证。 |
| 存档兼容 | `save_product` 验证旧世界 v1 迁移、构筑冷却持久化、损坏主存档保护、备份恢复及三槽隔离。构筑 v1→v2 的两槽迁移由模型套件验证。 |

组合验收 `SEAL_ACCEPTANCE_PASS checks=32 failures=0`；战斗 `70` 项、剧情获得 `66` 项、图标与声音接入 `119` 项通过。UI 无显示器运行 `23` 项，通过实际渲染额外加入截图检查后为 `29` 项；既有玩家回归 `46` 项、存档产品回归 `23` 项、升级集成回归 `28` 项通过。

旧回归夹具按新版规则更新：装备解锁使用真实事件，不用区域或探索能力；精准防御保留净资源成本；守钟架势后方可受击；控制线阵在实际物理帧命中；公开战具保留出手收势。这些是策划行为变更，断言仍检查资源、风险与判定。

整套旧回归运行覆盖 35 个套件，其中首次移动测试的起跳采样因并发引擎时间调度出现一次失败；保持原断言重新串行运行后 19 项全部通过。新增六个契印套件及最终战斗修订通过单独串行批次检查，合计覆盖 41 个不同套件；并非一次未经重跑的全绿报告。

## 验收发现并修复的问题

敌人的新增盐记、绊住、索敌干扰与诱铃状态原先未在复活时清除；组合验收发现后，统一加入 `reset_for_respawn` 的清理流程。测试保留该断言，避免状态跨死亡残留。

补录实际 World 图片时修复练针架提示缺少中文字体、默认技能切换键与钩索重叠，以及钟龛回调未传递补给许可参数的问题。默认技能切换改为 C，钩索保留 K/X；组合回归增加实际钟龛补满次数、不清空冷却和输入不冲突断言。

## 尚不能据此宣称完成的项目

- 自动按钮触发覆盖真实 UI 回调；实际键鼠点击、手柄焦点顺序及不同字号的完整人工体验仍需核查。
- 伤害开启的局部遭遇已覆盖；六区全流程、三种契印多构筑及所有守门者的治疗窗口，需要人工通关验证与首轮平衡调整。
- 程序生成的符号、分阶段动作表现与声音接入具有功能证据；独立原创逐帧角色动画、手绘图标最终稿、硬件混音及试听属于后续视听验收。
- 目前为首轮数值，测试通过不等同于难度、趣味性与资源经济已定稿。

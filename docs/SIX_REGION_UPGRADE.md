# 六区系统升级交付记录

> 文档状态校准（2026-10-15）：本文为PR #12的历史交付记录。下文“钟龛免费补给”、旧槽位和当时待办不再代表当前规则：已接入四类兼容槽、付费部分补给、地图图钉及候选包构建工具。当前实现与尚未验收项见[首页](../README.md)及[总清单](REMAINING_UPGRADE_ROADMAP.md)，不以子项关闭整包。

本批已通过 PR #12 合入 main，基于 `93888a3`，把六区探索、八能力动作、战斗资源、构筑与剧情存档接入实际 World 场景。以下状态指本批改动，不表示整个任务包已经通过产品验收。运行入口为 `godot/scenes/World.tscn`，请使用 Godot 4.6.1。

## 已接入的玩法

- 新增第三／第五区、第四／第六区、第五／第二区的双向侧路，20 个能力练习与回访空间；八能力各有两处旧区目标。动作门必须实际执行对应能力，开启后保存机关状态；相位门属于付费开启的机械锁扣。
- 钟卫、棘刺下劈、灯影相位、王冠共鸣获得真实动作；普攻加入前摇、有效帧、收势和墙体阻挡；治疗预付能量，在落地引导完成时恢复，被移动、跳跃、冲刺或伤害打断不返还。
- 缝名、司铸、校录三契印；六技能、四战具、六铭饰，两技能／两战具槽，NPC 获得与强化、方案管理、线势／钟压／盐记及治疗附加效果。战具在钟龛免费补给，不再通过材料配方补充。
- 六区证据、NPC 状态与迁移、一次性支线报酬、三结局条件；证据与任务页展示实际进度，关键对话需读完才提交。
- 构筑面板、战斗 HUD、字幕与镜头等设置、三存档槽、旧版本迁移与备份恢复。死亡留下半数货币的找回结，二次死亡替换旧结；坠落不再免费补满能量。跨区落点提供短暂受伤保护。

默认键盘：Q 钟卫，空中向下攻击触发下劈，按住 E 相位，R 共鸣，L 特殊技能，T 战具，C 切换技能，G 切换战具，B 构筑；未取得能力时不能使用。以设置页及已有操作提示为准；技能／战具切换与使用已支持键鼠、手柄及重映射，完整人工手柄体验仍待验收。

# 六区系统升级交付记录

本批基于 `93888a3`，把六区探索、八能力动作、战斗资源、构筑与剧情存档接入实际 World 场景。以下状态指本批改动，不表示整个任务包已经通过产品验收。运行入口为 `godot/scenes/World.tscn`，请使用 Godot 4.6.1。

## 已接入的玩法

- 新增第三／第五区、第四／第六区、第五／第二区的双向侧路，20 个能力练习与回访空间；八能力各有两处旧区目标。动作门必须实际执行对应能力，开启后保存机关状态；相位门属于付费开启的机械锁扣。
- 钟卫、棘刺下劈、灯影相位、王冠共鸣获得真实动作；普攻加入前摇、有效帧、收势和墙体阻挡；治疗预付能量，在落地引导完成时恢复，被移动、跳跃、冲刺或伤害打断不返还。
- 绯线、铸钟、盐书三纹章；四主动技能、两工具、五被动、十制作／补给配方；纹章代价、槽位限制、冷却、次数、方案保存与 NPC 附近制作接入运行时。
- 六区证据、NPC 状态与迁移、一次性支线报酬、三结局条件；证据与任务页展示实际进度，关键对话需读完才提交。
- 构筑面板、战斗 HUD、字幕与镜头等设置、三存档槽、旧版本迁移与备份恢复。死亡留下半数货币的找回结，二次死亡替换旧结；坠落不再免费补满能量。跨区落点提供短暂受伤保护。

默认键盘：Q 钟卫，空中向下攻击触发下劈，按住 E 相位，R 共鸣，L 特殊技能，T 工具，B 构筑；未取得能力时不能使用。以设置页及已有操作提示为准；工具快捷键的完整手柄／重映射覆盖仍需补齐。

# 默认主角：缄 · 缠线小偶

缄继承第七签署者留下的绯线回响。旧契约布形成新的身体，胸口线结维持形体，磨损字迹承载被遗忘的名字。姓名、人物弧线、六证词与结局条件保留；六章与 Boss 试玩配置统一记录新身体。

## 完整替换

默认 Player 直接加载 `thread_doll_v1/manifest.json`。32 个状态全部采用小偶图片，没有旧人形回退。包括待机与短足跑步、起跳／上升／下落／落地、双向转身、普通／重击／跑攻、地面与空中的上／前／下攻击、冲刺、壁滑、钩索、相位、治疗、格挡、近战／范围／远程／控制／防御／共鸣技能、战具、受击和死亡。复生与暂停沿用既有状态清理及淡入规则。

两只短足使用相同的固定裁片与固定长度关节，膝部藏在布摆内。实际位移驱动 60 世界像素的步态周期，支撑脚抵消移动、坡度与平台载体位移；身躯有承重压低与腾起，八张独立上身表现手臂和布尾变化。碰撞体、移动速度、跳跃、无敌、伤害和技能费用不变。

短缝锥在攻击有效姿势中展开绯线针刃，令原有打击距离可见；没有额外叠加普攻刀光。钩索视觉从逐帧测量的胸口线结发出，武器锚点改用小偶自己的针尖。射线、牵引范围和战斗判定不因美术锚点改变。

## 资源与发布

[十张选中源表、提示词与构建说明](../art_requests/thread_doll_motion_v1/README.md)。172 张独立绘图，包含 164 张完整身体动作与 8 张跑步上身，别名不重复计数。启动预读也覆盖上身和脚部，冷启动只保留新身体纹理。

旧人形源码素材留作历史记录，默认运行和导出包均不依赖它们。两平台导出配置排除旧人形贴图目录与旧跑步／分层待机脚本。`validate_hero_v3.py` 保留历史素材检查并验证完整小偶构建，防止旧构建覆盖默认外观。

[第一章实机录像](../artifacts/thread_doll_v1/gameplay-review.mp4)与[32 状态动作预览](../artifacts/thread_doll_v1/actions-review.mp4)通过原生 OpenGL 捕获，固定 60Hz，用于外观与动作审阅；不替代陌生玩家试玩或帧时间性能测量。

## 验证边界

`hero_animation` 检查全部 32 个默认动作、每帧的小偶资源归属、原阶段时长、攻击方向、治疗／受击／钩索／冲刺衔接以及左右胸口锚点。`grounded_run` 检查脚长、坡地接触、循环边界、真实运行中的支撑脚滑移和闪白／淡出。`player_idle_motion` 独立核对实际像素、脚底、两侧朝向、亮暗背景、闪白与淡出。冷预读检查全部新身体资源，无旧人形纹理。

战斗、能力移动、动作预算、镜头以及发布包独立验证结果记录在本 PR 的原生测试和 CI。发布包内实际实例化 Player，并检查 32 个动作、全部图片、跑步组件及旧人形资源排除。概念稿与运行素材分开，不把设计示意算作实机交付。

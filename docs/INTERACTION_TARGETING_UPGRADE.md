# 世界交互目标与提示一致性

基线：`main` / `64ec26851e6d664b54d14bf4347cadb4a9d4cfe6`。本批独立于音量升级，使用原有 `world_wayfinding` 正式回归入口。

此前操作按 150px 选目标，路牌却用严格小于 140px 的另一轮查询：边缘位置可以操作而没有提示。目标等距时还依赖子节点顺序，邻区采用缓存角色或重建节点后可能换目标。

现在 Main 的 `INTERACTION_REACH` 统一为 150px，`interaction_target` 同时供实际操作和路牌使用；边界包含在有效范围内。路牌先通过同一常量做远距预筛，避免远处标记每帧重复扫描所有候选。对话继续使用同一距离常量。最近物件优先，同距时按 authored 节点名稳定排序；保持已可开启章节出口的原有优先级，锁定出口不获得该优先级。

隐藏、已排队删除的 Area 不拦截可见目标；自动拾取物不抢交互提示，手动拾取仍可被选中。加载中、死亡、切区或覆盖面板打开时不出现可操作的附近提示；加载中也不再接受实际世界交互。普通场景里的落地路牌仍保留物理标志，不因失去附近操作提示而全部消失。

## 验证与边界

`interaction_targeting_validation.gd` 扩展已有真实 World 路牌套件，保留原来的 25 项验证，增加 32 项：反向创建/重排同距 Area、最近距离、旧 body-enter 目标替换、隐藏和排队删除、140/145/150px 与范围外边界、零/非法查询半径、章节出口优先级、手动/自动拾取、面板/死亡/加载/转场状态。

专项把 Player 定位到远离 authored 物件的位置，使用无拾取副作用的 Area 隔离“选择和派发使用哪个目标”；不把这些夹具称作自然探索或领奖流程。派发调用真实 `_try_interact`，路牌调用生产 `_process`。奖励、保存、机关和退出通过额外的既有正式回归覆盖。

Godot 4.6.1 / llvmpipe 验证结果：

- `world_wayfinding` **57/0**，其中新增目标专项 **32/0**。
- `world_interaction_safety` **24/0**。
- `world_route_access` **553/0**（原有定位夹具）。

反向恢复旧路牌条件（140px、独立范围/状态判断）后，专项检出 **5 处失败**，包括边缘距离、死亡和待切区提示；恢复后复验。变异未保留。`world_upgrade` 405/0、`obsidian_experience` 197/0；npm/campaign、两轮严格资源导入和差异检查通过。远距预筛补入后，路牌 57/0、路线访问 553/0 再次通过；该预筛不改变无候选参数的操作派发路径。

本批统一“当前可选目标”和提示，不新增穿墙视线判定、不重排 authored 路线，也不改变奖励或保存格式。既有回归中的 ObjectDB 退出警告保留，完整远端 CI 单独报告。

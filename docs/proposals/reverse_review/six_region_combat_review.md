## 证据边界与复现

本环境无图形显示服务；运行真实 Godot headless 物理与普通 Input 动作，未获得实际渲染截图，不能评价颜色对比、动画辨识或陌生玩家体验。静态地图不是实玩截图。各章均从 `Main.tscn` 独立加载；其 `world_mode=false` 不应用契印构筑，实际治疗0.85秒、命中回能15，不能外推为世界模式参数。**不是 World.tscn 连续游历，不证明带伤自然六区全通或 Boss 击败**。每次 2400 个固定 60 Hz 物理帧（约40秒模拟时间），每章每模式一个样本；不提供胜率或平衡统计显著性。

- `entry`：原始入口、初始5HP、0能量。前5秒静置；随后持续向右，每1.5秒按跳跃0.3秒，每0.75秒按攻击。没有寻路、交互、地图阅读、升降笼、治疗、闪避或拾取策略；死亡和重生自然发生。是可复现的**有限输入探针**，不是合理玩家完整操作。
- `boss`：直接调用 `_spawn_boss()` 与 `_set_boss_arena_locked(true)`，仅一次将角色定位在 Boss 左200px、上20px；玩家生命／能量不修改，不攻击、不移动，每2秒尝试治疗。跳过正常探索、解锁与门交互。死亡按游戏原有机制返回入口。
- `boss_phase2`：在上述人工遭遇中，额外把 Boss HP 设置为最大值一半以触发二阶段。此变更仅发生于隔离工程的内存，是**阶段夹具**，绝不是自然打进二阶段。
- 所有计时来自帧号，不等于真实墙钟；第一个 `hp` 记录是初始状态。首轮导入未完成的试跑与未锁门的探索性 Boss 试跑不作为本文结果；最终 Boss JSONL 已被锁门试验覆盖。

## 问题与试验建议（由末章回推）

### R06-01 · P1候选：冠肩陷阱造成反复重入扣血，缺少可学习的触发周期

**观测事实：** CH06 首轮在9.700、10.517、11.350秒，x≈3693–3703，连续从5HP掉到2HP；12.750秒剩1HP；15.900秒在(4561,1180)死亡。后两轮同一输入重复同样序列。配置 `ch06_hazard_shell_clapper` 是 `[3705,830,120,22]`、伤害1；`ch06_hazard_rain_floor` 是 `[4490,1174,120,22]`、伤害1。日志只记录血量变化，**没有伤害来源信号**；冠肩归因由位置、配置和代码共同支持，仍应做来源插桩复核。

**静态事实：** `main_level.gd::_hazard`（约3666行）为这些不同命名陷阱统一创建常驻 Area2D；`_on_hazard_body_entered`（约4401行）立即 `take_damage(..., false)`。该路径没有坠落前摇、重装、一次触发销毁或陷阱独立伤害冷却。

**推断：** 击退退出／重入同一碰撞区可能使玩家在尚未读懂“坠钟舌”前反复交税。不能从 headless 断言贴图不可读，也不能断言所有伤害都由同一陷阱造成。

**建议试验值：** 保持伤害1，先测试坠落前摇0.5–0.8秒、重装1.8–2.4秒；同一陷阱对同一角色重入冷却1.2–1.6秒，或本次通过只触发一次。CH01、CH05同类陷阱同步复核，不先增减角色总HP。

**人工验收：** 以有受伤反馈的正常角色从入口连续玩到雨渠回声池；分别不跳、短跳、受击后松方向、反向脱离，录像逐帧核对触发／落下／伤害帧；每路线至少5次，确认脱离手段与提示一致。仅由运行时负责者决定是否实现。

### R05-01 / R03-01 · P2待人工确认：入口常规前进方案在局部高度差持续受阻

**观测事实：** CH05约14秒起，持续右行＋周期跳跃仍停在x≈1711，直到40秒；CH03对应末端x≈1996。CH05附近 `base_cart_stand=[1450,2708,240,30]`、`base_run_b=[1800,2772,380,38]`；CH03附近 `spine_tall_shelf=[2010,2548,190,28]`、`candle_rise_a=[1850,2442,150,24]`。实际碰撞也可能来自生成洞体，不能只凭平台矩形定根因。

**推断：** 跳跃时机、顶棚净空、地形接缝或应当向支路转向中的至少一项与该输入序列不匹配。**没有证据证明软锁／不可达**；探针不会读路标或掉头。

**建议试验值：** 先保持碰撞不变，人工测起跳点±40/80px与短／长按跳跃；若确认为净空／接缝问题，再试落脚宽≥160–200px、连续基础跳高差≤110–130px或提示前置180–260px。若原路本来应转向，优先明确近场路线线索，不为了盲目右行强改关卡。

**人工验收：** 从原入口到目标位置正常行走，有目的地测试向左重新助跑、停止攻击再起跳与支路；记录是否需要后续章节能力。至少两位未看解法者各试一次，但不可把本探针叫作“陌生玩家测试”。

### R04-01 · P2试验：根网与根刺叠加的治疗机会需要真实录像

**观测事实：** CH04探针实际触发 `vine_roots`、`cage_net`、`cage_pounce`，两轮均死亡。仅凭日志不能证明它们同时命中或组成必死连段。Boss `boss_bishop_roots` 的前摇0.9秒、独立落点警告0.68秒、恢复0.5秒；`boss_bishop_cage` 二阶段前摇1.15秒、恢复1.2秒。

**建议试验值：** 保留强招识别度与伤害1，优先试同一小遭遇仅一个控制技能同时起手，或控制结束后0.35–0.5秒不再施加下一次控制。Boss根线后的真正安全地面窗口目标1.0–1.2秒，测量应计入残留危险区，而非只看 `recover`。

**人工验收：** 录下移动受限→受击→治疗取消的时间线；分别用近战、跳过、先杀远程的策略进入遭遇，判断是否确需干预。

### R02-01 · P2调参候选：第二章耐久高峰早于第三至五章

**静态事实：** CH02 Boss26HP、15常规敌、11陷阱；CH03–05 Boss各22HP、14敌、6陷阱；CH06 Boss28HP。CH02不是仅换皮的低压力过渡段；探针确实遭遇三类敌招并死亡一次。

**推断：** 在未计装备、成长、路线跳过率与招式暴露窗口时，CH02可能出现早期耐久峰值；**不能仅凭HP认定难度倒挂**。

**建议试验值：** 对比现值26与22–24HP，保持招式不变；把目标设为正常成长条件下可攻击机会6–9次，而不是按章节强制等差涨血。取得实测有效DPS后再决定是否降低；无DPS证据时不自动改配置。

### R01-01 · P2教学复核：起始章基本操作与地形跌落压力同场出现

**观测事实：** CH01前5秒安全；开始移动约4秒后掉血。首轮掉血位置y≈4240，明显低于入口y3360；19.267秒在y≈5500死亡。后一次重生的轨迹不同，说明同一周期输入的相位对落脚有影响。

**建议试验值：** 检查从入口到首个小怪是否提供一个长220–300px、无陷阱的稳定停步／出招区；若已有，先改提示而非新增平台。首敌 `larva_snap` 配置前摇0.25秒，建议新手首遇单独试0.35–0.45秒，后续同类保留快招，避免全局钝化。

**人工验收：** 不提供连招提示，观察初次游玩者是否看清下层安全落脚点；分别用不攻击、单次攻击、短跳记录受伤原因。不要把探针不看地形的跌落直接归责于关卡。

## 全章治疗与预警共通检查

### H-01 · P2候选：恢复帧不等于治疗安全窗，初始能量不支持被动挨打换治疗

**本次独立章节实测参数与世界模式生效参数不同。** 原18份 `start` 日志记录的0.85秒是 `Main.tscn` 真实玩家实例值，不是仅抄导出默认，但不能据此推断 World 的构筑治疗速度。

新增 `build_parameter_probe.gd` 在隔离用户目录运行真实场景初始化：Main实例得到 `world_mode=false / crest=not_applied / heal_duration=0.85`；World实例得到 `world_mode=true / crest=crimson / heal_duration=0.8`。再以明确标注的无被动装备夹具切换三契印，核对实际玩家属性。完整输出在 `evidence/build_parameter_probe.txt`，机器记录在 `build_parameters.json`。这是新增参数核对，不混入原18次战斗观察，也不是自然取得另两契印。

覆盖链：`World.tscn` 设置 `world_mode=true`；`main_level.gd::_spawn_player`（约2785–2796行）在世界模式调用 `_sync_player_build`；后者（约5655–5663行）对非世界模式直接返回，世界模式则调用 `build_system.profile()` → `player.apply_build_stats(profile)`。`build_catalog.json::crests` 三契印基础治疗均0.8秒／60能量；`player_controller.gd::apply_build_stats`（约838–840行）覆盖导出默认。被动装备仍可通过 `build_system.gd::profile` 修饰治疗时间，以下仅为无被动基础值。

|---|---:|---|---:|---:|

均为5HP、受伤回能10。`_try_heal`（约778行）要求站地、能行动且足额；`_update_heal` 遇移动／跳跃／离地中断；三契印基础中断消耗比例均1.0，可受被动／构筑影响。

在0能量且不攻击的本次Boss夹具中，非致死受击最多4次，只获得40，低于成本60；因此没有治疗事件是预期行为，不能声称“治疗键坏了”或“Boss完全不给治疗”。该被动挨打推导在上述世界基础构筑也成立，但**命中回能循环不同，不能把Main的4次命中一治疗泛化到所有契印**。

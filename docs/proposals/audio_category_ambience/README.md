# S03 六区环境声与空间混音审阅包

本包是独立审阅提案，未接入 Godot、运行数据、地图声源或既有总线。24 个原创 OGG/Vorbis 素材，48 kHz：每区一条 24 秒立体声床、一条 8 秒单声道设施循环、两条 3.5 秒单声道稀疏事件。无 NPC、导航或交互提示。人工实听状态全部为 `pending`；机器指标不能证明听感优秀或真实设备上无可闻接缝。

| 区域 | 持续环境床的主要构造 | 可定位设施 | 单次事件 |
|---|---|---|---|
| ch01 苔钟庭 | 不规则衰减滴水模态、石腔与湿润底流 | 蓄水石槽 | 叶面滴落、苔石细砾 |
| ch02 铸雨渠 | 水流、转子低频、非谐波机械脉冲 | 排水泵 | 泄压余气、渠底金属沉落 |
| ch03 盐白书库 | 有包络的纸页摩擦颗粒与盐尘微粒 | 通风书架 | 散页翻卷、盐晶微坠 |
| ch04 断弦温室 | 玻璃分音、慢根系应力与低频挠曲 | 根系玻璃管 | 玻璃应力轻鸣、根鞘松脱 |
| ch05 黑曜巡礼道 | 多周期风涡与调频风口哨音 | 裂谷风口 | 岩片滚落、侧孔短阵风 |
| ch06 寂冠核心 | 非齐奏空腔共振、缓慢压力包络 | 封闭银线谐振腔 | 远腔闷响、压力膜回缩 |

六区通过不同激励、事件节奏、衰减和模态组织区分，并非同一段噪声更换滤波。设施循环与所属区域共享材质，但保持 mono；床是 stereo，不应将它当作定位音源。合成材质是物理印象，不是实地录音。

## 空间建议

`assets/proposals/audio_category_ambience/mix_profiles.json` 是独立 WebAudio 审阅器的数据建议。距离用抽象米；既有 Godot 为二维像素世界，未来接入需单独确定比例与锚点。near 内保持音量，near 至 far 线性衰减振幅，far 外静音；等功率左右声像，遮挡叠加低通及负增益。建议参数变更至少 80 ms 平滑，避免拖动审阅器时阶跃。

| 区域 | near / far（米） | 遮挡 LPF / 增益 | 混响衰减 / wet | 事件间隔（秒） |
|---|---:|---:|---:|---:|
| ch01 | 2 / 18 | 1200 Hz / −8 dB | 1.4 s / 0.16 | 45–120 |
| ch02 | 3 / 28 | 850 Hz / −10 dB | 2.2 s / 0.13 | 48–124 |
| ch03 | 1.5 / 12 | 1800 Hz / −7 dB | 0.7 s / 0.08 | 51–128 |
| ch04 | 2 / 20 | 1400 Hz / −8 dB | 1.8 s / 0.19 | 54–132 |
| ch05 | 4 / 36 | 700 Hz / −11 dB | 2.6 s / 0.11 | 57–136 |
| ch06 | 3 / 26 | 600 Hz / −12 dB | 4.2 s / 0.24 | 60–140 |

床 −3 dB、设施 −7 dB、事件 −9 dB 为绝对 cue 播放增益，manifest 和 profile 的重复值不可相加。素材自身已预留峰值空间。若未来走现有 Ambience 总线，还需单独校准其默认 −14 dB；当前审阅器不应假设已套用运行总线。每区事件最大 1 声部，无立即重复；常态床+设施+事件最多 3 声部，跨区交叉淡化时总上限 4，先停事件再交叉淡化两组循环 2.5 秒。预警仅驱动环境混音的 −9 dB duck，45 ms attack、250 ms hold、900 ms release，同时暂停新环境事件；预警自身不在此包。

## 循环与复现

循环起点为 sample 0、终点为 1,152,000（床）或 384,000（设施），终点为 exclusive。设定播放器的真正 loop，而非 finished 后重启。周期频率和环形事件保持完整周期；首尾 80 ms 余弦平方端点整形抑制有损编码边界点击，无插入静音段，代价是极短的边界能量凹口。是否可闻必须人工审阅。初次播放及停止另做短淡入淡出。

在仓库根目录运行：

```bash
python tools/proposals/audio_category_ambience/build.py
python tools/proposals/audio_category_ambience/validate.py
```

依赖 Python 3、NumPy、SciPy、带 libvorbis 的 ffmpeg/ffprobe。seed 随每个 item 写入 manifest。使用 bitexact 编码控制 OGG serial 和元数据；同版本工具链两次完整生成的 OGG、manifest、mix_profiles SHA-256 都记录在 `validation.json`。跨工具链版本不承诺压缩文件字节一致。

机器验收对最终 OGG 解码，检查有限值、48 kHz、声道、精确样本数、4× 重采样估计 true peak < −8 dBTP、循环首尾差 < −55 dBFS、首尾 5 ms 峰值 < −35 dBFS，报告 RMS、EBU R128 integrated LUFS、内部差分统计及文件大小。事件极短，LUFS 只作相对参考，不能与长床按同一个听感目标判定。数据及第二次重建证据在 `validation.json`。未运行游戏听音，未宣称人工实听。

## 只读设计依据

- `godot/scripts/audio_director.gd`：现有全局 24 声部、Ambience 默认总线、环境床与稀疏事件调度，只作兼容设计背景。
- `docs/spec/20260726160400000_音效与音乐设计规格.md`：六区材质、环境与音乐分离及混音原则。
- `godot/data/chapters/` 六区叙事数据：区域名称与设施材质背景。

本包未改上述文件，未改既有 CI/验证入口。独立脚本只生成与验证提案目录。

## 当前事实与禁止提前承诺

基线的 `main_level.gd::_refresh_map_overlay` 直接绘制当前房间与玩家位置；房间探索流程维护已访问房间。未发现售图门禁、永久绘针与装备罗盘机制；也不存在修订方案引用的 `cartography_runtime.gd`、`pilgrimage_cartography.gd`。修订方案对PR17的证据不等同这个main基线，不能用其“最新已修复”表述覆盖本次读取结果。

因此，`map.*` 全部阻断。特别是“买图后才开地图”“坐钟龛才补绘”“没罗盘不定位”“错过售图者可补购”，都不能在当前版本对玩家说。独立导航辅助只有确定覆盖定位装备规则时，才能用`map.assist`。默认模式与辅助模式文案互斥。

六区指定售图者应从实际购图分支读取，而本基线没有绑定表。升台绘图师身份明确；其余以锈泵修女、封蜡档案员、蜂蜡商人、黑曜引路人、六印守望者作**未批准声音草案**，不宣称他们已售图，不虚构受托历史。若正式售图ID不同，必须重写人物声音，不可只换姓名。

## 人物声音约束

学徒用针、线头、衣服讲保存；渠童只讲记得的父亲与下工钟；柳用铆钉的手感确认人；书记用原件、核对、立案表露恐惧；叶从目录腔转为承担亲见责任。园丁用根与记性讲照料，囚徒先确认能否站稳，歌者维护歌声原意。修女以灯记路，逃旗手以军号与名字表现强制召回。守望者只清点，不代替玩家判善恶；钟舌自称“我这口钟”，终局代价直说。

主角不新增演说。已有`response`中的递线、收军令和转灯动作保持；本包只缩短指定NPC句子，不清掉其余行的战斗限制教学，尤其不把格挡、盐雾、绊线钉等写成万能护身能力。

## 文本预算、剧透与接入契约

字符预算按Unicode字符数，含标点与占位符源码：任务目标20，其余通常48，地图模板52。它是编辑预算，不是像素适配证据。动态`{price}`、`{missing}`、`{count}`替换后应检查大数值与字体；目标为两行短对白，实际换行由UI决定，不在文本中硬插换行。

剧透0为当前环境与工具用法；1为当地人物和已接委托；2为契约原文、六证词和结局代价。状态前置是曝光上限，不能把一条有`testimony_04`条件的歌者句子移到初遇。现有`states`按先匹配选中，候选标注的条件必须连同原顺序看；空条件不等于永远优先。

所有精确映射指针只适用于基线，合并前按NPC/state ID或quest ID重新定位，并核对`original_text`仍一致；不要依赖数组序号直接覆盖新版。只替换所指字段，不覆盖整个NPC或任务对象，不变更grant/reward/迁移字段。任何奖励与完成反馈均在对白末行提交成功后显示；中断提示不得产生完成或失败flag。

未提供定时失败、材料永久丢失、护送者死亡等反馈，因为五条当前任务没有这种已核实失败机制。缺物品、缺能力、中断是可恢复待办；显示具体下一步，不把可选支线变成通关门票。最终结局文案先展示后果再确认，确认动作与存档由拥有终局代码的集成者处理。

## 短简介

《绯线巡礼》是一款开发中的原创 2D 银河恶魔城原型。在洞道与铜钟之间寻找被抹去的名字，获得攀壁、双线跃等能力，回访旧路；搭配契印、技能与战具，尝试自己的战斗方式。

## 长简介

把名字带回来。

《绯线巡礼》以针、线、铜钟与失名证词展开一段探索旅程。这款开发中的原创 2D 银河恶魔城原型，已接入六区洞穴地图、能力回访与契印构筑系统，仍在持续打磨房间、战斗和视听表现。

从苔钟庭踏入铸雨渠，再前往盐白书库。取得攀壁与双线跃后，回到曾经受阻的旧路，打开新的通道。沿途寻找捷径，乘坐物理升降笼，在地图和旅记中查看探索与证词记录。

在缝名、司铸与校录三种契印之间选择打法。从六个技能和四种战具中各装备两个，再以铭饰调整构筑。前往钟龛整理配装，也可以在练针区熟悉技能动作。

与旅途中的人物交谈，推进跨越前三地区的“把名字带回来”支线，收取失名证词。故事与探索仍在成长：当前可运行内容不代表最终成品，六区自然带伤全流程、完整手柄体验和混音听感仍待人工验收。

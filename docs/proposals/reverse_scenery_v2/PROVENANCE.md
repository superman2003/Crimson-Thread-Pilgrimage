# 著作来源与参考范围

18 份 SVG 的路径、布局、渐变、设施图形均为本次提案用 Python 代码从零绘制。6 张 PNG 由这些 SVG 栅格化合成；没有下载、描摹、嵌入或重绘第三方素材，也没有使用图像生成工具。没有第三方字体或外链内容。固定 seed 和生成源码随包交付。

项目内主题及视觉参考（只读）：

- `docs/spec/20260619152048209_六章丝之歌级大体量地图蓝图规格.md`：六区主题及设施背景。使用既定世界观，没有复制地图布局。
- `godot/data/demo_ch01_moss_bell_court.json` 至 `demo_ch06_silent_crown_core.json`：现行区域身份和命名。
- `godot/data/world_narrative.json`：雨铃计时、排水泵、删名契约、母株、巡礼与镇潮钟网的叙事语义。
- `godot/data/original_world_art_designs.json`：苔绿、铜锈、盐白、银蓝与少量绯红的项目既有配色方向。
- `artifacts/world_material/six_regions.jpg`：六区现有实机画面的景深、视觉密度和色温；本包没有提取其中像素。

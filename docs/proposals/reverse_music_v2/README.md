# 六城回声：六区探索 / Boss 音乐提案 v2

本批新增 **12 首原创程序合成音乐**，按 CH06→CH01 交付，每区探索与 Boss 各一首。48 kHz、双声道、OGG Vorbis，完整循环 32–45.52 秒。不是上批短音效的延长版。未改动运行脚本、运行数据、验证系统或 CI；没有声称已接入游戏。**技术检查与人工实听验收是两件事：本批仅完成可重建生成及技术检查，人工实听、真实游戏混音和长时疲劳验收仍待进行。**

## 文件与使用边界

- `assets/proposals/reverse_music_v2/manifest.json`：根预览页统一 schema，`file` 均相对于包目录。
- `assets/proposals/reverse_music_v2/audio/`：12 个真正的 OGG 文件，包内 `.gitattributes` 关闭 LFS。
- `tools/proposals/reverse_music_v2/build.py`：完整作曲事件、音色合成、编码和技术检测生成器。
- `tools/proposals/reverse_music_v2/requirements.txt`：Python 依赖锁定。
- 本目录 `score_events.json`：每个音符的 MIDI、起始小节/拍、持续拍数、音色、声像与幅度。
- 本目录 `validation.json` / `VALIDATION.md`：解码后检测结果和解释。
- 包内 `PROVENANCE.md` / `LICENSE.txt`：来源、制作与授权说明。

读取过基线 `6544cceff5e812b5295b97204d7c55a4b8933de9` 的 `godot/data/campaign_chapters.json`、`godot/data/audio_visual_manifest.json`、`docs/spec/20260726160400000_音效与音乐设计规格.md` 和 `tools/generate_music_pack.py`。沿用项目缄钟/绯线动机的身份，在新谱中写入各区独立旋律、和声、节奏和音色。没有读取或采样旧音频。manifest 区名采用本基线 campaign 名称，同时记录设计稿别名，避免“无声王冠/寂冠核心”“巡礼道/巡礼路”混淆。

四段短曲式用于候选比较，Boss 是独立完整曲目，不是可直接叠加的 combat stem。为同区切换对齐，本批探索/Boss 使用同 BPM 和同拍号网格；**没有复刻设计稿长篇 88–128 秒、全部 Boss 独立速度/转调、实时招式同步和终战三乐章**。CH05 Boss 的三拍来自叠置节奏，主时间轴仍是 4/4；CH06 的 48 BPM 仅是编辑与切换参考，不代表探索有可闻脉冲。短循环尚不能替代长时间探索最终配乐。

## 循环与同区切换

音符连同释放尾音按样本索引取模叠加；循环末尾发声的尾部实际回卷到开头。空间反射用圆周延迟，频谱处理也使用循环边界。**没有整首首尾大淡出、没有把持续声部尾音裁断后冒充无缝。** 只有每个乐器正常的起音/释放包络。

每对曲目采样数一致，manifest 同时给出每小节起点、四个等结构分句边界、`loop_start_sample=0` 和 `loop_end_sample_exclusive`。分句如下（从零计时）：

| 区域 | 分句边界秒（含循环终点） | 网格 |
|---|---|---|
| CH06 | 0, 10, 20, 30, 40 | 每 2 小节 |
| CH05 | 0, 9.6, 19.2, 28.8, 38.4 | 每 4 小节 |
| CH04 | 0, 11.379310, 22.758621, 34.137931, 45.517241 | 每 2 小节（5+6 拍） |
| CH03 | 0, 8, 16, 24, 32 | 每 2 小节 |
| CH02 | 0, 10.434783, 20.869565, 31.304348, 41.739130 | 每 4 小节 |
| CH01 | 0, 10, 20, 30, 40 | 每 4 小节（6/8） |

未来接入时建议以共同样本时钟保留相位，等待下一分句边界，目标曲 seek 到同一分句起点，做约一小节的等功率交叉淡化。需要紧急进入 Boss 时可在下一小节开始同相位切换。OGG 的 LOOPSTART/LOOPEND 标签仅记录意图，不能假设所有引擎自动采纳，仍须验证导入器。两首都含完整和声，不应作为两条满音量持续叠放的 stem。

这只是**接入建议**：没有添加任何运行时切换逻辑，也没有验证 Godot seek 精度、同步调度或移动设备输出延迟。各区之间也不能按本表推断互相同相位。

## 增益与提示音空间

普通探索目标约 -24 LUFS，普通 Boss 约 -21 LUFS；CH06 分别约 -29 / -26 LUFS。交付声压并不等于游戏总线最终声压。建议试听起点：探索再降 **3 dB**，Boss 再降 **5 dB**；交叉淡化重叠期再留约 **3 dB** 余量。剧情对白或高优先级危险提示出现时，未来接入可暂降音乐 4–8 dB，之后约 0.3–0.6 秒恢复；最终量应由实际语音/提示响度决定。

合成阶段约 2.9 kHz 的宽频段温和减弱，低于 35 Hz 清理，约 6.2 kHz 以上柔和衰减。打击声仅 CH01/02/05 少量出现；金属敲击低于旋律、刷鼓窄带且弱。CH03/04/06 没有鼓组。这里的合成元音不是对白或真人歌唱；仍须用游戏实际人声、敌人预警、UI 提示共同实听，技术报告不能证明其永不掩蔽。

## 重建

```bash
python -m pip install -r tools/proposals/reverse_music_v2/requirements.txt
python tools/proposals/reverse_music_v2/build.py
```

环境：Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0；FFmpeg 及 libvorbis 版本见 `validation.json`。全局 seed `2026101406`；单曲 seed 为 `2026101406 + chapter_number * 100 + is_boss`。所有音符与和声由固定代码明示，无外部模型、网络或采样库。中间浮点 PCM/WAV 写入系统临时目录并自动删除，不提交中间 WAV。

以 `-fflags +bitexact -flags:a +bitexact`、固定 OGG serial offset、Vorbis `-q:a 0` 编码。相同工具链重复运行应得到相同文件；不同 FFmpeg/libvorbis/NumPy 版本允许编码字节或浮点舍入差异，应重新跑检测。生成器仅写三个 proposal 目录中的包/报告；不会覆盖任何运行音频。

## 攻击线条修正

用户再次指出攻击仍有线条。检查发现换人物画稿未清掉程序刀带，以及重击旧折线回退、技能提示层的额外线条；共鸣和相位还会重复叠加程序圆圈。本批删除普攻刀带模块、旧武器扫带绘制类、折线／圆圈回退和相关纹理拉伸辅助函数；技能阶段提示保留声音，停止生成攻击装饰。共鸣与相位保留各自已交付的素材。重斩、投射、控制和命中素材继续使用现有独立画稿。不可格挡危险提示保留原层级与预算。

用户随后指出缚线陷阱还有圆圈。已删除素材外额外绘制的双层圆弧，同时取消原像素测试对圆圈区域的跳过，改为完整区域逐像素对照源素材；陷阱的原 36px 作用距离、立即生效、盐记消耗与持续时间保留。

控制器删除四个展示工厂、五个函数中的展示调用；其余 120 个函数文本相对同步后的 PR 基线相同。Player 场景、碰撞体与素材加载入口不变。伤害、费用、有效窗口、命中回能、下劈反弹、打断与取消由相关真实入口回归验证。测试中原先要求程序刀带存在的断言改为要求其不存在；命中、声音、震动、危险层级和资源预算断言保留。

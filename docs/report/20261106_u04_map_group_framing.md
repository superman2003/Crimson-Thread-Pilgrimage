# U04：按已知层位和筛选结果框取地图

基于 main `2ceea261b137ebb87a59bde99776900310eb35d2`，保留已合入的设置页分帧与发布下载。本批独立于环境声 PR #547，提交只含地图差量。

## 玩家操作

在地图的「已知地点目录」中选择层位、区域、类型或搜索词，然后选择新增「框取当前筛选」，让这些已知地点一起进入视野。原来的单处查看继续使用。

- 本区域的结果使用区域图；含外区结果时使用世界图。
- 框取使用当前目录中已购且已补绘记录的锚点。贯层长井只使用已知段的锚点，不用其尚未补绘的完整几何扩大视野。
- 请求只传条目身份，运行时重新查当前公开目录。任何一处已经失效，就拒绝整组，并在目录中说明原因，保持原视野。
- 成功后关闭目录回到地图；没有结果时按钮不可用。新动作与原「查看此处」并排，使用原生键盘/手柄焦点和确认。
- 不移动角色、不自动购图/补绘、不解锁道路，也不添加玩家定位。存档被暂停写入时仍可查看。

## 实现与边界

`map_group_framing.gd` 按键重建当前公开条目，并将每处已知锚点投影到原来的固定纸面。`survey_map_view.frame_bounds` 计算可容纳整组的缩放/中心，沿用原 1–4 倍限制和纸面边界，清除旧拖动/摇杆平移输入；无效几何保持原相机状态。

目录第三个回调为可选参数，旧的两个参数调用不会沿用上次打开的分组动作。正式入口以原宿主/地图的弱引用检查生命周期；地图关闭、换区或宿主释放后，旧回调不执行。

只改变地图视野；不隐藏其它层位、不更改固定世界布局、地图比例或已知轮廓。查看整组不表示地点之间已经可以通行。最多处理 512 个身份，超出时保留目录并给出失败原因。

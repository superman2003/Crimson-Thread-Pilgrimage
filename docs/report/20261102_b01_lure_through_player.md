# B01／E02：玩家站在敌人与诱铃之间时，诱铃不再被玩家身体挡住

2026-11-02。B03（#502）查出光束被玩家身体截断后，逐个检查了代码里所有层 1（地形层）射线。敌人视线 `_has_line_of_sight` 早已排除玩家与自身（注释写明“玩家/敌人受击框不能遮挡视线”），但回响诱铃的两条射线没有：

- `investigate_lure`：敌人到诱铃落点的可见判定；
- `_update_patrol_or_aggro`：被诱导时向落点前进的前方 24px 探测。

正式 `Player` 的 `CharacterBody2D` 也在层 1。诱铃说明写的是“把会走动的敌人引开”，最自然的用法之一是把诱铃丢到自己身后、让敌人从身旁走过去——这时玩家正好站在敌人与落点之间，第一条射线被玩家身体挡住，敌人直接无视诱铃；即使已被诱导，走到玩家身前也会被第二条射线当成墙停下。

## 改动

两条诱铃射线都用 #502 的 `enemy_attack_effect.player_bodies()` 排除玩家刚体；地形、岩体、静态体照常遮挡与阻挡，与视线规则一致。

## 验证

`seal_combat` 新增一项：正式 `Player.tscn` 站在敌人与落点之间，敌人仍接受诱铃，且向落点前进时不会停在玩家身前。去掉修复时这一项准确失败，修复后 195 项通过（软件 GL）。`enemy_tactical_roles`、`enemy_ai_behavior`、`enemy_visibility`、`optional_challenges` 通过。

## 边界

只改诱铃的两条射线。敌人本体仍是穿过玩家的 Area2D（接触伤害规则不变）；诱铃范围、时长与 Boss 免疫不变。

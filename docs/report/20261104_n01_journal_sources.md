# N01／N03／U05：从派生旅记回看已知来源

日期：2026-11-04。接续证词出处、遗迹自述与结局回访，让提示与原始记录之间可以直接来回核对。

## 玩家流程

选择已解锁的遗迹自述，或结局后的可选回访指南。右侧原来的旅记操作位在确有来源时显示“回看来源”。打开后可用列表、“上一条”和“下一条”阅读；关闭返回原文。原分类、搜索、排序、未读／收藏筛选和滚动位置保持不变。

| 来源入口 | 可回看的内容 | 可见边界 |
|---|---|---|
| 六条本区遗迹自述 | 已观察的设施原文与独立取得的本区证词 | 缺任意来源时自述与入口均不成立 |
| 六条跨区遗迹自述 | 该条实际引用的两处设施原文 | 不列出相邻城市或尚未观察的物件 |
| 原始证词的已解锁对读 | 当前持有且参与该段对读的另一份证词 | 已知标题不替代持有；不把本条再次计作独立证据 |
| 结局后回访指南 | 玩家已接或完成的原委托详情 | 不列出未接受委托；联系人仍跟随正式迁移 |

窗口显示现有生产旅记的完整公开正文，不另写摘要，也不把读过的提示变成新证词。原始记录不再产生递归来源入口。

## 输入与恢复

- 原位按钮保持现有背包操作；旅记之外仍是原来的物品标记。
- 窗口首次使用才构建，正文支持选择复制、普通文本显示和现有无障碍字号。
- 下拉选择、前后按钮与返回按钮均可获得焦点，沿用原生界面的键盘／手柄导航。
- 注册现有模态输入保护；查看期间地图与游戏动作不会穿透到原界面。
- 关闭、切换记录、切换物品分类、关闭背包、改变存档范围或阅读会话都会撤销旧窗口。
- 每次选择都重新解析真实来源。物品或观察条件撤销后，旧快照不能继续打开对应内容。
- 只读来源不自动标为已读、不收藏，不调用世界保存、奖励、交谈完成或位置修改。

## 验证

十二条最小来源组合逐项匹配原始身份、顺序、标题和正文；分别遍历全部六位观察与六位证词组合，并遍历三结局下九十六种委托接受组合。另对六份证词 × 六位持有组合共三百八十四种情况核对对读伙伴去重、排除自己与仅知标题时的隐藏。覆盖损坏库存、删除前置、未知来源、普通记录、返回副本隔离。

正式 World 回归使用明确标注的已知来源夹具，点击生产按钮，核对实际窗口、字号、前后环绕、下拉选择、输入锁、返回焦点、筛选与滚动保持。随后撤销物品、改变存档范围、推进会话代数、切换记录与关闭背包，确认旧窗口都失效。全程比较游戏旗标、物品、货币、存档字节和显式阅读／收藏偏好。

这些夹具验证阅读与失效边界，不代表六区自然跑图或实体手柄验收；T04 的自然回访理解仍保留。

## 交接契约

- 冷或过期的路线清单使用loader唯一配置读取worker读取/解析；解析结果私有持有，使用既有显式栈复制器按512边分片交接，票据、loader代数和文件时间戳都有效才发布。
- 首区及存档恢复的地区路径等待清单发布后解析；活跃World的validator、portal/passage、prefetch和atlas使用cache-only查询，不因缓存未就绪同步读取正文兜底。
- 后台刷新让权于前台；丢弃的worker自然结束后才可重新申请唯一票据，取消不在主线程阻塞等待worker。
- 已准入通道保留目的配置路径。行走期间清单失效仍能在终点启动前台刷新，再按最新路线代际校验；构建及最终交接前发生版本变化则拒绝发布目标并恢复来源。
- atlas和邻区几何/玩法缓存按路线代际失效；待退休对象保留所有权，继续遵守原每帧释放和容量约束。

清单交接按每帧至多512边推进；既有邻区2ms预算是下一操作准入窗口，二者不是同一门禁。复制批、字典keys、文件元数据检查等不可抢占。不承诺目标硬件FPS、单帧硬时限或完整W00b2b完成；遗留同步兼容API与旧cached_data整表复制仍保留。

## 现代组合修复与新增验证

静态组合审查发现：前台冷清单读取/交接窗口未轮询短按Esc；atlas地形直接缓存命中可绕过代际检查且后台刷新后地图未自动重绘；passage active期间不推进prefetch，终点更新路线代际后可能在下一次step前取用旧预建对象。针对这些入口做最小修复；五类借用入口包含passage落地支撑的纯几何借用，同代支持保留，过期仅入退休队列。此外，空闲worker启动失败不再被误当作票据争用而无限等待，启动错误及原槽位重试入口保留；已接受票据仍只能由原owner消费。新增专项验证真实取消、缓存拒绝采用、预算退休、地图重绘与确定性启动失败，保留原存档/奖励提交边界。

新增两个全程通道失效行走套分别覆盖前三条和后两条的双向，共10次实际Input/物理行走，使用384×216软件GL正常绘制、固定60Hz模拟；原速度和合法终点不改。能力门初始状态是明确组件夹具，不叫自然六区通关。既有140项网络套和15处正常绘制像素探针保留；原网络套的关闭绘制循环模式只作为物理/状态证据。

另有独立组合套覆盖预检、构建与最终交接的路线代际变化、取消/重试/退树、现代叙事与保存隔离、几何/玩法旧缓存直接取用以及atlas。所有单套仍保持原180秒严格门禁，退出非零、引擎错误或缺完成标记均失败。

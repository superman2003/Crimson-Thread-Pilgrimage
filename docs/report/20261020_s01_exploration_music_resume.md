# S01：跨区回访的探索音乐续播

日期：2026-10-20。对应台账 S01“主题动机与连续转场听感”的连续播放子项；独立基于 main 2571f891。

探索曲原来只在同一个 AudioDirector 中避免重复播放，替换导演或离开再回到区域会从头开始。现在离开曲目或场景前保存播放秒数，同一运行中回访按该曲目的位置续播，保留原 0.8 秒淡入。最多保留 8 个纯数值记录，不缓存新的音频资源，也不写入旅途存档。

同曲目的暂停状态也算已在播放：Boss/钟龛期间重复应用区域状态不会解除暂停或从头开始。跨场景交接使用实例租约，旧导演晚退出不能覆盖新导演的进度。开始新旅途会清空记录并提升代数，退休场景不能再把旧旅途进度写回来。不同曲目仍各自独立，不改 Boss 相位、战斗层或钟龛曲的安排。

新增 music_phrase_resume_validation，经默认 audio_retirement 入口运行。用原生 AudioStreamPlayer 验证非零 seek、暂停重入、两首曲互相回访、重叠场景交接、迟到退休、缓存上限和新旅途隔离；夹具等待真实混音并释放播放。音色与跨区转场的人工实听仍待验收，本批不把 S01 整项关闭。

占用 audio_director.gd、main_level.gd 的新旅途入口、audio_retirement_validation.gd 与新专项；逐套结果见 artifacts/s01_exploration_music_resume/verification.json。本报告是独立台账补记，不改其它 PR 的共享进度段落。

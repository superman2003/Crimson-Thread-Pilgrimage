# U05：旅记长文翻页与会话阅读位置

新增八批第 5 批。旅记详情支持 PgUp／PgDn 和手柄 LB／RB 翻页，Home／End 到首尾；不改变所选条目。复用原来在旅记页禁用的“钉在旅记”按钮显示阅读提示，物品页仍显示原钉记操作。

按记录类型＋ID 保存当前 UI 会话的滚动位置，切换记录、重复焦点和关闭／重开行囊均可恢复。任务内容变化会使旧像素偏移失效，从新文本开头阅读。布局延后恢复带身份／文本检查，恢复中的零滚动值不会覆盖已有书签，防止逐帧刷新吞掉位置。书签最多64份、没有节点引用、不写存档；切区重建 UI 或重启不承诺保留。

实际生产 UI 与输入回归覆盖返回长文、关闭重开、重复焦点、文本更新、键盘／肩键翻页、首尾、64份边界和 NaN 拒绝。最初新增提示标签因真实字体最小高度与换行挤到下方按钮，被布局断言拒绝；改为复用既有禁用按钮，原失败日志保留。最终 build_slots_ui 54 项、ui_build_accessibility 17 项与 input_settings_regression 91 项在真实 GL 下通过，结果见 artifacts/u05_journal_reading/final_complete.log；完整 npm test／test:campaign 通过。

这证明界面组件的合成输入与阅读状态，不代表实体手柄、陌生玩家理解或全部字号人工验收。U05／T04 和全部46项最终验收仍 OPEN。

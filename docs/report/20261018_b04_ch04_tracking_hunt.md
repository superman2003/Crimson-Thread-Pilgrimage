# 第四章根网追踪狩猎（B04 续）

修订方案 B04 要求可选挑战（挑战房、精英、追踪狩猎、可选 Boss）可暂缓、可回访，奖励与难度匹配，并关联工具／证据／成长。前批（#121～#125）覆盖了挑战房／可选首领与第二章渠影追踪；本批补**第四章断弦暖房 · 根网追踪**。精英首胜仍见未合 #118。

## 问题

追踪狩猎此前只落在雨渠。暖房已有蜂蜡挑战房，且根库本就有根笼囚徒与可选花粉蜡支路，适合落地第二猎：西眺台／断弦辐桥循迹后，根库余响钟才刷出强化猎物，而不挡树心主线与根库拉杆。

## 改动

- 在 `demo_ch04_broken_string_greenhouse` 增加 `tracking_hunt`：**根网追踪**（`ch04_root_cage_hunt`）。西眺台与断弦辐桥各一道残迹；齐迹前余响钟拒开打；齐迹后封东侧树心阶入口刷出强化根笼猎手。
- 首清 50 碎钱、2 花粉蜡、证据·根网爪痕，并唤回 `charm_mender_found`（静钟碎片，与蜂蜡商人传授并列）；清场标记写入存档后不可刷。
- 根库 `guide` 注明余响钟；未改 `world_routes`（根库虽为检修源房，本批未改其工房覆盖字段，再生幂等不受影响）。
- 挑战敌人仍不计入地区清敌进度；经济审计计入本批一次性挑战收入（+50）：收入 2570，一次性消费占比约 35.0%。
- `optional_challenges` 套件增补残迹门控、封门推人、首清／防刷与跨区保留检查。

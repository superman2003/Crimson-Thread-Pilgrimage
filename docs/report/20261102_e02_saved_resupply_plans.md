# E02：记住补给清单，读取后按当前状态重新报价

基线 main `8f3048c0`。补给窗口原先每次打开都恢复“全部补齐”，上次选择的战具份数和优先顺序会丢失。本批新增“记住当前清单”和“读取已存清单”，每段旅途独立保存一份申请偏好，玩家明确读取后再核对报价和确认购买。

偏好只记录顺序与份数，不记录价格、钱包、库存、解锁或进度。读取时跳过当前不可用战具，按当前缺额缩减数量；之后新解锁的战具显示在清单中，申请默认 0。所有价格仍走原报价，当前资金不足、离开钟龛或保存失败时仍由原交易拒绝或回滚。读取偏好本身不改写已存申请、不消费、不补充库存，也不自动购买。

记录沿用独立辅助记录的原子写入与大小边界；数量、重复标识、额外字段等坏内容明确拒绝。损坏或未知版本的原文件保留，当前清单不变，后续保存按钮也不会覆盖损坏文件。

# U05：旅记分类与已击败敌人笔记

旅记新增全部、主线、委托、证词、敌人、结局六种筛选，筛选行位于左侧列表上方，不挤压右侧长文详情。各分类按记录身份记忆选中项，切换回来不会因新增记录或排序变化错选。原地图仍由独立地图入口操作，委托与证词继续使用原叙事评估器的已知线索规则。

为正式 40 种小怪和 6 位 Boss 编写中文名称，战斗习性与现有攻击目录一致。仅真实敌人死亡信号解锁该种笔记，预建／后台驻留不解锁；沿用胜利处理器原本的唯一存档写入，不另加战斗中磁盘写。未知种类、非布尔标记和未击败的敌人不产生公开记录，不展示未遇名单或完成总数，休息后的重复击败不重复添加。

数据校验约束正式种类覆盖、中文名称和实际习性。真实 World 检查使用正式敌人的受击／死亡信号和保存重读，覆盖分类、未知信息保密、重复击败、按身份恢复选择、筛选行缩放后布局；与原 UI、旅记、输入和存档套件共同运行。原生 GL 六套回归通过，原始日志见 `artifacts/u05_journal_enemy_records`；`test:campaign` 通过。新检查已接入叙事 CI。

这是分类和记录功能的完成证据。自然交战时的文字理解、不同字号和实体手柄长文体验仍保留在完整验收清单，不用定位／额外生成的测试敌人冒充自然流程。

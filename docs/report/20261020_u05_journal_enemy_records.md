# U05：旅记分类与已击败敌人笔记

旅记新增全部、主线、委托、证词、敌人、结局六种筛选，筛选行位于左侧列表上方，不挤压右侧长文详情。各分类按记录身份记忆选中项，切换回来不会因新增记录或排序变化错选。原地图仍由独立地图入口操作，委托与证词继续使用原叙事评估器的已知线索规则。

为正式 40 种小怪和 6 位 Boss 编写中文名称，战斗习性与现有攻击目录一致。仅真实敌人死亡信号解锁该种笔记，预建／后台驻留不解锁；沿用胜利处理器原本的唯一存档写入，不另加战斗中磁盘写。未知种类、非布尔标记和未击败的敌人不产生公开记录，不展示未遇名单或完成总数，休息后的重复击败不重复添加。

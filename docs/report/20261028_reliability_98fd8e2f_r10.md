# R10：声音地标播放期空间更新

依赖R09（#447）以避免AudioDirector同文件交接。NPC声音原已在起播时按射线降12dB，本批不重复建立遮挡功能；新增播放期间重采样。存活地标每100ms最多更新2条空间射线，轮询公平；源移动更新实际发声位置，门墙开合更新遮挡，始终从起播基准计算，不累积降音量。650px地标范围保留，失效／隐藏源立即退役。不会显示NPC名字、坐标或额外发现提示。

Godot4.6.1生产导演／空间音源与真实StaticBody2D11项通过，含新增墙、移开墙、移动源、源隐藏、轮询预算和范围保留；隔离编辑器导入通过，零ERROR／warning。R09的11项在组合代码复验通过。没有播放原始声音或自然World，不能当耳机/扬声器实听验收；46项最终验收保持开放。

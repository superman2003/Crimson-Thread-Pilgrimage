# U02／U06：手柄十字键能走遍所有对话框

接续台账 U02“技能装备条件与手柄完整导航”，以及 U06 的手柄焦点要求。起点为 main `e56ff5c1`。所有 46 个任务包的最终验收仍开放。

## 怎么发现的

在真实 World 里打开行囊、构筑、地图、设置四个主页面，以及从这些页面按钮打开的全部对话框（本次扫到 21 个）。从各自打开时的焦点出发，只沿十字键的四向焦点邻居做广度搜索。这里用的 `find_valid_focus_neighbor` 与视口处理 `ui_up/down/left/right` 时是同一个函数。另外用真实 `InputEventJoypadButton` 复核：在“危险字幕辅助”里按十字键上，焦点一直停在“保留原设置”上不动。

## 原因

1. **按钮行和正文互不相通**：Godot 只在 Window 下同一个顶层控件的子树里找焦点邻居。对话框的确定／取消按钮行和正文是两个顶层控件，所以凡是打开时焦点落在按钮上的对话框（出于安全默认焦点在“取消／保留原设置”），按十字键都进不了正文：危险字幕两个勾选框、手柄校准的滑条和四个预设、主动观察的模式和两条滑条、存档槽切换、浏览旧旅途、实战陪练场的列表、钟龛回访的站点列表。反过来，大多数工作台窗口从正文按十字键也到不了自己的“返回”按钮（Esc 仍可关闭）。
2. **滚动列表的裁切项**：几何搜索会跳过 ScrollContainer 可视区外的项目，多件制作清单十二个方案只能走到第五个。
3. **禁用按钮是死胡同**：十字键能落到禁用按钮上；已知地点目录最下面的“在地图中查看此处”在无结果时禁用，焦点到这里就下不去了。目录还隐藏了 OK，只留自己加的两个按钮。
4. **几何误选**：设置页“手柄校准”向右会选到右上方较高的“NPC 声音地标”开关，右边同一行的“危险字幕辅助”没有任何控件指向它。多件制作清单顶部的“隐藏已完成改制”也只能从搜索框向右进入，而搜索框本身吃掉左右键。

## 改动

- 新增 `dialog_focus_bridge.gd`。界面根节点监听 `node_added`，现有和以后加入的每个 AcceptDialog（包括各工作台后加的窗口）都自动挂上。对话框显示或焦点移动时（内容常在打开当帧或筛选时重建）只补缺失的链接：
  - 按钮行的“上”指向正文最下方的可用控件；
  - 正文里下面没有邻居的控件（包括禁用按钮），“下”指向默认按钮：当前焦点所在按钮，否则取消，否则可见的 OK，否则第一个可见按钮；
  - 每个滚动列表里上下相邻的项目串成链。
  - 作者显式写的邻居一律优先；桥接写的链接带标记，重新计算前先撤掉，不会和作者写的混在一起。
- 设置页“手柄校准”与“危险字幕辅助”显式互为左右邻居；多件制作清单的搜索框与“隐藏已完成改制”互为左右，第一项方案向上到这个开关。
- 对话框默认焦点不变：确认类对话框仍然打开在安全的取消按钮上。

## 验证

- 新默认套件 `dialog_dpad_focus`（正式 World，headless）109 项，21 个对话框：四个主页面从默认焦点走遍全部可交互控件；每个对话框从打开时的焦点走遍正文全部控件和按钮行全部按钮；“手柄校准”与“危险字幕辅助”互为邻居；危险字幕对话框仍打开在“保留原设置”，真实手柄十字键上进入选项，连续按下回到按钮行。
- 反向：桥接不生效时 21 项失败（上面列出的对话框，以及十字键上仍停在按钮行）。
- 套件已登记到 `DEFAULT_SUITES`、完成标记和计数契约；`test_regression_runner.py`、`test_ci_shards.py` 通过。
- 相关既有套件见 PR 说明。

## 边界

- 只读的 RichTextLabel 正文（物品说明、复盘记录等）不计入必达。部分正文的焦点本来就到不了，用手柄滚动长文仍要靠鼠标或已有的翻页键，这一点没有改。
- LineEdit 吃掉十字键左右，用于移动光标，这是 Godot 默认行为，没有改。
- 扫描只覆盖新存档里可见的按钮；需要特定进度才出现的窗口由同一个通用桥接覆盖，但没有逐个打开验证。
- 实体手柄的手感待 T04。

# G01：材料兑换选择当前最多可换份数

基于main `2d196324d30d1caf0b402be835dbf6ff807bf2fa`，2026-10-27。

材料兑换窗口显示当前最多可兑换份数，并可一键将份数选到该值；选择数量不执行兑换，仍须原报价确认。最大值通过原生产quote在硬上限10以内查找，统一遵守真实钟龛、已到邻区、巡礼印、库存、碎钱与目标材料保存容量规则，不另造一套付款条件。

点击时重新核价；若已有旧确认，清除旧申请并关闭旧确认框，再展示新数量。无可兑换份数、无已知路线或手填数量不足时明确禁用相应按钮。

Godot 4.6.1：28项实际报价模型与原生兑换窗口组件检查通过，宿主上下文为受控夹具。覆盖材料/碎钱/容量各自限制、十份上限、缺凭证、无效计数、钟龛/邻区边界、过期确认和只选数量不消费。将最大值搜索限制到1份后6项失败、退出1。新增独立严格CI；原实际付款与保存回滚代码不变，未将组件验证视为完整自然经济验收。

# R09：音乐加载成功后才提交切换

基线63981173。Boss和摇篮曲先获取可播放流，再修改激活状态／收起旧层；失败保持原播放和状态，可再次请求。终Boss阶段先夹取再比较，加载成功才更新阶段；失败不把旧曲错误登记为新阶段。音乐缺失负缓存可按1秒重试，最多记录16个失败时间，不改变普通音效缓存规则。

Godot4.6.1真实AudioDirector方法、AudioStreamPlayer和合成WAV夹具11项通过；包含缺曲、失败后重试、阶段失败保留、重复夹取阶段不重启、负缓存节流。编辑器隔离导入通过。使用可控音乐候选覆盖注入失败，非实际原曲听感。

初轮缺原素材预载发告警，且夹具立即退出出现ObjectDB warning；最终夹具为预载提供合成流、停止实际播放器并有界等混音器退休后，零ERROR／warning。运行器拒绝引擎错误、ObjectDB泄漏和未释放资源；不放宽旧门禁。完整World、原曲听感与发布包仍待验收，46项最终验收开放。

# B04 / E04：四件剩余证据接入制作

渠影爪痕、蜂蜡余响、灰旗爪痕、钟舌余响此前只有收藏文字。现在分别成为逆潮线轴、蜂蜡缝托、灰旗收针环、冠舌调线坠的制作图样，交给对应工匠，花 60 / 70 / 80 / 90 碎钱和三份当地材料；末件使用第六区冠响碎片，并引导回访铸雨渠。首清提示、证据说明、锁定铭饰说明和工匠详情均给出用途与去处。

四件新铭饰加入现有战斗／行旅槽及 64px 铜线矢量图标。效果均有取舍：远程距离 +15% / 技能伤害 -10%；治疗准备 -12% / 受击击退 +15%；地面移动 +6% / 受击击退 +15%；普攻回能 +10% / 治疗准备 +12%。三个线轴类变体互斥，提示指明实际冲突名称。保留原有技能消耗、治疗底线和永久能力门，不以降线术消耗制造新的资源循环。

图样不消耗，不能跨工匠购买、重复购买或在材料不足时部分扣款。所有权沿用构筑 `unlocked_passives` 持久保存，存档格式不变；制作不自动装备、不补生命或绯线，保存失败完整回滚。

经济审计现在强制九件挑战证据均有成长用途，六区材料均有制作消费。一次性收入 2840、全部一次性消费 1750（61.6%），仍达到至少 1.5 倍收入余量。五项变异检查验证删图样用途、弃用第六区材料、伪造来源和错误工匠均会被门禁拒绝，已接入 `test:campaign`。

原生 Godot 4.6.1 GL 的九套回归全部通过：`artisan_crafts` 92（新增 46 项）、`build_system` 91、`seal_identity` 4889、`build_slots` 48、`seal_ui` 31、`ui_build_accessibility`、`build_transaction_runtime`、`save_recovery` 35、`optional_challenges` 350。首次新夹具未解锁旧线轴即测试互斥、旧 UI 仍断言只有三件战斗铭饰，均已修正后复跑。npm 与 campaign 通过；原始记录见 `artifacts/b04_remaining_proof_crafts`。既有 ObjectDB 退出警告保留，未放行引擎 ERROR。

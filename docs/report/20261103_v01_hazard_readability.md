# V01：陷阱画满真正伤人的宽度

2026-11-03。台账 V01 的下一验收交付是“正常游玩画面统一比例与危险辨识”。六区 44 个地形陷阱的图片按 `max(宽,高)/112` 等比缩放、中心放在伤害区上方。但每张陷阱贴图都是一个宽格子里只有中间一小块不透明图案（尖刺图 96×96 里只有 28px 宽）：

| 种类 | 数量 | 原可见宽度 / 伤害宽度 |
|---|---|---|
| 尖刺 spikes | 7 | 25% |
| 捷径反击 shortcut_revenge | 1 | 25% |
| 钟缝 bell_gap | 8 | 31% |
| 孢子箱 spore_chest | 7 | 38% |
| 假苔地板 fake_moss_floor | 13 | 52% |
| 坠钟锤 falling_clapper | 8 | 65% |

软件 GL 截图把真实伤害框画出来对照：苔钟庭前庭的尖刺只在中间画了一小块，伤害框宽约四倍；孢子箱飘在伤害框右上方，框内大半是空气。玩家看着安全的地方会受伤。

## 改动（不改伤害范围，只改画法）

`main_level._add_hazard_visual`：按种类登记贴图里的不透明图案区域，用 `AtlasTexture` 裁出图案，

- 尖刺、钟缝、假苔地板、捷径反击、孢子箱：沿伤害宽度平铺若干份（每份约为陷阱高度的 2.2 倍、32–56px 高），底边落在陷阱地面上——例如 120px 尖刺带变成一排 5 枚尖刺，孢子箱变成两个并排的孢子囊；
- 坠钟锤：单个等比放大到伤害宽度的 90%，底边落地。

## 验证

新套件 `hazard_readability`（六区 Main）：每个陷阱都有图案、图案并集水平覆盖伤害宽度 ≥85%、每份图案底边落在陷阱地面。修改后 44 个全部通过（最低 90%）；修改前 44 个全部失败。`spike_pogo`、`quiet_sole_traps`、`legacy_travel_rewards`、`all_chapters_demo`、`ch02_demo`、`demo` 通过；`player_contact_art` 软件 GL 通过。软件 GL 截图核对了尖刺、钟缝、假苔、孢子箱、坠钟锤各一处。

## 同批记录：Boss 治疗与反击窗口实测（B02，无代码改动）

六位 Boss 开正常 AI、玩家站在 250／500px 不动、每阶段 30 秒：两次受伤之间 ≥1.15 秒（最慢的承力缝）的空档在每位 Boss 的两个阶段都出现多次，三种契印都能在战斗中治疗；500px 打不到的三位，该点在场地锁墙外，实战进不去。各招收招 0.5–1.2 秒，近战招都在 0.65 秒以上，远超玩家普攻起手 0.06–0.10 秒，近身招留有反击窗口；0.5 秒的多为远程招，靠逼近惩罚。

## 边界

平铺的图案仍是原有像素素材，与六区手绘画风的统一（V01 其余部分）需要美术；假苔地板本意是伪装，现在平铺后仍用同一张“假苔”图案，伪装程度未变。

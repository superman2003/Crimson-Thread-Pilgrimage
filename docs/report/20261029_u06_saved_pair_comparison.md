# U06 设置无障碍：两套保存方案只读比较

基线5af735c7。已有管理页的预览比较当前运行设置与所选方案；此项新增的是两套保存记录之间的并排阅读，不捕获当前InputMap，不调用安装/应用或写入。

## 交付

在原设置方案管理页新增比较入口。左右下拉可选择保存方案、交换方向，按设置参数/键盘鼠标/手柄按键划分，搜索标签，只显示不同项或包含相同项。全部输入标签来自保存事件的规范解码；旧方案省略字段明确显示未记录，不悄悄借用当前按键或默认值。输入顺序在全部视图保留，设备筛选不误报其他设备变更。

比较报告只保存窗口快照；所有者记录变化时旧报告失效，须显式重新读取。关闭父窗口或设置清空快照/正文，不留可执行回执。只比较保存值不表示这套记录已通过实际应用的冲突检查。

## 原有缺口与交付

兑换页可以选择最多可换份数，但不能按想持有的目标材料总量安排，确认前也缺少前后库存余额。

新增目标库存输入与按缺额选择份数；逐份使用原实时报价寻找不超过缺额与十份上限的可付数量。目标达成时不建议继续兑换，资源不足或上限限制时明确仍缺多少；确认窗口显示原报价中的材料和松脂前后余额。

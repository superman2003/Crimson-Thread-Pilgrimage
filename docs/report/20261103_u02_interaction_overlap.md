# W02／B04：按 F 永远选不中的两处互动物件

2026-11-03。B03／C01 的逐招矩阵之后，用同样“逐个全量”的方法检查了 World 六区的全部按 F 互动物件（NPC、钟龛、拉杆、出入口、工房传送口、挑战龛、狩猎痕迹、环境痕迹、手动拾取物；步行通道不算）。按 F 时 `interaction_target()` 只选**离玩家最近**的一个；两个物件放得太近，其中一个就可能在任何站位都输给邻居。

## 发现

| 地区 | 物件 | 问题 |
|---|---|---|
| 盐白档案馆 | 工房传送口 `upgrade_crown_resonance_2_access_a`（检修支线 → 删名契约暗柜） | 与 NPC 逃亡书记**坐标完全相同**（1490,1358）。距离相等时按名字决胜，`npc_…` 永远赢，按 F 只会和书记说话，这个工房进不去 |
| 无声王冠 | 挑战龛 `challenge_shrine_ch06_bell_tongue`（余响钟 · 钟舌试炼） | 左边是钟龛，右边 5px、低 8px 处是环境痕迹“日常”。痕迹更贴近玩家脚下，两者之间没有任何站位能选中挑战龛，**钟舌试炼开不了** |
| 苔钟庭 | 工房传送口 `upgrade_thread_dash_1_access_a` | 与 NPC 线匠学徒只隔 10px，只能从一侧很窄的地方选中 |

两处坐标都是 10-11 接入工房、10-20 加环境痕迹时直接放在已有物件上，之前没有任何测试检查互动目标之间的遮挡。

## 修复

只改数据坐标，不改选择规则：

- 盐白档案馆工房传送口移到同一小平台左端 x=1305（像后墙检修口），返程落点同步改；
- 苔钟庭工房传送口移到钟龛平台左端 x=1575，返程落点同步改；
- 两个工房在 `ability_backtracks` 里的 `source_position`（`world_upgrade`／工房套件据此核对返程位置）同步改；
- 无声王冠的环境痕迹“日常”移到 x=2745，与挑战龛、拉杆各隔约 85px。

`tools/validate_world_routes.py` 通过（传送口仍有地面支撑、配对对称）；`world_upgrade`、`world_workshop_group_one`／`_two`、`world_integration`、`world_route_access`、`optional_challenges`、`challenge_claim`、`scene_history`、`hidden_routes`、各区体验套件通过。

## 回归套件 `interaction_reach`

World 宿主依次载入六区，等可互动物件建好；对每个物件先把玩家移到旁边、等附近实体驻留，再沿脚下地面每 5px 摆放玩家，用正式 `interaction_target()` 判定，要求至少有 20px 连续能选中它的站位。

- 原数据：准确失败两项（盐白传送口 0px、钟舌挑战龛 0px）；
- 修复后：106 个物件全部通过（最窄 20px），本机约 60 秒；
- 加入 `--disable-render-loop` 列表（只验状态）。

## 边界

- 站位按“脚底在物件下方 40px”的作者约定摆放，不跑移动输入；悬空或在台阶上的物件按这条水平线判定。
- 落地即拾取的物品在巡视时会被捡走，不计入；手动拾取物照常检查。
- 只覆盖开局状态下的 World；NPC 迁移到别处后的新位置由迁移相关套件负责。

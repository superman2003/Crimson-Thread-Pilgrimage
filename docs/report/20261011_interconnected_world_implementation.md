日期：2026-10-11。实现基线：main `aabd317`。承接同日调研报告，不重新替换巨钟、失声契约、六区、美术或战斗素材。

## 已实现的玩家体验

默认入口改为 World.tscn。玩家在钟庭经旧运书索道看见盐风封门；没有双线跃不能越过，也不能从底部或攀壁绕开。另一条排水钟管通往雨渠。低处检修路线真实取得丝壁攀附，雨溢立管允许进入书库；阅览烛台支线真实取得双线跃。通过运书线返回钟庭，封门开启后可以收取“被删去的名字”证词，开启永久归庭索道。

入口需按 F，成对落点保存区域关系；首次跨区不要求清空敌群或本区 Boss。运书索道是区域内部的交互交通入口，不把瞬间切换称作实体移动的升降笼。原六区洞穴升降笼仍保留物理上下行。

三区中新增回声钩索铜环，钩索动作会选择朝向附近可见锚点，检查岩层遮挡，以碰撞物理拉动角色；跳跃、冲刺、受伤和复活可取消。未拥有 echo_hook 不可拉动。双线跃消耗一次空中追加跳跃，落地恢复，持续按键不能无限触发。

## 世界记忆

WorldState 保存全局背包、碎钱、剧情标志及每区拾取、捷径、探索、Boss、钟龛状态。正常敌群按既有遭遇规则重置，能力、证词与 Boss 奖励不重复生成。跨区保持当前生命和能量；重启在当前区域记住的钟龛恢复，不保存半空位置。旧单章 Main、GeneratedMain 及显式 --demo-config 参数继续独立运行，不读写世界存档。

文件使用临时写入、校验、原记录备份和原子重命名；损坏或未知版本记录不会被新数据静默覆盖。此前代码没有完整世界存档，本轮不虚构不存在的旧格式迁移。F9 的确认窗口启动新旅途，保留 .previous 备份。

跨区物品分类从六区目录合并，不再仅按当前章节目录把携带工具降为材料。

## 实际物理验证揭示并修复的问题

1. 原雨渠攀壁点要求过高的首访跳跃，移到低处检修路。
2. 原盐风门可以用攀壁从顶部绕过：封闭拱顶、基座和后壁，使实体能力门形成连续边界。
3. 书库两级踏台只留十像素起跳缝：为 34×84 角色留足身体空间。
4. 连续实心斜桥盖住从下方登楼的楼梯：拆成两侧夹层，保留真实登楼开口。
5. 长时间导航触发攻击效果自然过期后 typed filter 对已释放 Node2D 转换失败：改为倒序原地清理，同时保护过期 Tween。隔离基线代码运行新测试可以稳定复现，修复后连续多轮生成正常。

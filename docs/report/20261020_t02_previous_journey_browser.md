# T02 补充台账：旧旅途只读浏览

设置页新增“浏览旧旅途”，列出当前存档槽的 `.previous` 与 `.previous.earlier_*` 归档。显示归档时间（UTC）、停留地区、已记录地区／房间数、守门者、碎钱与结局；无记录和损坏记录均有明确说明。浏览器无恢复或覆盖操作，不切换当前旅途。

文件候选先排序，再最多校验 12 份；每份沿用 WorldState 的版本迁移、字段与 4 MiB 上限。界面显示总数，较早文件仍保留。正常存档、`.bak`、其他槽和其他保留副本不混入。弹窗及关闭当帧阻止底层快捷键轮询，返回设置时恢复焦点。

验证：`save_product` 新增 8 项档案隔离、损坏、摘要、旧结局、字节不变和显示上限检查；`ui_world_integration` 新增 6 项实际按钮／弹窗／输入隔离／返回设置检查；并回归 `save_recovery`、`settings_remap`。Godot 4.6.1 原生 GL 记录见 `artifacts/t02_previous_journey_browser`。

这里只提供台账要求的旧旅途浏览。旧记录并不因可展示摘要就被认定可恢复为当前版本的完整构筑。

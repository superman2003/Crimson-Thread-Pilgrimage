# C01：下劈可在地刺上反弹

台账 C01 剩余“判定对齐、取消代价、空中反弹”。下劈命中敌人后的反弹此前已有（`melee_recovery` 覆盖），但 `_apply_attack_hits` 只遍历敌人：下劈落到地刺上不会弹起，只会照常受伤。地刺分布在铸雨渠（4 处）与盐白书库（3 处）。

本批新增 `hazard_pogo.gd`：`MainLevel._hazard` 生成危险区时，只把静态地刺（`spikes`）标记为可反弹表面；孢子烛台、坠落钟舌、塌陷苔地与钟隙不是可站立的表面，不标记。玩家下劈的攻击框与地刺相交、且玩家到地刺顶面之间没有地形时，使用与命中敌人相同的 `_apply_downslash_bounce`（同一次挥击只弹一次，连跳计数照常），但不回绯线、不触发命中顿帧。反弹后有 0.12 秒地刺接触宽限，避免高速下落时同一帧先受伤；伤害仍只在进入地刺时判定，宽限结束后进入照常受伤。

新增默认套件 `spike_pogo`（14 项）：使用生产 `Player` 场景、真实瞄下与攻击输入，以及 `MainLevel._hazard` 生成的地刺与孢子烛台。覆盖：只有地刺被标记且表面与作者矩形一致；下劈反弹、不回能、不扣血；宽限内接触不受伤、宽限后照常受伤；中间有地形时不反弹；孢子烛台不反弹；地刺旁的水平攻击不反弹。拿掉地刺反弹调用会失败 3 项，拿掉宽限判断会失败 1 项。headless 与真实 GL 通过；`melee_recovery`、`combat`、`player_melee_feedback`、铸雨渠与盐白书库体验套件及 `world_neighbor_gameplay_live` 通过。

不在本批：敌方投射物或根刺的反弹、判定对齐与取消代价，以及实机手感（T04）。

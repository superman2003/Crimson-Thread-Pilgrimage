# 可选挑战成长解锁加深（B04 续）

修订方案 B04 要求可选挑战可暂缓、可回访，奖励挂钩工具／证据／成长。前批（#121～#127）已铺挑战房／追踪狩猎／可选首领；本批补**既有可选挑战上的工具／铭饰成长路径**，不追加碎钱，以免跌破经济审计 35% 消费占比门槛。精英首胜仍见未合 #118。

## 问题

渠影／根网／灰旗狩猎与封蜡库可选首领已能唤回铭饰，但冠裂隙、配重暗格、蜂蜡暗屋等挑战房仍只发证据与碎钱，工具向奖励仍几乎只靠人物支线。盐白线盐雾瓶也缺少与校录传授并列的可选挑战路径。

## 改动

- `_grant_optional_challenge_reward` 支持 `unlock_event`（原有）与 `unlock_events`（数组，可叠加）。
- **冠裂隙暗格**：`charm_reflux_found`（工匠线轴，与缝名学徒并列）。
- **配重暗格**：`tool_mine_found`（绊线钉，与雨渠铁匠并列）。
- **蜂蜡暗屋**：`tool_lure_found`（回响诱铃，与蜂蜡商人并列）。
- **封蜡库可选首领**：保留 `charm_stride_found`，追加 `tool_fog_found`（盐雾瓶，与盐白司书并列）。
- 不改各挑战 `currency`；经济审计收入仍 2570，消费占比 35.0%。
- `optional_challenges` 套件检查上述成长旗首清写入。

## 验证

- `optional_challenges` 正式 World：既有首清／防刷／跨区保留，外加本批成长旗。
- `npm run test:campaign`（含经济审计）与 `npm run test:optional-challenges`。

- 军墓／钟舌挑战房仍可再挂主题成长物；伤害开启手感（T04／B03）。

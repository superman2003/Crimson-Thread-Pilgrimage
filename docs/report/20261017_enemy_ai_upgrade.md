# 普通敌人 AI 升级：应对选招、预判、轮流进攻、受击反应与巡逻

## 升级前的问题

- **招式顺序可预测**：两招都打得到时强制换成另一招，形成 A、B、A、B 轮替。
- **针对玩家的应对大多失效**：选招加分查的是 `aoe`、`shockwave`，普通怪数据里没有这两种类型（实际是 `wave`、`nova`、`pool` 等），"玩家跳起用对空招""玩家回血就突进"基本不触发。
- **瞄准不预判**：飞弹、俯冲瞄准前摇开始时玩家的位置，玩家持续直线跑就能躲开。
- **群怪不协调**：同时发现玩家的怪会一起出手。
- **每次受击都打断出招**：玩家连砍就能让普通怪永远出不了手；挨打也不会后退。
- **只要玩家在附近就转身**：不管是否发现玩家，每帧面向玩家，巡逻的怪会卡在最靠近玩家的边界来回抖。
- **巡逻单调**；新加的精英怪没有接上已有的精英出场仪式。

## 改动（`enemy_actor.gd`，Boss 战术层不变）

### 选招

- 招式按类型归入角色：对空（nova/fan/projectile/mortar，以及机制名含"截空"的近身招）、反制（guard/retreat/feint/blink/melee/combo）、惩罚（lunge/dive/vault/wave/rootline/pool/combo）、拉近（lunge/dive/vault/projectile/fan/mortar/blink/beam）、范围（wave/rootline/pool/nova）。招式数据可用 `roles` 覆盖。
- 情境加分：玩家在空中或高于敌人 → 对空 +3；近距离挥砍/冲刺/钩索 → 反制 +3；回血 → 惩罚 +3.2；远离或超出 70% 射程 → 拉近 +2；站定 → 范围 +1；精英专属招 +1.5。
- 重复上一招递减扣分（每多重复一次再扣 2.5），不再禁止。
- 最终在候选招式间按分数做 softmax 加权随机：最合适的通常胜出，接近的次选也会出现。随机数以出生点 id 为种子，预建邻区与现场敌人保持一致。

### 瞄准

- 飞弹、扇射、瞬移、俯冲、弧跃在**前摇开始时**按玩家当前速度预判落点并锁定：预判时长 = 前摇 + 飞行（或出招一半），准确度普通 0.6、精英 0.85，水平最多 140 像素。
- 前摇期间不再追踪，预警方向与实际出手一致；玩家直线跑会被预判命中，前摇中及时变向仍可躲开。落圈、地刺、地波等有预警的范围招仍打在预警位置。

### 轮流进攻与走位

- 玩家 560 像素内同时处于前摇/出招的普通敌人最多 2 只；第三只进入 `wait_turn`，在玩家攻击范围外约 150 像素游走，有空位再上。精英不排队，Boss 不计入。
- 地面敌人如果同侧已有更靠近玩家的同伴（相距 70 像素内），多退后 60 像素，避免叠在一起。

### 记忆与搜索

- 发现玩家后记住最后位置 2.4 秒；失去视线时走到最后看到的位置，再左右张望，超时才回去巡逻（仍受地盘范围限制）。
- 只有在察觉范围内（仇恨距离的 1.1 倍）或记忆期内才面向玩家，修复巡逻抖动。

### 受击反应

- **韧性**：1.4 秒内连续挨 3 下，获得 1.8 秒韧性（冷却 4.5 秒），并立刻把出手欲望拉到门槛；韧性期间的前摇和出招不会被打断，只受 35% 击退，也不切成受击图。
- **精英**：出招一旦开始就不会被打断。
- **后跳**：近战型地面敌人（偏好距离 < 120）连续挨 2 下时向后跳开（冷却 3 秒）。
- 每次受击出手欲望 +0.25，并记住玩家位置。

### 巡逻

- 走到巡逻边界停下 0.5–1.3 秒，回头看一眼再走回去；巡逻方向与战斗朝向分开。
- 地盘小于巡逻距离的守门怪（如第 5 区出口平台的 E07、E13）原地站岗，每 1.6–3.2 秒左右张望一次，不再在平台上来回走。

### 精英出场

- `elite: true` 的敌人首次进战时播放已有的精英仪式起手音，与 `encounter_role` 含 elite 的遭遇一致。

## 公平性

保留：前摇预警、各招冷却、出手欲望门槛、Boss 战术层、地盘与回位规则、Boss 门前守门怪与 NPC/休息点附近敌人的既有回归契约。预判有上限且在前摇开始时锁定；韧性有冷却；同时进攻的普通敌人不超过 2 只。

## 验证

- 新增 `enemy_ai_behavior` 25 项：空中玩家选对空招、回血被突进惩罚、"截空"近身招识别为对空；300 次连续选招两招各至少 60 次、最长连续重复不超过 4；同出生点 id 选招序列一致；第三只排队、精英插队、空出名额后下一只出手；直线跑预判在上限内、站定直瞄、范围招保持预警位置、前摇中闪开仍能躲过；首次受击打断、连续两下后跳、连续三下获得韧性与反击、韧性前摇不被打断、精英出招不被打断；远处不察觉、近处察觉；巡逻转身停顿、停顿期间静止；守门怪原地站岗；失去目标后搜索最后位置、记忆到期回去巡逻。

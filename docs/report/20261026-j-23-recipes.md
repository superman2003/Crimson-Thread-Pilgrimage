# 配方可行组合与机会成本

## 玩家可见行为

对用户已选至多8个配方精确枚举所有子集，寻找不可再扩展的可行组合，显示必选项、机会成本及合计材料缺口。

入口：设置 → 旅途工作台。在「改制依赖图」编辑候选并勾选目标，当前分析展示组合；交互预览逐组合显示物资余量。

## 数据及边界

- 使用当前功能已经收录的公开观察，不扩大未知内容的读取范围。
- 交互试算只改窗口副本；记录仍走原有分槽存储与严格校验。
- 保留原模块分析、原生记录库、导入导出边界及已有测试。
- 最多256子集；安全余量对合计材料向上取整；技能分支互斥和已制作过滤同时生效。资源试算不替代正式构筑报价。

## 正确性验证

使用独立资源/分支可行性计算检查全部子集，覆盖资金、材料、余量、倍数、已制作状态、空计划、重复及越界选择。

新套件：`i_23_recipes`。原套件：`i_06_recipes`。

新套件还执行原生页面绘制、候选保存、磁盘读回、写入失败重试、撤销/重做、同槽导入及跨槽拒绝，并操作新增交互检查器确认主进度不变。

本地验证使用 Godot 4.6.1 headless 与隔离的域/原生控件夹具。它不代替实际 World 或软件 OpenGL 验收。

独立 Actions 工作流在真实项目的精确 PR 头执行资源导入、导出闭包审计、新套件、原工作台 World 与 i_live_world，分别使用 headless 和软件 OpenGL。原模块工作流及三分片整合 CI 保持启用。

# N02／U05：人物追问记得谁说过，也能回看当时的物证

日期：2026-11-04。接续战后辨认，补全人物回忆自己的来源链。

## 正式记录

每条已确认追问现在明确显示“对话者”，使用正式人物姓名，避免离开现场后只剩没有说话者的问答。原来的问题、完整回答、巡礼者手记与“当时核对的线索”保留。

来源按钮可直接回看该次回答实际核对过的实体观察和六份独立证词。只使用已经确认的版本；基础回答不会因为后来拿到新材料就凭空多出展开版的来源。

| 资料 | 回忆中保留 | 能打开来源的条件 |
|---|---|---|
| 已确认回答 | 当时的原话、说话者与线索标签 | 精确记忆标记仍成立 |
| 实体观察 | 当时引用的观察身份 | 对应正式观察记录仍可见 |
| 独立证词 | 当时引用的原始证物身份 | 当前真实持有原件，不用已知标题替代 |
| 技能、委托或结局状态 | 仍保留原来的线索标签 | 不把这些状态伪造成另一份证词 |

普通正文不会显示内部 NPC、剧情旗标或隐藏条件。来源窗口保持原人物记录、分类、搜索、滚动与阅读偏好；关闭后回到原文。

## 兼容与边界

显示姓名和出处不改变已发布的记忆身份，也不增加存档字段。213 条当前／归档追问的 426 个基础或展开版本都按原有哈希恢复。只增加了可见文字的阅读指纹内容，旧的明确已读标记不会把新增姓名说明自动当作已读。

证物不在手上时，相应原件入口撤销；已经确认的人物回答仍保留。撤销观察也会使对应来源失效，不会把另一个物件或未来线索补进去。重复引用按原始身份去重，不增加独立证据数量。

记忆展示模板按当前／已发表目录的整体指纹缓存；目录内容改变时重建，返回给界面的是独立副本。原话仍逐次按真实布尔标记筛选，不把可用的问题当作已经听过的回答。

来源窗口上限与追问最多六条基础来源加六条展开来源一致，保持十二条有界入口；不增加任意记录跳转或递归窗口。

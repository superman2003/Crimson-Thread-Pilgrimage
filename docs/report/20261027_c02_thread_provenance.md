# C02 疗伤与线资源：预留退款与练习来源结算

本轮第12/40项；修复实际资源账目，不改变疗伤成本、损失比例或练习收益。

旧实现会按理论退款给practice_energy加标记，忽略退款被容量截断；
而energy_changed在标记追加之前发出。夹具在旧生产实现复现18项失败：
满容量退款错误标记、离开练习误删真实绯线，以及信号内再次疗伤时
丢失预留来源。本次按实际容量接受退款，并在同一次状态发布前设置
energy与practice_energy，回调可以立即结算或开始新预留，不会被外层
调用回来后的写入污染。

同一来源规则用于实际普通针击与强化交叉斩在练习目标上的收入：
只标记实际收入，在信号发出前完成；普通敌人收入保持真实资源。
消费与容量缩减先移除练习绯线，避免把尚存的真实收入误标成练习。
硬复生的零绯线状态也在信号前清除练习标记。

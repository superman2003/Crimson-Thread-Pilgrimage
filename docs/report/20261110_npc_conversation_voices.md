# NPC 交谈动作与原创虫语

此前 NPC 有交谈原画，但阅读期间一直循环交谈动作，对话头像是静态图；声音仅有少数共用的极短元音，旧章节对话入口还没有接入声音。

现在 25 位 NPC 复用已有 400 帧原画，按待机、招呼、发声、聆听切换。招呼结束后，实际短句仍在播放才进入交谈动作；声音结束后安静聆听，等待玩家读完文字。重复显示同一段落不重启动作，切换人物、关闭对话或卸载角色会结束对应声音。角色根变换不随状态缩放，头像以同一原画和固定窗口显示动作。

声音采用用户选择的“偏口语的含混呢喃”，原创虫语名为“绯鸣”。25 个角色各有六段招呼、叙述、询问、安抚、警示短句，共 150 段，按角色设定基音、共鸣、气声、粗粝度、语速和少量回声。中文文字仍承载剧情，不按字幕逐字播放提示音。声音是原创程序合成，未使用其他游戏或演员的采样。

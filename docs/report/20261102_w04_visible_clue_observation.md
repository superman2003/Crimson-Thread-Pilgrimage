# W04：隐藏入口观察需要真正可见的视线

基线为 main `8f3048c0`。此前走到线索 260px 内就会写入观察记录，隔着墙、楼板或隐藏了线索节点也会提前发现。本批保留原距离和保存事务，增加节点可见、同一物理世界、玩家眼部到线索的地形视线检查。查询同时使用正式 World 的岩体／平台／地形解析查询和 layer 1 物理射线，覆盖未驻留碰撞；不强制额外加载碰撞，不把角色受击区域当作墙。

未观察到的近处线索至多每 150ms 复查一次。失败保存仍按原 5 秒退避；没有穿过墙就不写发现标记、旅记或 checkpoint。成功保存后沿用原提示，同时显示已有阅读横幅，防止旁边机关的首次互动提示在同一帧盖掉观察文字。

验证保留八处正式入口、隐藏奖励、发现状态与旧存档迁移检查，并增加实际 World 中的墙、隐藏节点、非地形层、范围、保存字节、复查间隔及解析岩层检查。低矮顶板下的两处旧夹具把玩家脚底放在画稿锚点上，眼睛进入了岩层；改为同一入口的下方观察位置，地形与线索画稿坐标均未改。

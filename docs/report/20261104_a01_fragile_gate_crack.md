# A01／S02：普通一击敲到可破地面时会开裂

2026-11-04。三处棘线下劈回访工房（苔钟庭、盐白书库、断弦温室）的出口，是一块必须用棘线下劈击碎的地面。原来没有学会下劈时，从上面普攻这块地面什么都不会发生：没有声音，画面也不动。玩家无从知道它能破坏。音效生成包里早有一个专门的“开裂”声 `player_downstrike_crack`，清单还写着“开裂阶段尚未实现”，一直没用上。

## 改动

- 普攻的判定框碰到可破地面（`fragile_terrain` 组）时，每一挥只播一次开裂声，并发出 `gate_struck` 信号；
- 关卡收到信号后，让地面的画面节点轻微震动约 0.13 秒，再回到原位。碰撞体不动，站在上面的玩家不受影响；
- 不弹任何文字，避免提前点名尚未取得的能力。地面上的能力门标识（另见 #509）负责说明；
- 正在放棘线下劈时不播开裂声，地面照原有流程击碎；
- 清单中 `player_downstrike_crack` 改为 `wired`。

## 验证

新套件 `fragile_gate_crack`，在正式 World 的苔钟庭下劈工房里，用真实按键（跳、下 + 攻击）验证，共 14 项检查：

- 没有棘线下劈时，下落途中出手和跳到顶出手，各开裂一次（每一挥只算一次）；
- 开裂后地面仍然完好，碰撞体位置不变，画面震动后回到原位；
- 取得棘线下劈后，同样在跳到顶时下劈，能击碎地面，并且不再播开裂声。

去掉本改动后同一套件立即失败。以下相关套件本地通过：

- `world_upgrade`（三处下劈门的原有开门流程，需加长超时）
- `spike_pogo`、`player_melee_feedback`、`melee_recovery`、`death_cache_placement`
- `player_action_buffer`、`ability_movement`、`world_workshop_group_one`、`world_workshop_group_two`

## 顺带确认

下劈开门的判定只在起手那一刻做：起手点距地面 175px 以内。所以如果下劈起手太高，砸到地面时并不会击碎。查了数据，三处工房的顶板都在可破地面上方 150px，玩家跳不到超出范围的高度，所以实际游戏里不会出现这种情况。如果以后有更高的房间放置可破地面，需要改成落地时再判定一次。

## 边界

- 开裂声的音量与手感仍需实机试听；
- 只处理可破地面，其他能力门（冲刺、攀壁等）被普攻敲到仍然没有反馈。

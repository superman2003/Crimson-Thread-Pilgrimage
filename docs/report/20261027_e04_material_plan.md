# E04 工匠制作：整单材料规划与实际结果预览

原多件清单只显示首个拒绝原因，玩家无法同时核对所有缺料。现将整单碎钱与所有材料合计列为需要/持有/尚缺，图样单列且明确只出示、不消耗、同一份可共用。逐件显示描述、工艺来源、前阶要求及生产报价原因，并使用实际物品显示名与已有用途/来源说明。

可提交的构筑与材料候选还会展示实际容量前后与现有次数、已修复契印新开放的确切槽位、解锁但未自动装备的铭饰，以及校习方向变化。结果来自原整单事务的独立构筑候选；条件不足不制造成功预览。部件制作不能替代契印机制修复，容量改制不会免费补充次数。

原生工匠窗口加入名称搜索、隐藏已完成改制、清空已选及可聚焦滚动报告。筛选始终保留被隐藏的已选项目，整单仍按完整清单核对，清空动作能移除隐藏选择。Enter仅聚焦匹配项。关闭后的确认即使保有旧阶段也不消费；重新打开须从新清单开始。原两次确认、陈旧报价复核和单次原子存档事务保留。

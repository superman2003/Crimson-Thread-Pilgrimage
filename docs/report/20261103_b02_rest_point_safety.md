# B02：六区所有钟龛与 NPC 都是安静的停留点

2026-11-03。台账 B02 的下一验收交付包括“交谈/歇脚位置”与“真实治疗窗口”。此前 `silent_crown_experience` 只证明了无声王冠三处钟龛和铸雨渠工头旁不会被攻击。

## 做法与结果

新套件 `rest_point_safety`（正式 World 宿主）依次载入六区，对每位 NPC 与每个钟龛：把玩家放到该点，执行与真实传送相同的到达预热（岩体、地形、平台与附近敌人驻留），让敌人以正常 AI 运行 90 帧（1.5 秒），要求没有任何敌人宣告接战、玩家生命不减。

六区共 45 个点位全部通过（本机约 87 秒）。为确认套件能发现问题，用同一流程把玩家放在苔钟庭 E01（苔虫）身旁 70px，套件准确报出接战与掉血。

同批记录（数据见 V01／B02 陷阱报告）：六位 Boss 两个阶段都有多次 ≥1.15 秒的治疗空档，近战招收招 ≥0.65 秒。

## 边界

只覆盖开局状态的 World（NPC 迁移后的新位置由 `interaction_reach` 的迁移复查检查可选中，不含敌人安全）；停留时间 1.5 秒，不代表长时间挂机。改动敌人刷新位置时 World 使用运行时的出生点检索结果，单改数据中的坐标不一定反映到实机，验证请以本套件为准。

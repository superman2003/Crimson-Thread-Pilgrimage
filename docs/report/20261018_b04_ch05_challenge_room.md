# 第五章巡礼军墓挑战房（B04 续）

修订方案 B04 要求可选挑战（挑战房、精英、追踪狩猎、可选 Boss）可暂缓、可回访，奖励与难度匹配，并关联工具／证据／成长。前批（#121／#122／#123）覆盖了一至四章；本批补**第五章黑曜巡礼道 · 巡礼军墓**挑战房（灯影／黑曜相关支路）。精英首胜仍见未合 #118。

## 问题

可选挑战房尚未覆盖黑曜线。巡礼军墓本就是旗桥西侧的补给／暗灯／证词支路，适合落地一间可绕开的余响钟试炼，而不抬高地区清敌、不挡旗桥回访与主线。

## 改动

- 在 `demo_ch05_obsidian_pilgrim_road` 增加 `optional_challenges`：**军墓试炼**（`challenge_room`）。东侧封门至清场，西侧墓区仍可撤离；两只精英（黑曜矛兵、灰旗小鬼）。
- 首清 40 碎钱、2 黑曜碎片、证据·军墓灯影；清场标记写入存档后不可刷。
- 军墓 `guide` 注明余响钟；未改 `world_routes`（军墓非检修工房源房间，再生幂等不受影响）。
- 挑战敌人仍不计入地区清敌进度；经济审计计入本批一次性挑战收入（+40）：收入 2480，一次性消费占比约 36.3%。
- `optional_challenges` 套件增补第五章封门推人、首清／防刷、跨区与存档保留检查。

## 验证

- `npm run test:campaign`（含经济审计）与 `npm run test:optional-challenges`。
- `tools/test_workshop_layout_contract.py` 再生幂等。

# U04 完整地图系统

对应 `SILKSONG_ALIGNMENT_REVISED_PLAN.md` 原题与总台账 U04 剩余的“楼层语义”。
本批基线 `e17ff53206dca1d983d6f2018be3a28926ae9bbd`。不计入已关闭的台账外挑战。

六个正式地区的 140 个房间显式标注层位 ID/名称，跨层房间另标为贯层通道。
不通过未探索房间的包围盒推断可见楼层，不修改房间坐标、道路、奖励或能力门。
已购且补绘的目录行继承所属房间层位；房间、门、危险、捷径、图钉使用同一来源。

目录列表与详情展示层位，搜索支持层位文字；新增层位筛选与现有区域、类型、搜索、排序组合。
选择项只从当前公共目录行生成，区域间同名层位有独立身份，切换区域清除不适用的约束。
重开目录重置层位筛选；未标注的旧数据仍可在全部层位中查看，不冒充某个楼层。

验证：Godot 4.6.1 原生无头模型/控件套件 345 项通过，包含六区数据、隐藏信息边界、
旧数据兼容、区域同名隔离、筛选实际激活与重新打开。目标字体使用真实运行时文件。
本地逐文件 JSON 对照确认移除新增两字段后与基线完全一致，所有既有内容、几何和奖励保留。

隔离入口 `tools/run_map_floor_contract.py` 不运行完整 World、GPU 像素或人工路线。
既有集成 CI 保留，按新头另核；六区自然获取/使用、整体地图体验及 U04 最终验收仍开放。
本批没有估算总完成百分比，也不把 140 条元数据视为 140 个台账任务。

# 无声王冠：休整点安全、门前守卫与西环遭遇

W02／B02 第六区子项。前五区已在 #49–#53 做过逐房构图和遭遇编排。第六区的 15 间原有房间和 20 间工房已在 10-15 批次接入独立镜头，但遭遇布置还停在初版：有敌人贴着 NPC 和灯，甚至能在玩家休整时直接开打。本批只调整敌人位置、巡逻、领地、门前节奏和相应的房间提示，不改地图几何、能力门或物种招式。

## 发现的问题

用正式 World 逐一检查后，发现以下问题。判断依据是实际的交战条件：玩家在领地（+42 像素攻击余量）内、在仇恨距离与纵向容差内、并有视线。

| 敌人 | 原位置 | 问题 |
|---|---|---|
| E14 回声水轮骑士（精英） | `throne_rest_b`，距 Boss 前回跑灯 `save_late_runback` 仅 40 像素 | 每次 Boss 重试都从灯下直接开打 |
| E12 回声棘哨（固定炮台，仇恨 440） | `moss_bell_perch`，距苔庭隐藏灯 281 像素，纵向在容差内 | 玩家在“最安静”的休整房坐灯时会被射 |
| E13 光核 | `throne_walk_a`，距六印守望者 150 像素 | NPC 交谈位置在战斗范围里 |
| E07 迟影 | 钟舌库地面，距旧王钟舌与灯约 200 像素 | 奖励／NPC／灯房间里有敌人，房间说明却写“清怪后”拉杆 |
| E11 回声苔虫 | 苔庭地面 | 休整房里巡逻 |
| 第二区 E10 渠虫 | `sv_floor`，距半沉工头 80 像素，同一高度 | 标为休整的淤泥库里，NPC 旁有敌人；隔壁“栈梯上有伏兵”的房间反而空着 |

另有两处“作者坐标与实际出生点不一致”：第二区 E14 写在 x=1050，但头顶空间不足，引擎实际放在 x=1170；新 E10 也一样。本批把数据改成引擎真实采用的位置，行为不变，以后读数据不会被误导。

## 验证

新增 `silent_crown_experience`，共 420 项、0 失败，已登记进默认 CI，也可用 `npm run test:silent-crown-experience` 单独运行：

- **数据层**：每只敌人站在自己命名的平台上。两个地区所有敌人按实际交战条件计算，都够不到任何 NPC 或灯，计算包含区域与 spawn 级的仇恨覆盖。精英位置、门前守卫领地和房间文本也逐项检查。
- **局部真实战斗**（正式 Player 与敌人，伤害开启）：
  - 门前守卫保留两招，招式身份和伤害不变。
  - 每招收招都比治疗时长多出至少 0.15 秒。
  - 玩家在灯的位置等待 3 秒，守卫不开打。
  - 玩家靠近后，守卫自然起手并造成伤害。
  - 退回灯下，已发出的地波不会消失。
- **正式 World**：
  - 第六区 4 位 NPC 和 3 盏灯、第二区半沉工头的位置，各让周围所有在场敌人运行 1.5 秒：没有一只开打，玩家也没受伤。
  - 每只在场敌人的实际出生点与数据一致：地面敌人比坐标，飞行敌人比所在列。
  - E07、E13、E14、E12、第二区 E10 在新平台上仍会对靠近的玩家开打，不是被放到无效位置。
  - 地区名称、15 间房的镜头，以及在回跑灯复活后的取景都已检查。
- 5 张真实 GL 定位取样在 `artifacts/silent_crown/`：玩家在正式碰撞上落地后冻结、敌人暂停。这是定位取样，不是自然通关截图。

初版专项在调试中发现 3 类问题，都没有靠放宽断言解决：

- 初版的静态规则忽略了领地限制和第二区已有的 spawn 级仇恨覆盖，所以误报。
- 起初给炮台的领地只有 40，它几乎不会开打，已改为 180。
- 栈梯的窄板头顶空间不够，引擎会把 E10 悄悄挪到下一级、紧贴陷阱的位置。这一问题促成了“出生点与数据一致”这项检查。

相关回归见 PR 描述。

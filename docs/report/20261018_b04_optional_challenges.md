# 挑战房与可选 Boss（B04 子项）

修订方案 B04 要求可选挑战（挑战房、精英、追踪狩猎、可选 Boss）可暂缓、可回访，奖励与难度匹配，并关联工具／证据／成长。精英首胜奖励在未合入的 #118；本批做挑战房与可选 Boss。

## 问题

六区已有精英遭遇，但没有可敲响、可封门、可回访的挑战房，也没有与主线守门者分开的可选首领。侧房奖励多为固定拾取，缺少“打完才给、清过不再刷”的挑战回报。

## 改动

- 新增数据驱动的 `optional_challenges`：余响钟交互 → 封门 → 刷出挑战敌人 → 全灭发奖并写清场标记。
- **第一章冠裂隙暗格**（冲刺门后，可绕开）：挑战房，两只精英；首清 40 碎钱、2 苔壳、证据·冠隙余响。
- **第三章封蜡库**（本就可选支路）：可选首领，一只强化抹名法警；首清 60 碎钱、3 盐晶、证据·封蜡账册，并唤回 `charm_stride_found`（巡礼鞋结印记）。
- 清场标记写入剧情标记与存档；再敲钟只提示已清，不重发奖励。挑战敌人不计入该区清敌进度，不挡主线。
- 经济审计计入两处一次性挑战收入（+100）：收入 2310，一次性消费占比 39%。

## 验证

- 新增 `optional_challenges` 套件（正式 World）：首清奖励、封门开关、清敌计数不变、防刷、存档跨区保留。
- `npm run test:campaign`（含经济审计）通过；另跑相关战斗／地区回归。

## 仍待验收

- 精英首胜奖励（#118，未合入本分支）。
- 追踪狩猎；更多地区的挑战房／可选首领；与战具、证据链更深度绑定的奖励物。
- 伤害开启下的实机手感与多种构筑可解（T04／B03）。

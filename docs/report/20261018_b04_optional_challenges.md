# 可选挑战：挑战房、追踪狩猎与可选首领（B04）

修订方案 B04 要求挑战房、精英、追踪狩猎和可选 Boss 可绕开、可回访，奖励与难度匹配，并关联工具／证据／成长。

## 规则

- 敲钟后封住挑战房一侧入口，刷出挑战敌人；全部击败后开门发奖，写入清场标记。
- 追踪狩猎要先在其他房间辨认两道残迹，猎物的余响钟才肯敲响。
- **从另一侧离开挑战房即中止本次试炼**：封门打开，挑战敌人撤走，不发奖，可随时回来再敲。死亡同样中止。
- 挑战敌人不计入地区清敌进度，不挡主线；也**不掉普通碎钱和材料，击杀不回充绯线**，只在首清时给一次奖励。失败重来不能刷。
- 清场标记写入存档；之后敲钟只提示已清。

## 相对最初提交的修正

最初的提交（#121～#127）有四处问题，本批修正：

1. 封门只封一侧，从另一侧离开后，封门墙和“进行中”状态都会留下，其他余响钟只提示“先了结当前的可选挑战”，要死一次才能解开。现在离开挑战房即中止。
2. 第一章冠裂隙暗格的第二只精英站点在 `nook_floor` 可用范围外 8 像素，生成时被放到 2400 像素下的 `station_floor`，玩家在挑战中永远够不到它，挑战无法结束。原测试直接调用 `_on_enemy_died`，没有发现。已移回平台上。
3. 三处追踪狩猎与可选首领额外“唤回”的铭饰（铜背扣、静钟碎片、余声针匣、巡礼鞋结）都已有来源：前三件由人物传授，巡礼鞋结开局自带。已拥有时奖励为空，提示却仍写“唤回”。现在只给碎钱、材料与证据物；与工具／成长挂钩的独有奖励留给 E04 重做。
4. 挑战敌人每只仍给 8 碎钱与 1 份材料，经济审计没有计入，失败重来还能反复拿；为卡住 35% 消费占比，灰旗追踪的碎钱被设为 0。现在挑战敌人不掉普通战利品，碎钱按种类统一为 30／40／60。
5. 生成失败时仍把站点写入存活表，试炼会永远清不掉。现在只在敌人真正生成后再登记；失败的站点跳过，全部失败则试炼当场结束且不发奖。
6. 挑战敌人虽不掉碎钱和材料，击杀仍回充 20 点绯线，可以「敲钟 → 打死一只 → 离房」反复刷。现在挑战击杀不回充绯线，首清奖励也不另给能量。

## 经济

挑战一次性收入 330。全游戏一次性收入 2540，一次性消费 900，占 35.4%（审计下限 35%）。

精英首胜奖励（#118）若合入，收入会再增加，需要与本批一起重新平衡。

## 验证

- `optional_challenges` 套件（正式 World，350 项、0 失败）：
  - 每只挑战敌人生成在挑战房内，地面敌人脚下有地板。
  - 用真实受击打死每只挑战敌人，死亡信号走正常路径；正面格挡的精英从背后打。
  - 首清只发一次奖励，没有逐只战利品，不计入清敌，击杀与首清都不回充绯线。
  - 生成失败的站点不留在存活表里；全部失败则试炼不卡住、不发奖。
  - 离开挑战房中止试炼：封门打开、敌人撤走、不发奖、不写清场标记。敲钟后打死一只再离开，也不回充绯线。
  - 追踪狩猎缺一道残迹时拒绝开打。
  - 清场标记跨区、读档后保留，不能再刷。
- `npm run test:campaign`（含经济审计）。

# 地图分视图记忆、触控手势与输入隔离

区域图与世界图分别记住缩放和归一化视野中心，记忆有容量上限，复位只清当前视图。支持触控板缩放、双指平移、窗口变化和小尺寸内容边界。文字编辑器或独占窗口打开时停止平移并清除按住状态。

本轮第 2/10 项，独立基于 `main 14dbb91bcd68f3f22029f5ada78dd4843091dbe0`，不依赖其它未合并 PR。生产范围：`godot/scripts/survey_map_view.gd`。没有编辑共享入口、回归注册表和进度台账。提交前复核开放 PR 的最新文件列表；同轮十组生产文件也互不重叠。

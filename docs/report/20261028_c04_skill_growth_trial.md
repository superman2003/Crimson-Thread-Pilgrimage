## 用户可见目标

在已有陪练入口中，允许玩家临时试用一个未固化的校习方向：

- 试用只影响当前陪练回合，不改写已装备构筑、永久技能等级或存档；
- 试用前显示方向、消耗、持续回合和可能覆盖的当前效果；
- 陪练结束、离开区域、读档或取消时清理临时状态；
- 保存失败、重复点击、过期回合和不兼容旧存档都必须保持原状态；
- 正式确认仍走既有构筑确认事务，不在本项目中新增第二套成长系统。

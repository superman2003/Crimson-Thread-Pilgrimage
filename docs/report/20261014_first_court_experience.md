# 苔钟庭首段体验：房间镜头、单敌遭遇与首次缝补

日期：2026-10-14。基于 PR #48 的镜头／输入基线，目标为 main 的下一批 PR。main 核对基线为 be47690；前批最终验证摘要已补上传。

## 玩家可见变化

- 苔钟庭42个原有房间增加独立镜头范围。狭廊显示落脚面和上方地标，竖井保留纵向跟随；中央钟庭保留上下分叉的视野。24像素门口迟滞抑制反复切换，范围以模拟时间平滑过渡。Boss事件优先于房间，解除封门后恢复探索构图。复活直接采用出生点房间，跨区／钟管清空旧范围。世界坐标、地图轮廓及缩放保持原契约。
- 苔落走廊的E01改为单次可读咬击：0.55秒前摇、1.15秒收招、3点生命，较短巡逻和追击范围。它仍正常造成伤害、可被击败并提供正常奖励。原物种AI保留，只有此出生记录指定遭遇配置；邻区预建和直接生成走同一配置入口。
- 中央钟庭E02移到西岸远端，入口先看路线再进入交战；齿台E14缩短追击范围，保留殿前钟龛歇脚与重试空间。
- 跳跃、挥刃与缝补仅首次遇到对应情境显示短提示，记录到现有story_flags存档；使用当前绑定键。缝补提示需要受伤、能量足够、站稳且附近无活动敌人，不在菜单、危险地面或Boss战中展示。
- 已经按着方向、跳跃或冲刺时申请治疗会直接拒绝，不先扣能量。治疗开始后的移动、跳跃、受击和界面锁仍按原构筑结算打断，保留原治疗成本与持续时间。
- 初鸣钟龛学徒的首次对话与路况询问改为场景线索，移除固定热键和多项重复操作指令。

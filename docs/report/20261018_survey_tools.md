# 盐墨绘针与钟骨罗盘（U04／E03 子项）

修订方案为地图设计了两件工具，此前都没有实现：

- **盐墨绘针**：一次获得后，在钟龛安坐时可补绘所有已购底图；可向制图师购买。
- **钟骨罗盘**：装在行旅铭饰槽时显示当前位置，没有它就靠地标导航；另外要提供独立的导航辅助设置。

实现前，在钟龛安坐总会自动补绘，地图上也总显示玩家位置。

## 盐墨绘针

- 钟龛补绘需要绘针。没有绘针时，途中笔记仍然记下、不会丢失；钟龛的提示会说明原因和购买途径。买到绘针后的第一次安坐，会把积累的笔记一次补绘。
- 六个地区的地图商人在玩家拥有绘针之前都会出售，价格 10 碎钱。错过任何一位商人都不会失去补绘能力。
- **旧存档兼容**：已经拥有任何一张地图的存档，在读档时自动获得绘针，不会因为这次更新而失去补绘能力。

## 钟骨罗盘

- 新的行旅铭饰，占 1 格，不改变任何战斗数值。三个契印的所有行旅铭饰槽都能装。
- 装备后，区域地图和世界总览都显示“◆ 位置”；不装时没有位置标记，图例会写“无罗盘·看地标”。
- 地图商人在玩家拥有罗盘之前出售，价格 15 碎钱。
- **导航辅助**：设置的“阅读、画面与手柄”区新增“导航辅助”开关，默认关闭。开启后不需要罗盘也始终显示位置，设置会保存。
- 非世界模式的单章试玩仍然总是显示位置。

## 验证

- `cartography`：
  - 纯规则：没有绘针时安坐不补绘、笔记保留；有了绘针后补绘；没有地图的旧存档不会白得绘针；已有地图的旧存档会自动获得绘针。
  - 正式 World：没有绘针时安坐，提示里写明需要绘针。通过真实商店对话框，少一枚时购买按钮不可用；绘针和罗盘按价格各买一次，买过后按钮消失，也不能再买。
  - 地图标记：有绘针时安坐会补绘；罗盘没装时没有位置标记；装上后显示；卸下后开启导航辅助也显示。
- `world_map`：没有绘针时安坐不补绘；没有罗盘或导航辅助时，世界总览不显示玩家；开启导航辅助后显示。
- 原本把安坐当作“全部补绘”的测试夹具，现在先授予绘针：`world_route_access`、`world_host`，以及两个真实 GL 像素检查（`validate_world_atlas_pixels`、`validate_region_commit_pixels`，本机在真实显示下运行均通过）。
- `seal_ui` 的行旅铭饰选项数改为读取该槽位实际可装的列表（多了罗盘）。`build_system` 的铭饰数量改为读取目录。
- 下列套件通过：`cartography`、`world_map`、`survey_map_knowledge`、`map_player_pins`、`inventory_map`、`input_settings_regression`、`ui_build_accessibility`、`ui_world_integration`、`ui_redesign`、`build_system`、`build_slots`、`seal_ui`、`seal_acceptance`、`upgrade_integration`、`save_product`、`world_resume_regression`、`world_interaction_residency`、`world_interaction_safety`、`world_route_access`、`world_host`、`story_guidance`、`first_court_experience`、`narrative_outcomes`。
- `build_slots_ui` 在无头模式截图时会触发已知的假渲染器错误，与本批无关。
- 真实 GL 实拍在 `artifacts/survey_tools/`，由 `tools/capture_survey_tools.gd` 生成：商人出售绘针和罗盘、未装罗盘的地图、装上罗盘的地图。

## 注意

- 本批基于 main，地图商店仍使用常量价格。#113 已修正为按各区商人价格扣费，两边会在 `cartography_runtime.gd` 的同一段代码产生合并冲突，合并时保留双方改动即可。
- #113 的经济审计还没有把绘针（10）和罗盘（15）计入一次性消费。两者合并后，一次性消费会增加 25，比例仍在审计范围内。

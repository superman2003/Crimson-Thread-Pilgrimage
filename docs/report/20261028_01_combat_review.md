# C02/B03：战斗复盘汇总与同构筑观察比较

本批是原台账的功能子项，不关闭整项最终验收。范围说明：[PR #416](https://github.com/superman2003/Crimson-Thread-Pilgrimage/pull/416)。输入基线：`a9457669a4a1a08f885c96c95c80a069d059f7ff`；本批独立面向 main，不继承其余九批代码。

## 原有缺口与交付

原复盘页逐条查看原始计数，只能比较筛选列表相邻一条；难以核对同一地区、同一契印的多次观察。

新增观察汇总窗口，可选全部、所选地区、所选地区与契印三种范围；显式选择同地区同契印基准，周期刷新保留基准。按总有效时长加权计算针击/承伤速率，零时长保留计数但不参与速率；无格挡或疗伤样本显示不可计算。

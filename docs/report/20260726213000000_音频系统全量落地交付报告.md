## 二、运行时系统(新建 `godot/scripts/audio_director.gd` + 三脚本集成)

- **AudioDirector**(由 `main_level._build_audio` 实例化,非 autoload,headless 安全):按章选探索曲/战斗层/环境床/摇篮曲;BGM 无缝循环(`stream.loop`,删除 finished 手动重播);音量四滑条(master/music/sfx/ambience,V 键面板,存 `user://audio_settings.cfg`)。
- **双层音乐状态机**:0.25s 轮询敌群 AI 决策判定接敌,战斗层 0.8s 淡入/脱战 2s 冷静后 2.5s 淡出(总线 MusicCombat)。
- **Boss 音乐按章**:`_spawn_boss` 起本章 Boss 曲;终 Boss 按血量 2/3、1/3 切三乐章;Boss 亡/玩家死亡重置恢复探索曲。
- **子总线**:MusicExplore/MusicCombat/MusicStinger(→BGM)、SFXPlayer/SFXEnemy/SFXWorld(→SFX)、ReverbZone,落盘 `default_bus_layout.tres` 且运行时幂等兜底;UI 音全部改道 UI 总线(干声,不再被章节混响污染);玩家/敌人/世界音源分道。
- **六类 ducking 补全**:Boss 入场、玩家死亡(原有)+ 对话开合(Music-4dB)、关键道具拾取(-6dB)、钟龛摇篮曲切换、死亡 300Hz 全局低通。
- **声部管理**:静态 `AudioDirector.request_voice`(同 key 最小间隔/并发上限、全局 24 声部、P0>P1>P2),player/enemy/main_level 全部播放调用前置。
- **濒死低通改扫频**:2kHz 起 2s 滑向 800Hz(关断为守验证断言当帧摘除)。
- **房型混响微调**:hub/vista wet+0.10、corridor/secret −0.08,0.6s tween。
- **接线的 asset_ready 事件**:hook_latch/hook_reel、boss_windup_light/lethal(按伤害分档,替换 heavy_hit 复用)、elite_ritual_start(generated ch03–06 生效)、敌前摇音弃用 player_hook.ogg;另接普攻三采样轮换±4% pitch、落地软/硬、受击三材质档(moss/fiber→soft、salt/silent→shell、copper/obsidian→armor)、六 Boss 四件套、脚步 ch04→glass/ch02→wet。

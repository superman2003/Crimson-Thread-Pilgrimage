# 第六章钟舌库挑战房（B04 续）

修订方案 B04 要求可选挑战（挑战房、精英、追踪狩猎、可选 Boss）可暂缓、可回访，奖励与难度匹配，并关联工具／证据／成长。前批（#121／#122／#123／#124）覆盖了一至五章；本批补**第六章无声王冠核心 · 钟舌库**挑战房（冠下回声／钟舌相关支路）。精英首胜仍见未合 #118。

## 问题

可选挑战房尚未覆盖王冠终章。钟舌库本就是核心竖井底的补给／可选冠下回声碎片／西环拉杆支路，适合落地一间可绕开的余响钟试炼，而不抬高地区清敌、不挡西环捷径与王座前廊主线。

## 改动

- 在 `demo_ch06_silent_crown_core` 增加 `optional_challenges`：**钟舌试炼**（`challenge_room`）。西侧封门至清场，东侧库区与下坠前廊仍可撤离；两只精英（坠舌钟锤、回声苔幼）。
- 首清 40 碎钱、2 王冠回声守卫碎片、证据·钟舌余响；清场标记写入存档后不可刷。
- 钟舌库 `guide` 注明余响钟；未改 `world_routes`（钟舌库非检修工房源房间，再生幂等不受影响）。
- 挑战敌人仍不计入地区清敌进度；经济审计计入本批一次性挑战收入（+40）：收入 2520，一次性消费占比约 35.7%。
- `optional_challenges` 套件增补第六章封门推人、首清／防刷、跨区与存档保留检查。

## 验证

- `optional_challenges` 正式 World：ch06 封门按试炼侧推人、首清发奖、再进不刷、存档跨区保留（含 ch01～ch06）。
- `npm run test:campaign`（含经济审计）与 `npm run test:optional-challenges`。
- `tools/test_workshop_layout_contract.py` 再生幂等。

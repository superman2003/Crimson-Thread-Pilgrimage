# T03：敌人落点搜索跳过不可能胜出的候选净空检查

隔离诊断发现铸雨渠切区构建 cursor 295 约 223ms 的尖峰。对真实 World 的 `_enemy`、落点、边界、预制体和净空查询分别计时后，确认 E04 `bell_mote` 的备用落点搜索是来源：单次生成 225,988µs，落点搜索 223,500µs，1,371 次净空检查合计 222,296µs；移动边界只有 1,066µs。原定点上方没有足够空间，算法回退遍历全区平台及其扫描点，即使已经找到更近的安全位置，还在检查无法胜出的点。

本批只将两个搜索函数中的原评分计算移到几何净空检查之前：如果候选分数大于或等于当前最优，就不执行该点的净空查询。候选集合、枚举次序、评分表达式、首个同分赢家、平台偏好和完整地形/岩体碰撞判定均沿用。没有缓存、空间索引或新的失效协议，也没有缩短搜索范围、移动敌人、减少敌人数、改伤害或调整帧预算。

# U05：手柄右摇杆可以滚动长文

接续台账 U05“不同字号与实体手柄长文体验”，起点为 main。所有 46 个任务包的最终验收仍开放。

## 改动前

旅记正文、物品说明、各工作台的详情栏、来源与许可、多件制作清单等长文，只能用鼠标滚轮、拖动滚动条，或在旅记里用键盘的 PageUp/PageDown/Home/End 滚动。手柄没有对应的输入：说明一长出可视区，手柄玩家就看不到后面的内容。十字键能把焦点移到部分正文上，但并不是所有正文都能聚焦（见 U02 报告的边界）。

## 现在

- 打开任意界面或对话框时，右摇杆上下滚动当前的“阅读区”。默认绑定里右摇杆在游戏中未使用，而且只在界面打开时生效，所以不会和操作冲突。
- 阅读区的选择：有对话框时用最内层的可见对话框（包括挂在关卡下而不在界面层下的对话框，如结局阅读台），否则用当前页面。焦点所在控件或它的祖先里有可滚动区域时优先滚动它（比如在制作清单里聚焦某一项时滚动这张清单），否则滚动该层面积最大的可滚动正文。原生列表（ItemList、Tree，如地图目录）也算可滚动区域。
- 速度：满推每秒 900 像素，按推杆幅度线性缩放。死区沿用设置里的手柄死区，滚到文末自动停住。滚动条按整像素走，不足一像素的推杆量会累积到下一帧，轻推也能慢慢滚动。旅记的阅读位置记忆按原有逻辑照常保存。
- 实现：`reading_scroll.gd`，由界面 `_process` 调用；`reading_axis_override` 只给测试夹具用。

## 验证

- 新默认套件 `reading_scroll`（正式 World）24 项：死区换算，非有限值无效；无手柄时不滚动；游戏中推右摇杆不移动角色；行囊里最长的旅记正文能向下滚、按推杆幅度向上滚，松杆停住，滚到文末停住，选中的记录不变；打开“来源与许可”后滚动的是对话框里的文字，不是背后的页面；在多件制作清单里聚焦一项后，滚动的是这张清单，每帧 0.4 像素的轻推连续 10 帧也能滚动；挂在关卡下的对话框里聚焦一个超长 ItemList，它是阅读区并能滚动。无手柄时为 0 的检查只在本机确实没有连接手柄时执行，不会因为桌上手柄摇杆漂移而失败。
- 反向：去掉 `_process` 里的滚动调用，5 项失败；用审查前的 `reading_scroll.gd`（不含 ItemList、关卡对话框与累积），4 项失败。
- 相关套件见 PR 说明。

## 边界

headless 夹具里没有真实手柄设备，摇杆读数通过 `reading_axis_override` 注入；`stick_axis()` 只验证了无设备时为 0。实体手柄的手感与速度待 T04。右摇杆如果被玩家改键绑到某个动作上，界面打开时它仍会同时滚动阅读区（游戏动作在界面打开时本来就被锁住）。

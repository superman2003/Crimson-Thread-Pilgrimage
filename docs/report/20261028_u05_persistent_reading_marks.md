# U05 旅记与对话：显式跨启动阅读位置标记

基线 main eeaae57f72728abae5a8076dbc26bcaf75f68a24；从08e8e0c实现后核对新主线只增加已认领说明/报告，没有改本批生产方法。已有journal_reading只在World会话中保留位置，本批保留该自动行为，另增玩家显式保存/恢复的本机当前槽阅读标记。

旅记选择已知文档后，“阅读位置标记”可保存当前位置、恢复、删除、重试或明确放弃待保存操作重读文件。只存文档key、内容指纹及有界数字，不保存标题、正文、任务标志或旅途数据。同版式恢复精确像素；宽度/字号改变时按原阅读比例定位，说明这一边界。内容指纹变化拒绝旧位置但保留旧标记。最多64份，容量满不静默丢弃旧标记。

使用既有严格偏好文件事务，在其持有锁并移开原文件后，独立子类核对被移开原文件身份；即便另一实例在预检后写入，也拒绝候选并恢复对方新记录。成功后保留已安装候选的实际身份，避免解锁后另一写入被错认成本次成功。没有修改共享事务实现、原断言或超时。保存失败保留旧记录及明确待保存操作，不能被新按钮静默丢弃。

窗口绑定当前槽/文档/阅读代际，关闭行囊或文档变化时退役；恢复仍走原延迟阅读恢复和代际检查。新入口与资源用途、追踪和复盘按钮分开；原说明实际文字保留且缩窄可用矩形，避免控件重叠。普通滚动、切页和关闭不自动写新偏好。

# PR #27：场景路牌与一次性交互教学

2026-10-13，承接 ab607e9。针对出口悬空名称和管道左上常驻说明，改成有立柱的青铜路牌：地区徽记加箭头，苔钟庭为钟、铸雨渠为砧、书库为书、温室为叶、黑曜为晶、王冠为冠。通路未开启时用锁/能力菱形区分，不再画“闩/缺/F”。管道中段没有路牌，也不再显示距离、步行和 Esc 常驻说明。

所有钟龛/休息点共享火焰图标；NPC、地图购买、机关等使用不同图标。浮动交互图标只在当前选中且可交互的近处对象显示，叠加当前绑定按键；离开或打开菜单后收起。常驻 HUD 交互长句与地图商人悬空价格删除；价格仍在购买界面显示。连续显示的操作教学默认关闭，仍可在设置启用。

文字教学只在第一次遇到一种交互方式时短暂出现。例如首次休息提示一次，后续所有休息点均不重复。通过 `tutorial_interaction_seen_<type>` 的持久剧情标记写入现有存档；按类型区别交谈、购买地图、操作机关、步行通道和按键通路。新旅途重新教学，继续存档保留已看状态。既有门槛、主动交互失败反馈、对话和菜单信息继续使用原逻辑。

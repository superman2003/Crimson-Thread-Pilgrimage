# 第四章蜂蜡暗屋挑战房（B04 续）

修订方案 B04 要求可选挑战（挑战房、精英、追踪狩猎、可选 Boss）可暂缓、可回访，奖励与难度匹配，并关联工具／证据／成长。前批（#121／#122）覆盖了一至三章；本批补**第四章断弦暖房 · 蜂蜡暗屋**挑战房。精英首胜仍见未合 #118。

## 问题

可选挑战房尚未覆盖暖房线。蜂蜡暗屋本就是补给／暗灯支路，适合落地一间可绕开的余响钟试炼，而不抬高地区清敌、不挡东藤壁主线。

## 改动

- 在 `demo_ch04_broken_string_greenhouse` 增加 `optional_challenges`：**蜂蜡试炼**（`challenge_room`）。西侧封门至清场，东侧仍可撤离；两只精英（棘哨、蜡蜂）。
- 首清 40 碎钱、2 花粉蜡、证据·蜂蜡余响；清场标记写入存档后不可刷。
- 暗屋 `guide` 注明余响钟；`world_routes` 覆盖按章节 guide 重生，与检修入口文案并存且可再生幂等。
- 挑战敌人仍不计入地区清敌进度；经济审计计入本批一次性挑战收入（+40）：收入 2440，一次性消费占比约 36.9%。
- `optional_challenges` 套件增补第四章封门推人、首清／防刷、跨区与存档保留检查。

## 验证

- `optional_challenges` 正式 World：ch04 封门按试炼侧推人、首清发奖、再进不刷、存档跨区保留（含 ch01／ch02／ch03／ch04）。
- `npm run test:campaign`（含经济审计）与 `npm run test:optional-challenges`。
- `tools/test_workshop_layout_contract.py` 再生幂等。

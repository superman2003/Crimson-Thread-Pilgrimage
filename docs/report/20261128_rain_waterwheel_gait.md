# 铸雨渠水轮骑士：停步与转身

对象是铸雨渠的普通水轮骑士 E06，不是王冠的回声骑士。旧版在地面刹停时会先走最后不到 0.1 像素的一小步；表现层已把它算作静止，等到真正切站姿时反而播不到停步。巡逻折返也直接换朝向。

- 步行转静止时，继续认可最后一个可测到的水平步幅；只作用于仍请求走路的地面单位，原有攻击、暂停与死亡优先规则不变。实际位移不变。
- 原生产清单追加 0.16 秒停步与 0.18 秒转身各一段。每段以当时已经显示的姿势接入，后接六张为普通水轮骑士绘制的新图。保留原 idle、walk、冲锋、轮回和命中动画及其清单参数。
- 新图使用内置图像生成制作，按原 376×230 逻辑画布和落脚线注册；转身后半程的最后两张采用反向朝向注册。未复制王冠回声骑士的材质，未插值合成动作。提示词、原稿校验和、图集裁切记录见[素材来源](20261128_rain_waterwheel_gait_sources.json)。

## 验证

在真实铸雨渠 World 中，以一次固定起点复现 E06；启动后只走正常移动与跳跃输入，保持伤害开启，没有移动敌人、改血量或跳过攻击。前后分别回放 900 个物理帧；旧版无转身或停步片段，修后分别启动 3 次，覆盖各自 7 张动作帧。第 15 帧的停步会在第 20 帧被正式招式正确打断。双方位置、速度、玩家血量、敌人决策、转向要求、攻击时钟、命中以及攻击阶段的画格和朝向逐帧一致。双方均观察到 2 次攻击完成，玩家最后剩 4 HP。后续走路动画可从另一张接入，因此走路帧相位不要求一致。

带合成分支本机测试中，未加素材时 3 条新增资产断言失败；只加素材不修判断时，亚像素刹停断言仍失败。全部修正后 92 项通过。以主线资源加载器和战斗脚本隔离复验，动作测试 85 项通过。三端静态导出审计通过。这次是生产关卡的固定输入回放，不是整章桌面试玩或三端实机认证。

独立分支的战术测试以正常实时时钟重跑，旧版与新版均为 294 项通过。

# U01：四个主页面统一字号

## 问题

在正式 World 中、1280×720 下逐个打开行囊、构筑、地图、设置四个主页面，收集各页面浮层（`BackpackOverlay`、`BuildOverlay`、`CourtMapOverlay`、`AudioSettingsOverlay`）上的全部可见文字：

| 页面 | 改前字号 |
|---|---|
| 行囊 | 11, 12, 13, 14, 15, 16, 17, 18, 20, 23 |
| 构筑 | 11, 14, 16, 17, 18, 21 |
| 地图 | 12, 13, 14, 16, 17, 21, 23 |
| 设置 | 11, 12, 13, 14, 15, 16, 17, 18, 20 |

层级本身是清楚的（面包屑 11、页标题 18、分节 20、地区／物品名 23），乱的是 13 与 15 两档：

- **次级功能按钮**：行囊和构筑是 14，地图是 13，设置是 14 或 15；
- **提示文字**：分别用了 11、12、13、15；
- **物品角标**：是 13，而同类的计数文字是 12。

颜色基本一致：三种主色，另有地图页一种纸色，这次没有改。

另外发现一个显示问题：地图工具栏的图钉下拉框宽 150px，默认文字“图钉 0 / 12 · 请选择”在 16 号字下超出控件，尾部被截掉。

## 改动

新增 `godot/scripts/ui_type_scale.gd`，按用途规定九档字号：

| 用途 | 字号 |
|---|---|
| 面包屑 | 11 |
| 提示、图例、计数与角标 | 12 |
| 次级操作（功能入口、筛选、存档槽、工具） | 14 |
| 正文与数值行 | 16 |
| 主操作（返回等） | 17 |
| 页标题与开关 | 18 |
| 分节标题与分类标签 | 20 |
| 阅读基准 | 21 |
| 地区与物品名 | 23 |

四个页面上原来用 13／15 的 26 个控件改为引用这些常量，涉及 12 个文件。行囊的旅记视图里另有 17 个 13 号控件（10 个分类筛选、仅未读／仅收藏、排序、本条查找、标为已读、收藏记录、筛选结果标已读），一并改为 14。钟龛工作台装备面板上的 6 个 13 号控件（搜索、仅可装入此槽、卸下此槽装备、查看补给报价、确认购买补给、按需与优先补给）同样改为 14。改后全部能容纳在原控件内，`pilgrimage_interface.gd` 中已没有 13 号字。归档规则：

- 按钮 13／15 → 14；
- 提示与角标 13／15 → 12；
- 行囊物品分类计数行 15 → 16；
- 装饰动态按钮：“未存”状态的文字较长，用 12，平时用 14。

图钉下拉框改为 14 号，与工具栏其他控件一致，文字可以完整显示。

## 旅记正文跟随阅读字号

行囊右侧的物品／旅记正文（`bag_description`）是最长的阅读文本，原先固定 17 号，不跟随设置里的阅读字号。对话框正文和构筑详情早已跟随阅读字号，它是遗漏。现在按 `journey_window_layout.scaled_font` 的同一比例缩放，原框本身可以滚动：

| 阅读字号 | 正文字号 |
|---|---|
| 17（最小） | 14 |
| 21（默认） | 17，与原先相同 |
| 26（最大） | 21 |

## 验证

新套件 `page_type_scale`：四个页面、行囊旅记视图和钟龛装备面板（技能、战具两类，沿用 `build_slots_ui` 的工作台夹具）的可见文字只使用这九档字号，且单行 Label／Button 的文字宽度（含按钮边距和图标）不超出控件。原代码上报告 48 处字号不符（默认视图 26、旅记视图 17、装备面板 5，搜索框不是文字控件不计）和 1 处截断。改后通过。套件同时检查旅记正文在默认阅读字号下仍为 17，且随 17／21／26 三档递增。

## 对话框内文字截断

页面能打开的对话框此前只检查“整窗在屏内”，没检查窗内单行文字是否超出控件。用同样的测量方法扫描了四个页面的全部对话框：21 个对话框各在阅读字号 17／21／26 下打开，共 63 次，测量 366 个单行控件，没有截断。这项检查已并入 `dialog_viewport_fit`（每个对话框、每档字号一项，共 42 项），防止以后回退。

- 页面内弹出的对话框已由 `dialog_viewport_fit` 跟随阅读字号；HUD 不在本次范围内。

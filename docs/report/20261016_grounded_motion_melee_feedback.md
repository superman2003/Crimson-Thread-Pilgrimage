## 失败记录与边界

1. 初轮导入继承不可写home下XDG路径，虽然进程exit0，严格门禁检出10条环境ERROR并拒绝；改工作区独立XDG后完整双轮复验，不计旧轮成功。
2. 早期足锚测试3项失败来自float32 alpha阈值与源图整数阈值不一致，按round(alpha*255)>128统一后，未改脚锚行为目标和断言。
3. player_upgrade_regression、melee_recovery、ability_movement保留ObjectDB退出warning，未归因；不声称全局无泄漏。
4. 手柄请求与停止逻辑通过模拟设备验证；云端无实体手柄，震感强弱/舒适度尚未验收。真实音效沿用现有链，此批没有全量听感认证。
5. 用户仍未认可待机循环，不能将本批称为“待机漂移完全修复”。现有普攻有效阶段仍是既有动作帧，短尾迹不是新增完整挥砍关键帧。新imagegen源帧未过一致性审查，不接入本批；房间稳定纵向镜头也单独推进。
6. 软件渲染同场景实录约19fps，仅为当前云环境观测，不承诺目标硬件帧率，模拟60Hz不能当成实际FPS。没有用插帧/变速隐藏问题。

# 地区材料工匠用途（E04）

修订方案 E04 要求材料有补给以外的用途与事务取舍。此前四种战具材料（苔壳／湿壳／盐晶碎片／花蜡）只进钟龛补给；技能校习配方的 `materials` 为空。

## 设计

- **校习耗材**：六个 `upgrade_*` 各耗 1 份对应地区材料（缝名向苔壳、校录向盐晶、司铸向湿壳），与既有碎钱校习费叠加；不改校习碎钱总额（仍 660），经济审计消费占比保持 35.9%。
- **工匠制作**：四条 `craft_*`（`kind: passive`）用 2 份地区材料＋少量碎钱，唤回已有铭饰（工匠线轴／铜背扣／盐页书签／静钟碎片），与人物传授／可选挑战唤回并列；已拥有则拒绝，事务失败仍走既有回滚。
- 第五／六区掉落（无战具补给）本批不强制进配方，避免无落点硬造槽。

## 改动

- `build_catalog.json`：校习 `materials`；新增 `craft_reflux`／`craft_shell`／`craft_spur`／`craft_mender`。
- `build_system_validation`：配方数 10；校习有材料；新档工匠制作与缺料拒绝。
- `build_transaction_runtime_validation`：失败校习夹具补苔壳，使请求到达存档失败边界。
- `tools/audit_economy.py`：战具补给材料必须另有配方水槽；校习不得空材料。

## 验证

- `audit_economy`：income=2840 sinks=1020 share=0.359。
- `build_system_validation`：96 项通过。
- `seal_acquisition_validation`：既有门禁保持。

# S02：脚步声与画面上的落脚同拍

2026-11-03。台账 S02 的下一验收交付包含“动作同步”。主角跑步姿态由位移驱动：`run_cycle_phase` 每走 `RUN_CYCLE_DISTANCE`（95px）推进一个完整周期，8 张跑步图的第 0 张是左脚落地、第 4 张（半周期）是右脚落地，所以画面上每走 47.5px 落一次脚。而脚步声另按 `FOOTSTEP_STRIDE`（88px）独立计步：

- 每个跑步周期只响约一声，左右脚只有一只有声；
- 88 与 95 不成整数比，声音相对落脚持续漂移，停步再起步时还会被重置到半步，与画面相位无关。

## 改动

`_update_ground_motion` 推进跑步相位时，同时统计这一帧跨过了几个落脚相位（0 与 0.5）；`_update_footsteps` 在有跨越且仍着地、不在冲刺/攻击、移速不低于 60 时播一声（与原有条件相同），否则丢弃。删除独立的 88px 步距计数。材质选择、语音限流（`player_footstep` 最多 2 个、90ms）不变。

## 验证

`player_motion_continuity` 新增：真实地面上按住右移，加速到巡航的 30 帧里，脚步声次数必须等于跑步相位跨过的落脚次数，且每次响起时相位都刚过落脚姿态（半周期内余量 < 0.15）。改动前这一项准确失败（跨过 2 次落脚只响 1 声，且在相位 0.466 即右脚落地前响起），改动后通过（1197 项）。`player_melee_feedback`、`player_layered_idle`（软件 GL）通过。

## 边界

只同步主角跑步的脚步；跳跃落地、冲刺、小怪脚步不在本批。实际听感（音量、密度是否过密）需人工试听。

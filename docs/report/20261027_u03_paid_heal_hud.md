# U03 战斗HUD：疗伤预留账目

本轮第11/40项。对应台账要求的绯线量、疗伤阈值和危险优先信息。

原HUD会在支付疗伤后显示减少的绯线和下一次疗伤阈值，但不显示
当前已支付的预留额。新增独立账目行与细条：当前预留、中断损失、
当前可退回数量；容量溢出用灰色斜线区分，避免误以为退款无上限。
这不修改疗伤、绯线收入、损失比例和练习结算。

原Player只增加只读reserved字段。界面通过实际get_heal_readiness读取，
显示与主绯线条分别表达“已预留”和“当前可用”。打开覆盖界面隐藏，
疗伤结束清除，敌人遮挡时沿用整组HUD淡化，无额外输入抢占。

Godot 4.6.1真实原生组件验证：新契约133项通过；原有构筑工作台41、
阅读会话355、装备UI58项通过，合计587。覆盖实际Player支付、中断、
完成与容量限制、实际生产刷新调用、覆盖界面隐藏、字典隔离、原生节点
退役与分段几何。严格runner负例自测通过。首次夹具缺少Player场景子节点
产生的错误已通过实例化真实Player.tscn修正；未放宽错误检查。

此验证使用显式资源和空中疗伤能力夹具，不等于自然取得该能力或完整
游玩体验验收。图形审美与实战阅读仍需后续实玩核对。

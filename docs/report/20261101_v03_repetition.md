# V03：同材质平台不再一模一样，岩体去掉镜像万花筒

接续台账 V03“正常房间前中后景，消除镜像装饰重复”，起点为 main `e56ff5c1`。所有 46 个任务包的最终验收仍开放。

## 改动前

- **平台**：`flat_map_art.add_platform_visual` 只按材质挑整块切片，普通岩台全部落到 2 号 `fractured_ledge`、不翻转。苔钟庭 145 块平台里，普通岩台都是同一个带蘑菇的浮岩剪影、同一朝向。关卡数据里其实已有作者给每块平台定的 `art.flip_h`，但代码只读 `material_flip_h`，这些朝向一直没生效。`main_level._decorate_platform` 从未被调用，是死代码，本批没有动它。
- **岩体**：`world_rock.gdshader` 用两格周期的镜像折叠掩盖图集接缝（1254px 原画）。接缝是没了，但大块岩体在两条折叠轴交叉处出现四向对称的“万花筒”花纹，一眼就能看出是镜像平铺（见对比图上半）。

## 现在的做法

- **平台切片**：每个地区按图集手工挑出风格一致、可互换的普通岩台切片（同号切片在不同地区不是同一种东西，所以逐区看图挑选），例如苔钟庭用 0/2/3/9 四种天然苔岩，铸雨渠用 0/2/3/4/10。普通岩台按平台 id 的哈希在这一组里选一种。仍然一块平台只用一种切片、一种朝向（原有“不混切片”“单一朝向”检查保留）；桥、青铜闸桥和首领地面不变；显式 `material_variant` 仍然优先。
- **平台朝向**：优先 `material_flip_h`，其次作者已写的整块 `flip_h`，都没有时按 id 哈希。按 id 选择，所以流式驻留重建同一平台时外观不变。
- **岩体采样**：两层不同世界偏移的镜像折叠，用低频世界噪声决定混合比例，再叠一层幅度 0.12 格的连续扭曲，把直的对称轴弯掉。每一项都是世界坐标的连续函数，所以不会引入新接缝；混合时按亮度差偏置，尽量保留其中一层完整的墨线，减少重影。`break_repetition=false` 可复现旧的镜像折叠，用于前后对照。
- **边缘衔接**：洞穴边缘（`ink_cave_edge`）的 `join_body` 原本按旧镜像采样岩体去衔接。现在两个着色器带同一段 `ROCK_SAMPLE` 代码块（逐字相同，由测试保证），边缘与岩体仍按同一采样衔接。没有用 `#include`，因为多个隔离契约只拷贝部分着色器，找不到 include 会编译失败。

## 验证

- `world_material`：2825→2828 项（原 2825 项中 2822 项为原有检查，新增平台变化与采样一致性检查），六区通过。新增内容：平台切片和朝向在重建后不变；作者 `flip_h` 生效；普通岩台只用本区岩台组；每区至少三种切片，单一切片不超过一半，两种朝向都有；两个着色器的采样块逐字一致。
- 反向：用旧的选择逻辑跑新检查，492 项失败（194 项作者朝向、280 项重建一致、每区 3 项多样性与朝向）。
- GPU 岩体探针 `tools/validate_rock_seams.gd`：12→20 项（真实 GL）。原有平铺/镜像接缝探针保留；新增“混合模式”接缝探针，要求格边跳变不大于图内其它位置的最大相邻跳变（普通平铺的真接缝为 1.0，单独出现在格边）。另加真实墨岩图集上的对称探针：在两条折叠轴交叉处，左右镜像差异从 0.0000（完全对称）升到 0.0571。说明：64px 合成渐变上，混合层之间的过渡是连续的，但在这个探针尺度下很陡（最大相邻差 0.48–0.82），所以混合模式只能证明“格边不比别处更突兀”，不能像镜像模式那样证明格边完全平滑；真实 1254px 原画下的过渡带约 18px。
- 其它 GPU 像素探针在新着色器下通过：`ROOM_RIM_PIXELS` 12、`STREAMING_PIXELS` 12、`WORLD_ATLAS_PIXELS` 5、`PASSAGE_PIXELS` 5、`REGION_COMMIT_PIXELS` 10。本地有一次 World 类探针报告“15 秒内未发布初始区域”，同一着色器连跑 3 次、main 着色器连跑 3 次均通过，判断为本机偶发；远端以 CI 为准。
- `cave_exploration`、`cave_route_walk` 通过；`tools/test_rock_gpu_validation.py` 通过。
- 真实 GL 截图（`artifacts/v03_repetition/`，上旧下新）：苔钟庭、铸雨渠、断弦温室各一张缩远全景，苔钟庭平台局部一张，大面积岩体一张。截图脚本为 `godot/scripts/capture_platform_variety.gd`。

## 边界

切片分组是按图集目测挑选，是否有个别切片放在某个房间里不协调，需要 T04 实际游玩时判断。岩体在少数位置仍能看出较弱的对称团（对称差约 0.057，不是 0）。新采样每个岩体像素多一次贴图采样和三次噪声计算，低端显卡的实际帧时间尚未测量。背景远景层的两张镜像拼接（滚动系数 0.075）和中远景装饰的固定 2560px 周期没有改动。

# S03 环境混音

对应修订方案原题 S03，以及台账剩余的“低通音色处理”。基线为 main
`e17ff53206dca1d983d6f2018be3a28926ae9bbd`，独立于 U04 楼层批次。

此前敌人隔墙音仅衰减音量；本批将普通受遮挡的单次音效路由到一个共享低通总线，
截止频率 2400 Hz，不额外增益，再送回原 SFXEnemy／SFX 链路。
危险前摇、确认与死亡尾音保留无新滤波的原路由；现有声部准入、优先级、衰减、音量、
用户静音和敌群行为均保留。每个播放只进行一次遮挡查询。

滤波总线只创建一次，复用同一效果资源；父总线移除或重排后按名称重新定位，保证
Godot 所需的从右向左混音顺序，不接管同名外部总线，也不修改原 SFX 总线的用户音量。

Godot 4.6.1 原生无头套件 639 项通过，使用真实 AudioServer 效果及真实 Enemy 播放函数，
播放器流为非空合成静音夹具，遮挡状态明确由探针注入。验证资源引用均为真实 VFX 文件，
不将合成音源说成原声音素材或实机试听；物理遮挡仍由既有 enemy_tactical_roles 套件覆盖。

新增严格 CI 保留退出码、引擎错误、完成标记和 120 秒单项预算。完整世界/GPU 检查按
新头 CI 另核；耳机/扬声器实听、环境声与 Boss 场地音的遮挡、S03 最终验收仍开放。

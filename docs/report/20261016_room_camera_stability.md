# A02：普通跳跃的稳定房间镜头与纵向视野

日期：2026-10-16。独立堆叠在动作反馈 PR #90 head `cfdd983f569a5d779aeb8f9c78f2263ea50290ce`。保留 #88 的路线和 main #87 planner，不含 #89 治疗或 #91 工房；只计本批镜头差量。

## 玩家改善与原因

原 Camera2D 继承 Player 的 Y 位移，局部位置再做平滑，会把普通跳跃反馈为上下跟随。现在将地面基线保存为世界空间镜头中心，立即抵消继承的 Y；横向预看、观察延迟、Camera2D 原平滑、房间/Boss边界及 FeelKit 震屏归属不变。

普通跳跃留在安全范围内，镜头中心保持稳定；登上不同高度的平台后，目标采用新层并经原平滑收敛。二段跳或长井下降离开安全范围后主动纵向跟随，按当前平滑延迟预留落点视野，关闭可选预看仍保持安全跟随。没有全局锁死Y，没有改变世界/玩家坐标或移动参数。

同区房间门沿用既有缓动边界和门槛迟滞，当前用生产规则夹具验证；first_court检查42个位置视图及5个命名点，不声称自然输入连续过门。本批不重置同高房门的纵向基线。跨区传送/复活仍保留原到达重置及有意切换，不能据此宣称所有跨场景切换都新增了平滑。

## 初轮验证（P2修复前）

官方 Godot4.6.1，真实 llvmpipe OpenGL，正常绘制，固定60时钟，每套原180秒。直接真实Player镜头套74项/0失败，另外 camera_focus86、first_court216、ability_movement与player_state_cleanup9均通过。实际Player使用生产场景、重力、跳跃/横移/观察输入和真实Camera2D scroll；普通跳高142.241px，画面Y变化0；二段跳镜头上移71.952px、最小头顶余量40.151px；3700px落差峰值3669.164px/s，最小脚下可视余量182.861px。

规则部分另覆盖30/60/120Hz、短/长普通跳、地面接触微校正、同高房门、Boss边界优先级及观察锁。真实Player局部夹具使用人工地板、预置二段跳与定位起点，隔离FeelKit以测摄像目标；不代表自然关卡通关、所有房间构图或人类手感验收。

镜头和既有ability套各有退出ObjectDB warning，未隐藏。镜头verbose复验74/0列出OggPacketSequence、AudioStreamOggVorbis及其Playback引用/SFXPlayer，没有镜头实例出现在该列表；不将它归因解决，也未修改音频范围。原日志本地保留，公开源码/日志SHA及准确指标见[verification](../../artifacts/room_camera_stability/verification.json)。

## 发布前P2修复与真实负例

独立审查发现预测中心采用单向min/max时，长坠落后贴墙或空中停顿会保留旧高速预测量，使镜头继续远离角色。已用生产Player、实际墙体/按右输入与实际dash复现：旧源78项/2失败，墙滑和空停头顶余量分别-279.82px/-211.35px；原74项仍过，证明旧套未覆盖该边界。

修复为进入纵向跟随后每帧重算可回收的速度预测，不保留过时单向极值。新78项/0失败，墙滑/空停最小头顶余量244.86px/246.96px，脚下182.86px/186.17px；原头>24px、脚>70px门槛及180秒不变。普通跳Y漂移仍0，二段跳/竖井原断言保留。复跑camera_focus86与ability_movement19均通过；无关first_court与状态清理复用原同路径结果。修前/修后源码和负正日志分别保存，未把旧74通过重标为修后。

# E05／U02：构筑方案恢复条件与资源预览

日期：2026-10-20。对应台账 E05“手柄恢复方案、代价预览”与 U02 导航子项。独立基于 main 2571f891。

原有方案页已经列出当前与保存的装备名称；缺的是恢复前的兼容结论、上限变化，以及保存按钮的焦点预览。新增 BuildSystem.preview_loadout，复用真实恢复的校验器，在隔离候选中计算目标 profile，返回能否恢复、拒绝原因与免费/不补充资源的规则。原构筑、库存、冷却和保存方案都不被预览修改，返回嵌套数组也独立。

方案页显示真实条件、生命与绯线上限前后值，并明确恢复不会补满生命/绯线/次数，也不会清空冷却；当前生命或绯线超过新上限时仍按既有行为截断。未保存或不兼容的恢复按钮禁用并给出原因，保存按钮仍可用且参与焦点导航。手柄焦点移到哪一行保存按钮，就预览那一份方案，避免保存/恢复两行的选择信息错位。

新增 7 项真实构筑模型检查与 6 项生产界面焦点/显示/动作检查。build_system 合计 94 项、build_slots_ui 合计 36 项、build_transaction_runtime 全部通过。逐套日志与结果见 artifacts/e05_loadout_restore_preview/verification.json。存档格式、实际恢复事务和资源结算规则不变。

本报告作为独立台账补记；手柄实体体验、完整配置流程与自然六区通关仍待验收。

# 改键覆盖全部操作与恢复默认按键（U06）

修订方案 U06 要求“重映射、手柄焦点、字幕字号/速度、闪光/震动/音量”。台账待验收项是“重映射、字幕、震动与关闭残留”。

## 之前的状态

逐项核对设置页：

- 字幕字号、字幕速度、镜头震动、镜头前瞻、手柄力度、受击闪光、手柄震动、探索提示、导航辅助都已真正生效。
- 改键的保存、读取、设备分组、冲突检测和保留键都已有，`input_settings_regression` 有覆盖。
- 在正式 World 实测：改过的键重启后仍保留，默认键不会被重新加回。

缺的有两处：

- **只有 9 个动作能改键**。游戏里实际要按的还有左右移动、上下（瞄准与上下劈）以及四个永久能力（回声钩索、钟壳格挡、灯影相位、王冠共鸣），它们都不能改。习惯其他键位或需要单手操作的玩家，能力键和移动键只能用默认的。
- **没有“恢复默认按键”**。改乱了只能去存档目录删设置文件。

## 改动

- 设置页的改键列表加入左移、右移、向上、向下、回声钩索、钟壳格挡、灯影相位、王冠共鸣，共 17 个动作。保存、读取、冲突检测、保留键沿用原有规则；改一个设备的键不影响其他设备的绑定。
- 新增“恢复默认按键”：一键把全部 17 个动作恢复为游戏自带的绑定并保存，声音、字幕与画面设置不变。默认值在本次运行第一次读取设置之前记录一次，所以不会把玩家改过的键当成默认。
- 改键区改为 4 列，按按钮的实际最小高度排版；提示文字和存档槽按钮保持原来的位置，所有控件都在面板内、互不重叠。

## 验证

- 新增 `settings_remap` 套件（正式 World，14 项、0 失败，加入默认 CI）：
  - 扫描 `player_controller.gd` 里所有按键读取（`is_action_*` 与 `get_axis`），除关闭界面、地图、行囊外都能改键。
  - 设置页有 17 个改键按钮；按钮、提示、恢复按钮与存档槽都在面板内、互不重叠；能力按钮写着能力名和当前按键。
  - 通过设置页把回声钩索从 K / X 改到 P，手柄按键保留；左移改到 Z。
  - 普攻改到 Q 被拒绝，提示写明冲突的是“钟壳格挡”；跳跃改到 M 被拒绝（保留给地图）；钩索让出的 K 可以给普攻。
  - 重启（新 World、新玩家）后改键仍在。
  - “恢复默认按键”把钩索、移动、普攻恢复为默认，并说明其他设置不变；再次重启读到的就是默认键。
- 受影响的回归通过：`input_settings_regression`、`input_prompt`、`ui_redesign`、`ui_world_integration`、`ui_build_accessibility`、`player_action_buffer`、`camera_focus`、`ability_movement`、`world_integration`、`save_product`、`combat`、`demo`、`pilgrimage_overhaul`、`map_player_pins`。
- `npm test`、`test:campaign`、`test:runner` 通过；截图在 Xvfb 真实 GL 下拍摄。

`pilgrimage_interface.gd` 的设置页与改键部分，新的 `settings_remap_validation.gd` 与 `capture_settings_remap.gd`，以及测试登记文件。没有动 `enemy_attack_effect.gd`、特效素材、`.gitattributes`，也没有动构筑、存档与叙事代码。

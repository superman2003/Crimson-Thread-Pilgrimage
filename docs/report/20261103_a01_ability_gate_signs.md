# A01：能力门在现场写明需要哪种能力

2026-11-03。台账 A01 的下一验收交付是“启用与取消、碰撞、门和说明逐项验收”。地图（`survey_map_knowledge`）早已标出能力门，但现场的 16 道能力门全部是同一种青铜桥／水闸材质、同一种颜色：玩家撞到一道门时无法知道它要的是冲刺、爬墙、二段跳还是下劈，只能打开地图去查。

## 改动

- 新脚本 `ability_gate_sign.gd`：每道带 `required_ability` 的门在门面视线高度（门底上方约 92px；横向的可破地板居中）挂一枚琥珀色圆牌，按能力画单笔画图标——冲刺双箭头、爬墙竖线加钩、二段跳双上箭头、下劈箭头加裂纹、灯相位虚线圈、冠鸣同心弧、回响钩。
- 玩家在 180px 内时，圆牌上方才显示“需要 · 能力名”（名称取自门数据的 `required_ability_name`）；远处只看图标，不在场景里铺文字，和现有路标/互动提示的做法一致。
- 圆牌是门体的子节点，取得能力或完成动作开门时随墙一起移除，不残留。

软件 GL 截图核对过：苔钟庭钟骨折梯的可破地板显示下劈图标，玩家靠近时上方出现“需要 · 棘线下劈”；垂藤井的爬墙门柱在远处只显示钩形图标。

## 验证

新套件 `ability_gate_signs`（Main 宿主，六区）：开局仍关闭的 14 道门（另 2 道因开局自带冲刺已开）都挂着对应能力的图标且名称非空；远处不显示文字、靠近显示；调用正式 `_unlock_ability_gate` 后圆牌随门消失；7 种门控能力各有自己的图标。85 项检查通过，约 25 秒。`ch01_room_reconstruction`、`all_chapters_demo`、`world_route_access`、`survey_map_knowledge`、`world_upgrade` 通过（后两者本机需放宽超时，与改动无关）。

## 边界

- 图标是程序绘制的占位风格，与手绘美术是否协调需人工看（V01）；需要时可换成美术出的门牌素材，接口不变。
- 只说明“需要什么能力”，不说明怎么到达能力取得点；那是地图与旅记的职责。

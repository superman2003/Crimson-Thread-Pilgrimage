# T02 存档迁移：当前槽旧旅途与已存进度只读核对

基线 main 08e8e0c22dbb8b62f45a0960684de522a1851fbc。原归档分页、单份详情、存档槽总览与主档/备份恢复差异均保留。本批针对不同历史旅途的逐项核对增加明确动作，不提供归档恢复或写档。

在设置“浏览旧旅途”选择有效归档后，可用“核对当前已存进度”。按旧旅途→当前已保存旅途显示碎钱、生命/绯线小数、具名行囊数量、分类装备、已知愿望/证词与已作出的终局选择。相同房间/捷径数量仍按实际已记ID核对共同与各自独有数量，不公开地点ID、坐标、未持有物品或尚未作出的结局选项。旧装备未说明与空槽分开，未知旧物品不混成同一物品。

两份源文件均采用原World只读校验、大小上限和前后身份核对；当前主档缺失/损坏不会被归档、备份或零状态代替。合法旧版仅在内存按现有迁移器读取，原始字节保持。界面保留原两回调入口，新比较回调为可选；刷新/换页撤销选择，重开/关闭拒绝过期结果，坏返回交回已有详情适配器。

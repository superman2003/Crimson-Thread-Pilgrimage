# 地区材料兑换

六区各两条邻区材料兑换，共十二条；只在本区钟龛办理，目标地区必须已到过，本区巡礼印须已持有但不消耗。每份花费三份本区原生掉落材料与八松脂，换取一份邻区原生掉落，一次一至十份。不可兑换印记、证据或能力。

实际构筑页入口提供数量、现存库存、完整报价与默认取消的原生确认框。确认重新取规范配方、检查地区/距离/凭证/资源/容量，再把付款及收入写入同一候选存档。写盘成功才发布内存；关闭、过期报价与写盘失败都不会扣款。

经济审计接入既有 audit_economy：规范配方与地区掉落匹配，每笔总材料减少二、松脂减少八，故任何非空兑换循环都亏损。独立单测拒绝增值比率、零费用、印记产出、错误印记及重复路线。

验证：Godot 4.6.1 软件 OpenGL MATERIAL_EXCHANGE checks=39 failures=0，含真实窗口、数量边界、无效数值、凭证、写盘失败、实际重读、过期确认、库存溢出和离开钟龛；Python 兑换审计与三项反例测试通过，整体经济审计保持 PASS。

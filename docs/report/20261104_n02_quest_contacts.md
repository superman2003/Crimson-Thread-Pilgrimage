日期：2026-11-04。对应跨区支线的回访引导、人物迁移与奖励一次性。

## 玩家看到的变化

正式旅记的已接取委托新增“接下来”，显示当前该做的事、联系人、实际房间，以及这一步与人物诉求的关系。五条委托共十三步；未接取委托不显示，之后的步骤不整份提前公开。

| 委托 | 当前目标与回访 |
|---|---|
| 把名字带回来 | 孩子 → 原页／残片 → 书记 → 钟庭学徒 |
| 西门的灯 | 下劈取得点 → 根笼囚徒；已保存迁移后到温室西门 |

| 不用回答的军号 | 军令 → 逃旗手；已保存迁移后到巡礼营地 |

搜索目标按真实收集物校验；能力取得点按 `world_routes.acquisition_plan` 校验。灯影穿行指向巡礼营地，避免误以为必须先击败镜池新娘。人物位置由正式 `npc_world_state` 解释，单凭任务完成标记不会捏造一次尚未保存的迁移。

## 完成、奖励与存档

- 进度仍来自 `WorldNarrative.quest_journal` 的第一项未完成步骤，不新增第二套任务状态机。
- 完成标记存在、奖励标记缺失的旧存档，提示回真正拥有该奖励的 NPC 核对。
- 已领奖励后只提示重逢，不暗示再次发放。
- 纯读取按既有存档重建；不传送、不消耗物品、不写任务或奖励标记。
- 布尔剧情标记严格识别；字符串不会凭空接取委托或移动人物，异常物品数量也不能跳过目标。

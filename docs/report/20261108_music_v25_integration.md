# Music v2.5 全量接入

用户于 2026-11-08 要求补生成缺失 Boss 曲，将全部音乐接入游戏并提交 PR。
`godot/assets/audio/bgm/ai_generated/music_pack.json` 记录 34 个音乐角色：
33 首实际音频以及第六区普通战斗的明确静默。原有三首已批准音频保留；
其余 30 首由 ElevenLabs Music v2.5 经 Vercel AI Gateway 生成。

六区探索、五区战斗、六位守门者、终战三乐章、六区钟龛、三个结局、快旅
站厅、出发/到站及隐藏区音乐均接入 AudioDirector。独立生成的战斗伴奏
作为单独的遇敌曲使用：0.8 秒淡入并暂停探索曲，脱战后以 2.5 秒恢复探索
乐句。没有把它们声明为已同步的 stems；温室战斗曲约 107 秒，较目标短。

当前代码把第六章守门人与终战王冠放在同一个 `silent_crown_core` 实体上。
因此《六城点名》播放为八秒入场段，随后进入《无声》；血量进入后续阶段
时立即换到对应乐章。旧入场回调在换阶段、离场或重试时取消。
钟龛回访在接受行程后播放出发短音，只有成功提交目的地区域才播放到站短音。

所有原始 MP3、提示词、来源、请求回执和 SHA-256 保留在
`art_requests/ai_music_v1/`。首次断连的执剪者请求回执也保留，用户明确授权后
以新的文件名补生成。生成工具不会自行重发已有回执对应的付费请求。
`tools/build_game_music_pack.py` 完全离线，按回执重建候选、验证哈希并安装音频；
不需要 key 即可运行或构建游戏。API key 仅供生成工具读取，不放入游戏资源。

自动验证检查所有 33 首音频解码、长度、循环/单次播放结束、实际场景选曲、
战斗/探索切换、钟龛/Boss 互斥、三个终战乐章、快旅、隐藏区与播放资源释放。
原始音乐风格、精确音符及 BPM 没有用自动检查冒充听觉验收。

生成来源与处理记录中的 `pending_listening` 是保留的素材审听状态；本次
运行时接入是用户另外明确授权的操作。它不表示所有音乐学要求均已人工验收。

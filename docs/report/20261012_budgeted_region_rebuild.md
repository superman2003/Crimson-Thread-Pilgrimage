# W00b2b：跨帧整区重建与取消恢复

2026-10-12。基线：PR #21 已合并到 `codex/persistent-world-host`，提交 `6de8f50697f900455762255fba04b6169eaa24db`。本批是 W00b2b 的异步装载子项；完整空间流式化与 W00c 未完成。

## 实际行为

真实 F 门户仍由 `WorldRoutes.access` 检查永久能力和远侧闩门；通过预检后进入异步加载器。离开时先中断治疗/探索动作并结算资源，再保存离开区。宿主和 Player/Camera、WorldState、BuildSystem 保持同一实例。

工作计划依次创建背景元件、逐块地形、钩索、升降笼、平台、能力门、危险、拾取、门户/机关、钟龛、NPC 和敌人。启动与独立章节同步执行同一计划，实际跨区跨帧执行；地图轮廓和最终碰撞内容保持一致。每帧最多八个直接子节点卸载或构建工作项；2ms 为下一项准入预算，单项不可抢占。

加载期间宿主处理及玩家碰撞关闭，完整遮罩显示进度和 Esc 返回提示。物理区域信号另外检查 `world_loading`，避免暂停处理仍触发伤害、拾取或交互。完成全部几何后才恢复玩家、更新存档和注册目标区域。预检新增有限数值坐标/地形轮廓检查，失败时不卸载原区。

Esc 取消或调用 `cancel_transition()`：完成正在退休的节点清理，清理部分目标，恢复离开时的 WorldState/构筑快照，再按预算重建原区，在原位置恢复玩家和镜头。源状态重建期间不能再次取消或并发跨区。未完成目标不会成为存档当前位置，也不会授予目标区域的探索/物品奖励。宿主退出会取消在途任务并延迟释放根节点上的加载界面，避免退树时修改忙碌父节点。

## 恢复边界

这是按永久状态快照恢复原区，不是逐对象撤销。原区敌人的瞬时生命、攻击、临时特效和临时 UI 状态会重建；离开时的治疗退款/能量损失不会撤销，探索动作已取消。永久进度、能力、构筑、货币、生命/能量、技能及移动冷却保留。没有把换装当作探索门条件。

普通入口仍是 F 与成对落点。玩法节点在活动区域内仍全部驻留；本批不包含按距离释放碰撞/敌群/NPC/交互、不包含邻区实体预加载，也没有连续步行跨区通道。复杂贴图、整块岩壁、HUD 与提交仍有同步操作。

针对性最终检查：`world_async_loading` 94 项、`world_host` 497 项通过。既有 `world_streaming` 1991 项、`world_integration` 64 项通过。真实输入导航 `world_route_walk` 25 步/1853 物理帧通过，明确使用免伤，不能计作 T04。`world_upgrade` 动作/门/奖励回归通过；敌人移除与定位仍为夹具，保留其既有 ObjectDB 退出警告。

`npm test`、`npm run test:campaign` 通过。完整 Godot 回归与图形证据会在本批结束记录追加；远端 CI 单独报告，不提前宣称通过。脚本断言不代表自然赚钱、完整六区带伤通关、听感或手柄体验。

## 实测预算限制

最终受影响套件的 headless 夹具：六区工作计划分别 285/293/139/131/115/97 项；每批最大操作数均为 8。准备阶段约 8–13ms，最大构建批次约 43–256ms，提交阶段约 97–191ms。具体原始微秒值保留在 `artifacts/world_async_loading/diagnostics/final_affected/world_async_loading.log`。数字包含素材缓存/共享运行环境影响，不是稳定帧率基准，也不表示最终画面每帧都在 2ms 内。

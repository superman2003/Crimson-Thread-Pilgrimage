# N03 主角表达：已确认短回应回顾

已有11段主角短回应在完整交谈完成后以短提示显示，却无法在旅记回看。本项将真正完成并成功保存的短回应、针线动作与共鸣回应纳入自述，包含当时地点、回应方式及此前已经读完的NPC末句。普通探索不启动额外对白或语音。

普通交谈的回应身份与原任务/奖励/人物回忆在同次保存中提交；心愿候选也准备相同身份，并只在原子写入成功后显示短回应。身份绑定NPC、完整原文、回应、方式和地区。未读完的打字机文字、未到末行、写入失败、伪造文本/奖励元数据均不能记录；旧存档的任务标志不会凭空重建“当时说过的话”。重复提交不重放回应或奖励。

使用现有布尔story_flags存身份，正文从规范叙事重建，没有新存档结构或持久化场景对象。自述页沿用搜索、滚动、已读和收藏，只检索已提交记录；切换到未获得回应的旅途会清除旧卡片。四套既有专项包含新回应事务与真实原生UI检查，工作流同时监听新增回应模块和自述接入文件。

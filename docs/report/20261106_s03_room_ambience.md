# S03：房间环境底声过渡

基线为 main `0fc65b199ef64c3c040c8035931f018f1e228b9b`。本批独立于待审 #541，不重复加入它的生产修复；另外以 #541 头 `1e5cc2cb4ab306ce19a4bda129f102adf1f80b67` 建立临时组合源码验证。新增三个 Godot 文件共 511 行（含实际回归）。

## 玩家可观察到的变化

六区各选两处通风空间、两处遮蔽空间，共 24 个明确房间身份。遮蔽处的连续底声在 0.6 秒内降至原来 -6dB，并通过 3200Hz 低通；走向通风处或未配置房间时平滑恢复，结束后旁路低通。这里只处理原本的弥散区域底声，不把它改为来自玩家位置的声源。

| 地区 | 通风配置 | 遮蔽配置 |
|---|---|---|
| 苔钟庭 | 东庭露台、雨眺台 | 织线暗室、顶阁暗格 |
| 铸雨渠 | 雨栅长堤、阀顶眺台 | 检修匍匐缝、听潮暗室 |
| 盐白书库 | 天顶盐桥、白盐码头 | 封存书堆、封蜡库 |
| 断弦温室 | 西眺台、东琉璃台 | 蜂蜡暗屋、根库 |
| 黑曜巡礼道 | 旗桥、上段砌道 | 黑曜哨站、瞭望塔 |
| 无声王冠 | 东冠肩、冠肋 | 雨渠回声室、钟舌库 |

这些是本轮明确编排的声学处理，不根据 corridor／secret 等通用房型推断其它房间。其余房间恢复原底声，不冒称整个世界已有人工室内／室外审听。

## 实现与所有权

`room_ambience_mix.gd` 是导演持有的子节点：只弱引用宿主和实际底声播放器。正式 `configure_ambience`／`_start_ambience`／`on_room_changed` 三处现有入口负责绑定及更新，无主控制器 API、战斗、剧情或存档字段变更。

一个有效导演最多持有一个私有处理总线，只处理其底声并送回原 Ambience 总线，因此用户音量／静音、对话退让及房型混响继续在下游生效。音乐、SFX、空间环境点声和 NPC／敌人提示不通过此处理。房间切换不替换 Ogg 流、不创建新播放实例。快速折返取消旧 Tween，末尾旁路由 generation 与实际效果身份确认；退出停止 Tween、恢复播放器原路由并移除自身总线，不按名字删除外部替代总线。

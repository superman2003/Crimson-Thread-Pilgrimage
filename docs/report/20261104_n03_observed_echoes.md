# N03：观察遗迹之后的主角短自述

日期：2026-11-04。对应台账 N03 的语言边界与探索不中断。

## 玩家看到的变化

自述分类新增十二则短回应。六则以“已经明确记下的本地设施 + 亲手取得的本地证词”为条件；另六则在两处日常设施都实际观察后出现。每则保持九十字以内，并在正文后列出“记自”的已遇见来源。

| 本地回应 | 必须实际遇见的两类来源 |
|---|---|
| 把试音模合回去 | 开合试音模、井喉证词 |
| 把工牌翻过来 | 泵渠分流箱、档案舱证词 |
| 留下刮刀的边 | 运书压页台、改字原页 |
| 给停拍留个位置 | 接弦养根槽、母株证词 |
| 木条空出来以后 | 营床点名轮、重编名册 |
| 钥匙并未折断 | 钟舌分钥架、锁钥告解 |

六则跨城回应把送声与分流、轮班与整页、修书与接弦、养根与营床、点名与分钥、分钥与试音分别放在一起。回应表达巡礼者怎样理解眼前设施，没有替未遇见的人作证，也没有把推测写成确知的作者身份或居民意愿。

## 阅读与探索

- 不自动弹窗，不播放额外语音，不移动镜头，不打断行走或战斗。
- 玩家自己打开旅记的“自述”分类回看，阅读来源随同正文进入现有搜索。
- 分类明确写作“自述 · 观察遗迹之后”，与原有的“获得能力之后”区分。
- 一处设施单独观察不会制造一篇新对话；需要另一处已观察设施或真实持有的证词形成新的对照。
- 读取只返回独立副本，不修改观察、人物、奖励、证词或结局状态。

## 存档与信息边界

观察条件复用正式 `scene_history` 成功保存后的布尔标记。读到一半退出、存档失败或字符串伪标记，都不能当作已经确认观察。证词按实际正整数持有量判断，旧的已知／已读标记不能代替实物。

旧存档使用现有观察与物品自动重建；不新增一次性记录字段，也不因重复阅读复制条目。公开记录只含已经解锁的文字和来源，不附带未来条件表。

## 验证

- 4096 种“六处设施是否已观察 × 六份证词是否持有”组合逐条核对全部十二则回应。

- 数据门覆盖六城各自来源，反向植入六类错误必须检测失败。

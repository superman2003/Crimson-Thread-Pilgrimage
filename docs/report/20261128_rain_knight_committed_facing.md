# 铸雨渠 E06：冲锋不在地盘边缘反向闪一帧

## 复现与原因

在 Godot 4.6.1 Linux 云机用生产 World 场景，把测试玩家放在指定遭遇附近，再只发正常移动、跳跃输入。每个遭遇记录 460 个物理帧；不改敌人位置、指令或玩家伤害。初始落点是定位夹具，不是自然路线试玩。测试工作副本亦有独立的王座前廊优化，未改本次使用的两区配置。

- 铸雨渠 E06 水轮骑士的 `wheel_charge` 朝左发起。冲到地盘左限 x=4122 时，地盘裁剪把精灵朝向翻到右侧，下一帧又翻回来；此次攻击的实际方向仍朝左。
- 苔钟庭 E01 幼虫现有转身素材正常参与播放：记录到三次转身、三次完成攻击。此次未触发刹停，不能据此判断刹停或整体手感已验收，也不重复添同名画格。

地盘裁剪仍约束位置，巡逻仍在边界反向。只有战斗态改为保留已经承诺的朝向，让具体招式继续负责自己有意的换边。无攻击数值、判定、发生时序、素材或平台几何变更。

## 验证

- 同一段 E06 输入的 460 帧前后只有第 184 帧三项不同：方向、请求镜像、显示镜像。两次完成攻击、玩家生命、攻击时间及两者位置逐帧相同。E01 的 460 帧记录逐列相同。
- 用真实 E06 的 `wheel_charge` 新增边缘合约，旧实现 82 项中 2 项失败，修后 82 项全过；另 303 项战术回归全过。
- 不把这处修复记为普通水轮骑士新增转身/刹停素材，也不把场景定位回放当作完整桌面试玩。

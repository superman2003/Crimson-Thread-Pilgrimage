# 预览服务的媒体读取和请求生命周期

原服务对错误百分号路径会抛异常，文件路径仅做字符串前缀判断，媒体没有正确类型或范围响应，HEAD 仍发送文件流。此批统一实现异步文件读取、规范路径边界和隐藏目录隔离、GET/HEAD/405、206/416、ETag/304、媒体 MIME、流错误与客户端断开收尾，并清理换端口重试遗留的监听器。

验证：`node --test tests/preview-http.test.mjs` 通过。测试使用真实临时目录、目录符号链接和 HTTP socket，覆盖中文文件名、非法 URL、邻级目录、媒体分段/后缀/无效范围、条件请求与持续可用性。原源码反向运行在非法 URL 前即失败；原进程缺少异常收尾，使用外部超时结束，不把超时当作新代码通过证据。日志见 `artifacts/reliability_20261025/01_http/`。

新增专用 CI，不修改现有 npm 命令、Godot 运行时或其他 agent 的界面/奖励 PR。此服务仍是本地预览入口；没有构建发行包或完成自然流程/46项最终验收。本批基于 main 43fbcf88，单独审阅合入。

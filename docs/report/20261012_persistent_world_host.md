# 第一阶段 W00b1：持久世界宿主与整区生命周期

2026-10-12。承接 #18 世界坐标和存档基础；本批继续分阶段深化。

## 实现

World.tscn 既有根节点成为持久世界宿主。普通门户不再替换 current_scene，Player、Camera2D、WorldState、BuildSystem 和区域加载器保留实例；能力、货币、剧情、购图/补绘笔记及技能冷却沿用现有存档/共享状态。

world_region_loader.gd 将当前区域作为一个粗粒度内容块：目标路径、JSON、世界尺寸、基础集合和落点预检通过后才卸载旧内容，再用目标配置重建区域地形、敌群、NPC、地图、UI 和音频控制。预检失败保持旧区域及玩家。对外快照报告区域 ID、代次、驻留区域数和节点释放统计。

区域字段从未入树的原控制器实例获取 typed 默认值，逐项复位；SESSION_FIELDS 明确列出需跨区保留的共享对象。新增区域字段默认不会继承旧区值；新增会话字段应加入保留表。内容仍作为 Main 的直接子节点，以保持现有 NPC、能力门、UI 和既有回归的路径契约。

跨区先取消钩索、穿相碰撞例外、攻击、下劈与治疗，随后保存实际治疗中断结算。冲刺/防御/共鸣/技能冷却不因跨区清零。按区域登记宿主绑定 Tween，卸载前停止；延迟操作携带区域代次，旧代次及已释放参数不得操作新区域。抵达后刷新同一镜头的边界并重置平滑。

新旅途/换存档槽属于切换会话，允许创建新宿主和玩家；新旅途重置保留原调用的存档路径和 .previous 备份。

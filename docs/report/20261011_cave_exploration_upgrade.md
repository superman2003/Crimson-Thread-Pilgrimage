# 六章洞穴探索升级：调研与验证

此前版本已有手绘素材和局部连续坡道，但大量路线仍以悬空单向台阶组织，普通地形厚度约 100 像素，宽矩形背景区域没有实体洞壁。新版将普通通道挖在实心岩层中，增加特殊暗穴视野、可步行路段、物理升降笼和通过探索接通 Boss 通路的办法。

## 参考调研

研究来源是 Team Cherry 的[《丝之歌》官方网站](https://hollowknightsilksong.com/)、[官方洞窟截图](https://images.squarespace-cdn.com/content/v1/606d4bb793879d12d807d4c8/5b2edc7f-750c-4bcf-9216-e0cac388a585/01_grotto.png)以及[开发者游戏介绍](https://www.teamcherry.com.au/games)。官方介绍明确强调相互连通的手绘二维世界，包含苔藓洞窟、森林和城堡，并不全部是洞穴。

从官方洞窟截图观察到的空间层次：厚岩层形成地面和墙体，洞内背景有亮部，外围岩体与前景以深色压暗，行走空间与封闭空间容易区分。这是对画面的设计分析，不是对其私有引擎实现的推断。本项目的射线视野算法、岩层生成和升降笼均为独立实现，没有导入《丝之歌》的代码、图像或关卡。

## 实施改动

| 内容 | 当前实现 |
| --- | --- |
| 实体洞穴 | 六章 JSON 记录岩层碰撞矩形与轮廓。普通通道沿原有可行走路径挖空，枢纽大厅与 Boss 场保留较大空间；低矮洞顶连接上方岩层。外围岩体实际碰撞且不透明。 |
| 连续路线 | 新增 39 条平地/缓坡连接：六章分别为 10、11、5、7、5、1。坡度不超过 30°，避开能力门、已有平台净空和其他连接的头部空间。 |
| 竖井通路 | 每章一个 AnimatableBody2D 升降笼，F 从两端呼叫或在笼上启动。以 300 世界单位/秒连续移动，玩家可跳离；专用竖井避开已有实心和单向平台。 |
| 视野 | 普通区域默认完整显示，不叠加局部视野遮罩。仅 `map_rooms[].visibility: dark` 或整章 `cave_world.visibility: dark` 显式启用暗区；房间配置覆盖章节配置。目前仅第一章“假苔穴”启用，半径 360 世界单位。暗区使用 96 条物理射线约每 0.08 秒更新一次；普通区域停止射线扫描。岩层始终不透明，HUD 独立绘制。该机制为本项目设计，并非声称复刻《丝之歌》的视野算法。 |
| 探索推进 | 六章接通捷径拉杆即可开启 Boss 通路，不再必须清空全图小怪。原来的清怪开门方式与旧配置仍受支持；击败 Boss 才能通过章节出口。 |
| 提示与地图 | 章节入场提示、首位 NPC 路线说明加入洞道/升降笼操作；游戏地图加入升降笼落点标记，完整布局图显示岩层与升降井。 |
| 边界修复 | 在玩家物理移动前检查坠落边界，避免越界后被深层岩石碰撞推出、留在地图底部而未返回存档点。 |

原有章节结构、剧情、物品、敌人素材与攻击设计保留。攀爬、跳跃和高低差仍用于部分支线和竖向区域；本轮不是取消动作平台玩法，也没有宣称每个旧房间都已人工重绘。

## 验证

- `cave_exploration_validation.gd`：六章 170 项，覆盖出生点不埋入岩层、探索拉杆开门、升降笼上下行、正常玩家物理下上行与下行乘坐、呼叫、远程拒绝、步行与岩墙阻挡视线；真实 Godot OpenGL 渲染截图已生成。
- `cave_route_walk_validation.gd`：全部 39 条新连接，78 次双向物理步行，检查通行和保持接地，不输入跳跃。
- 保留并运行章节路线 270 项、物理/减速 12 项、复审回归 133 项、六章通关、46 类敌人及 104 个攻击序列、试玩、第二章、背包地图、Boss 试炼、战斗、生成运行时、章节注册、剧情引导、中文剧情和 MetSys 套件。
- 三个 Node 测试、JavaScript 语法检查、两项 Python 章节结构检查通过。
- CI 增加两项洞穴套件；各套件使用独立用户数据目录，避免音量设置测试被其他测试留下的缓存干扰。

截图来自验证脚本在真实运行场景中的定位与渲染，用于检查地貌和视野；不是完整的人工六章游玩记录。原有两条待处理 P2（跨章物品分类、攻击打断警示线）不在本轮修复范围，历史记录保留。

初版截图保留作地形历史参考，其中普遍局部视野效果已取消，当前仅特殊暗穴启用。

## 维护

安装 Shapely 后执行 `python tools/build_cave_world.py`，从现有章节配置重新生成岩层、步行连接与升降笼数据；生成器会先移除上一轮自身生成的节点，保留其他章节内容。运行时仅依赖 Godot 与 JSON，不依赖 Python。安装 Pillow 后执行 `python tools/render_current_gallery.py` 可更新布局图。

## 收尾核验

升级 PR：[PR #9](https://github.com/superman2003/Crimson-Thread-Pilgrimage/pull/9)。原提交 `c979a32` 的远端 CI 已通过全部 17 个 Godot 套件、三个 Node 测试和两项章节结构检查，代码与安全复审均完成且没有新增意见。收尾补丁让玩家在升降笼下层落点开启正常物理并接地，再执行上行，覆盖此前仅在关闭玩家物理时验证的上行路径；六章各新增一项上行前接地断言。原有路线、战斗和两条历史待处理 P2 保留。最终合并状态与补丁 CI 以 PR 页面为准。

## 视野规则修正

普通通道、竖井、大厅与 Boss 房恢复完整镜头视野。取消通过 `vault/grotto` 名称猜测黑暗区域的逻辑；第一章“假苔穴”明确配置为特殊暗穴，离开即恢复正常显示。可用房间 `visibility: normal` 覆盖整章黑暗配置。生成器默认写入正常视野，并保留既有章节与房间的显式设置。回归覆盖六章入口、进入和离开黑暗区域、章节与房间覆盖规则，以及实际玩家位置识别假苔穴。

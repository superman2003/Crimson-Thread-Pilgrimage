# S03：警戒拟声的距离与遮挡

日期：2026-10-20。对应台账 S03 的空间混音子项，独立于 S01 音乐续播 PR。

普通敌人进入交战时的一次材质拟声，原来使用 AudioStreamPlayer，无论敌人在哪都从全局位置发声。现在从实际敌人的世界位置创建 AudioStreamPlayer2D，原生衰减与声像随听者位置变化；900px 以外不发声，也不占声部名额。有效音源、听者必须仍在同一个 World2D 中。

音源触发时对已驻留地形做一次遮挡射线，只检测地形 bit 1、排除听者自身。遮挡时从原 -19dB 再降低 12dB，角色碰撞层不遮声。短促警戒音固定在本次接敌位置，不逐帧追踪或补建地形；原来的家族音色、1800ms 限频、每次交战一次、SFXEnemy 总线与音量设置保持不变。

新增 spatial_enemy_alert_validation，由默认 enemy_ai_behavior 套件运行，覆盖范围边界、非法坐标、原生空间播放器、真实墙体与非地形层、远处及退场音源不占名额、真实导演生成、重复限频及原生播放回收。音频退休与普通战斗回归一并复验；精确结果见 artifacts/s03_spatial_enemy_alerts/verification.json。

本批只处理进入交战的可选拟声，不改实际攻击危险音、AI 视线/仇恨或全局声部调度。耳机/扬声器实听、远处声景和混响层次仍待验收。本报告是独立台账补记，不将 S03 整项关闭。

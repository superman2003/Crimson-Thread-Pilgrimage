# 追踪狩猎与更多挑战房（B04 续）

修订方案 B04 要求可选挑战（挑战房、精英、追踪狩猎、可选 Boss）可暂缓、可回访，奖励与难度匹配，并关联工具／证据／成长。前批（#121）做了第一章挑战房与第三章可选首领；本批补**追踪狩猎**与**第二章挑战房**。精英首胜仍见未合 #118。

## 问题

可选挑战仍缺可循迹的狩猎玩法，且挑战房只覆盖第一章。第二章愿板／水表／档案舱本就有探索支路，适合落地第一猎与第二间挑战房，而不挡主线。

## 改动

- 扩展 `optional_challenges`：新增 `kind: tracking_hunt`。残迹交互写入 flag；齐迹前余响钟拒绝开打；齐迹后敲钟封门刷出猎物，首清发奖并闩死防刷。
- **第二章配重暗格**（水轮内暗格，可绕开）：挑战房，两只精英；首清 40 碎钱、2 湿壳、证据·配重余响。
- **第二章渠影追踪**：愿板侧与水表回廊各一道残迹 → 沉没档案舱余响钟；一只强化水轮骑士猎物；首清 50 碎钱、2 湿壳、证据·渠影爪痕，并唤回 `charm_shell_found`（铜背扣印记，与雨渠铁匠传授并列的成长路径）。
- 挑战敌人仍不计入地区清敌进度；经济审计计入本批一次性挑战收入（+90）：收入 2400，一次性消费占比 37.5%。
- `optional_challenges` 套件增补残迹门控、第二章首清／防刷／跨区保留检查。

## 验证

- `optional_challenges` 正式 World：残迹未齐拒开打、齐迹后首清、防刷、存档跨区保留（含 ch01／ch02／ch03）。
- `npm run test:campaign`（含经济审计）与 `npm run test:optional-challenges`。

# N02／U05：已经认识的人，还有哪些线索可以继续问

日期：2026-11-04。接续人物回忆的姓名与来源，把可主动继续的取证对话整理成可选回访提示。

## 可见条件

旅记“手册”分类按人物新增“回访”条目。只有该人物的普通交谈或可选追问已完整确认、并且当前材料支持至少一个尚未记录的现行问题，才会显示。

| 当前状态 | 页面行为 |
|---|---|
| 有材料，但没有已确认的人物交谈 | 不介绍人物或暗示其未来话题数量 |
| 已认识，但材料不足 | 不列出锁定问题或缺少条件 |
| 已认识且有可问的新问题 | 显示当前去处、问题标题与可自由回访的说明 |
| 基础回答已经听过，新材料支持展开 | 标明“有新线索可续问”，仍不展示新回答 |
| 现行回答已读完并保存 | 对应提醒撤下；没有剩余问题则整张回访页撤下 |

普通交谈中途离开而追问已经保存，也能证明已经认识这个人。仅有“见过 NPC”一类未经确认的旗标、物品或已知证物标签不算交谈记忆。

页面只复用正式追问解析器当前允许的问题，不新增任务、材料或结局条件。阅读不代替在人物身边打开追问窗口、完整阅读并明确确认。

## 去处与来源

二十五位正式人物的初始地点按现有房间包含规则绑定：嵌套房间优先于外层大厅，同时使用作者的访问区域。房间名从章节读取，不另写一套显示名。

囚徒与逃旗手跟随已保存的迁移去温室西门或巡礼营地。只有委托完成／奖励已领而没有迁移标记时，仍保留正式原驻点；字符串形式的迁移标记不成立。

每张页面能回看证明已认识此人的真实交谈。新的未听问题没有被伪造成人物回忆。页面身份以人物保持稳定，迁移或新线索导致正文改变时，旧的阅读指纹不会把新去处遮成已读。

## 验证

- 所有现行问题分别覆盖材料齐全但陌生、真实认识后可问、当前版本确认后撤下、基础已听后的展开提示；覆盖二十五位人物。
- 目录和所有去处对照六区章节，六类数据故障必须被拒绝，包括把歌者错放进包围它的外层树冠。
- 检查坏数量、非布尔记忆／迁移、未知人物、伪造交谈哈希、空提醒撤下、目录与公开记录副本隔离、JSON 恢复及迁移后的阅读身份。
- 正式 World 调用 Main 的房间解析器逐一比对二十五个初始位置和两个人物迁移落点。

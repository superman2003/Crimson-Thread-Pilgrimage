# 线术校习方向（C04，含 E04 材料用途与 U02 工匠页）

修订方案 C04 要求线术靠探索、人物和练习学习，成长要“分支改变打法”，并且“不给所有技能复制金币升等级菜单”。

## 之前的状态

六个技能共用一个两级菜单：每级伤害 +1、距离加 20（绯线穿刺 40、回声针 80），守钟架势和盐印缚线每级持续 +0.2 秒，只花碎钱。这正是方案说不要的“复制金币升等级菜单”。另有两个问题：

- 守钟架势的实际窗口被运行时卡在 0.65 秒，第二级（0.95 秒）买了等于没买（#130 发现）。
- 购买要在工匠旁进行，但构筑页只在钟龛处完整打开，工匠旁只有切换页，所以界面上永远买不成（#133 发现）。

#130、#131、#133 曾在线性菜单上补说明文字和工匠配方。线性菜单没有改；工匠配方唤回的又都是人物或剧情已经给的铭饰。所以这三个 PR 不合并，由本批取代。

## 改动

### 两个互斥的校习方向

每个技能两个方向，各是一种取舍：

| 技能 | 方向一 | 方向二 |
|---|---|---|
| 绯线穿刺 | 远刺：距离 +60，起手 +0.06 秒 | 连刺：起手 −0.06 秒、收势 −0.1 秒，伤害 −1 |
| 回声针 | 远针：射程 +200 | 重针：伤害 +2，射程 −160，绯线 +10 |
| 盐印缚线 | 久缚：定身 +0.4 秒 | 缚刺：伤害 +2，定身 −0.5 秒 |
| 守钟架势 | 长架：窗口 +0.1 秒 | 快架：窗口 −0.15 秒，收势 −0.08 秒 |
| 钟鸣震波 | 远波：距离 +100 | 震晕：敌人踉跄 0.4 秒，伤害 +1，距离 −40 |
| 断弦回斩 | 宽斩：触及 +30 | 快斩：起手 −0.05 秒，收势 −0.1 秒 |

每项数值都核对过，确实进入了实际招式：起手、收势、距离、伤害、绯线消耗、震波的踉跄、缚线的定身时间、架势窗口。`validate_thread_skills.py` 对十二个方向逐一检查 C03 的规则：满条可放 2–5 次、冷却不长于动作 0.4 秒以上、控制不能连锁、架势窗口不超过 0.65 秒。

### 先练熟，再选方向

- 在该技能的练针架上用这个技能命中三次，就算练熟；守钟架势要挡住练针架三次。普攻打练针架不算。
- 练熟后提示可以去找工匠，记录在存档里。

### 在工匠处购买

- 织线学徒、雨铸匠、蜂蜡商人处可以买。
- 价格按技能的学习地区：苔钟庭的两个技能 100 碎钱，铸雨渠的两个 125，盐白书库的两个 160；每次另付 2 份该地区材料（苔壳、湿锈甲片或盐晶碎片）。这些材料同时也用于战具补给，两者需要取舍。
- 之后可以付全价改选另一个方向；已是当前方向的不能重复购买。
- 购买沿用既有事务：存档写入失败时，钱包、构筑与冷却全部回滚。

### 工匠页（U02）

- 工匠旁打开构筑页，只显示强化页；钟龛旁仍是完整页。
- 列表标出“当前方向”和“需先练熟”。
- 详情列出当前方向、所选方向的实际数值变化和另一方向的说明，并提示两个方向只能取其一。

### 存档

字段不变：`skill_levels` 的 0 表示未校习，1／2 表示所选方向。旧存档里买过一级的技能会成为方向一；买过两级的会成为方向二。

## 经济

一次性消费按每个技能较便宜的一个方向计：770 碎钱。全游戏一次性收入 2540，消费 1010，占 39.8%。#118 的精英首胜奖励若合入，收入增加 300，占比为 35.6%，仍在审计下限 35% 以上。

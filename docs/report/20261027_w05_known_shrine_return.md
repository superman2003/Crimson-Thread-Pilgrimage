# W05 钟龛与交通：已知钟路回访

对应修订方案原题 W05，推进“已开站点缩短回访”子项。每区只列最近安坐、存档坐标与原作者钟龛一致的记录；未访问、默认 start、试炼 boss_trial 与损坏坐标不列出。当前必须在已安坐的实际钟龛旁、结束动作，且不在 Boss/试炼/通道切换或保存阻塞中。

回访查询沿实际配置的 world_portal，用既有 WorldRoutes.access 检查能力和远侧门闩，只可通过已访问地区。界面显示经过区域、目的地及零碎钱费用；取消默认聚焦。并不授予能力、站点、地图、生命、绯线或战具补充；正常区域进入的既有奖励/迁移规则保留。它不是现场可走路径的寻路预览。

确认、deferred 调度和异步预检结束后重新复核 fingerprint。回调持有 WeakRef，主节点存活但区域 generation 变化时不得清除新行程锁。沿现有 WorldRegionLoader 进行实际构建/回滚；只有此新钟路请求强制出发保存成功才开始卸载。失败在 prepare_region_handoff、碰撞变更和源区释放之前返回，普通步行通道原有内存继续策略保留。

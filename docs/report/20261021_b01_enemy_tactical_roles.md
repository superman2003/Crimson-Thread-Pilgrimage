# B01：敌人职责落到行为——伏击、报警与守点

台账 B01 剩余“视线遮挡、追击脱战和角色差异”。视线射线、拴绳、目标记忆与搜索最后位置此前已在 `enemy_actor.gd` 中实现；差异主要停留在招式和数值，46 种敌人只按地面/飞行/固定区分，伏击、报警这类职责没有对应行为。

本批为 `original_creature_combat.json` 的每个物种加入 `tactical_role`，生成器 `tools/build_creature_combat.py` 同步给出相同结果：巡逻 14、伏击 4（渠底蛭、盐页螨、回声苔虫、藤蔓爬虫）、护卫 4（齿轮哨卫、回声水轮骑士、两种荆棘哨卫）、远程 4、空中 11、报警 3（孢铃匠、无声号手、回声巡礼副统）、Boss 6。远程、空中与巡逻沿用原有决策层；新增三种行为：

- **伏击**：不巡逻，原地蛰伏（`lurk`）；只有玩家进入 150px（`ambush_trigger_range` 可覆盖）且视线通畅时才现身，现身后照常使用原有前摇与物种 aggro 范围；脱战后走回原位继续蛰伏。
- **报警**：首次发现玩家时，通知 420px 内仍空闲的同伴玩家最后出现的位置（8 秒冷却）。同伴把搜索点限制在自己领地边缘以内，仍需自己的视线才会进战，不会被引出拴绳范围；Boss、已在战斗或正在搜索的敌人不受影响。
- **护卫**：失去目标后不去搜索最后位置，而是回到岗位警戒（`hold_post`）。

“入口不偷袭”：三处伏击敌人离通道或起点不足 200px（铸雨渠 E10、盐白书库 E03、无声王冠 E04），用已有的刷怪点 `encounter_profile` 改为巡逻；其余 8 处伏击点都在 240px 以外，新套件对所有章节强制该距离。

新增默认套件 `enemy_tactical_roles`（178 项）：职责数据与移动方式/距离一致、每种职责至少一个物种；伏击的隐藏、现身与回岗；报警只通知半径内空闲的同伴、隔墙同伴被引来后自己看到才进战、领地边界与冷却；墙体遮挡视线、移除后进战、再遮挡后搜索、搜索结束脱战；护卫回岗；伏击点远离入口。分别拿掉伏击、报警、领地限制、护卫回岗四处逻辑，各自对应的检查都会失败（4/3/1/2 项）。headless 与真实 GL 均通过；`enemy_ai_behavior`、`enemy_encounter_roles`、`enemy_lifecycle_regression`、`world_enemy_residency`、`combat` 及铸雨渠/盐白书库/无声王冠体验套件通过，`npm test`、`test:campaign` 通过。

本批不涉及新动画（蛰伏沿用待机姿态）、报警音效与实战难度；自然流程中伏击是否易读、报警是否让房间更难，留待 T04 实机验收。

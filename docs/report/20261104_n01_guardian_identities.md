## 旧回答与新发现

笔记要求正式布尔战胜标记和九条既有追问的真实记忆身份。追问仍沿用原有完整阅读、明确确认与成功保存事务。

已保存的基础回答可以作为来源；后来满足展开条件，并不自动把未听过的新话塞进旧回答。若基础与展开版本都已确认，优先回看已经听过的展开版，但仍只生成同一张辨认笔记。

追问记忆现在携带来源话题、确切已听行与版本层级，均从现有精确哈希恢复，不改变存档标记或原话。辨认笔记核对自己引用的原句是否确实出现在该版本中。物品之后不在手上，也不会抹去已经听过的人物回答。

“回看来源”可直接打开已确认的人物追问。通用来源解析按入口类型选择目录，只在人物来源确实需要时重建追问材料；普通证词和操作手册不会为此遍历全部人物回忆。

## 验证

- 六张辨认逐项检查战胜条件、每位说话者、每条必要回答、基础／展开版本、真假标记、已知副本隔离与 JSON 恢复。
- 遍历全部六十四种地区战胜组合、六十四种区域证言组合；缺战斗或缺原话均不能生成对应笔记。
- 数据门拒绝错配战斗、跨区说话者、未发表原句、借用未来展开、重复来源、进度副作用、空边界和错误版本。
- 正式 World 中以明确的证物／战后夹具接近真实断弦歌者，打开生产追问窗口。中途关闭、只显示最后一句、保存失败都不出现辨认；重新确认成功后保存并从实际 JSON 恢复。
- 读取辨认与已确认的展开原话后，核对货币、物品与存档字节保持一致。

夹具不替代自然六区通关、实体控制器和陌生玩家理解验收；T04 保持开放。

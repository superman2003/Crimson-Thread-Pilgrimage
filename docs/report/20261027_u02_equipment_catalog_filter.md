# U02 契印装备UI：四类装备检索与当前槽位筛选

本轮第13/40项，深化已有四类槽位的配置可读性与键鼠/手柄操作。

新增按已知名称/ID搜索和“仅可装入此槽”开关。四类装备各自记住查询与
筛选状态；兼容性读取当前所选真实槽位的解锁状态、家族与白名单。
不检索隐蔽剧情条件，不修改背包、解锁、冷却、货币或实际配置。
搜索或兼容筛选没有结果时清除旧装备详情，明确说明清除搜索或换槽方式。
行路配置保留原来的已配技能/战具循环，不开放背包重配入口。

键盘输入保持搜索焦点，回车只把焦点交给第一个可用结果，不能暗中装备。
手柄方向可在搜索、兼容开关与结果间移动；结果重建时更新焦点路径，
空结果清除旧路径。行高按原生字体/主题最小尺寸计算，给目录留出空间；
契印画面及非装备页保留旧列表位置。

合计512项通过。覆盖实际LineEdit键盘事件、手柄方向事件、生产UI绑定与
按钮列表、四家族记忆、锁槽/不兼容、空结果、焦点重建和资源不变。
完整npm test、campaign通过；严格runner错误传播与工作流自身路径检查通过。

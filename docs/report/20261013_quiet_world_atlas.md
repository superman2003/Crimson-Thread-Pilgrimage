# PR #28 地图视觉精简

原旅册同时绘制大量平台多边形边线、重叠房间边框、旧路斜线和长段说明，总览缩小后难以辨认。现用与场景接近的灰绿、暗金配色，浅墨描出连续房间外缘，消除重复的内部边线。世界总览省略平台细节；区域图使用物理房间坐标和真实地形填充。地图的公共底图、补绘详细几何与隐藏房间记录仍保留。

常驻文字只剩标题、区域名及一行图标/操作提示。房间名、补绘统计和门槛说明放在悬停信息里；旧路端点连线只在悬停相关房间时显示，实体钟管一直显示。门槛标记置于实际端点，避免漂浮在两区中间。

地图区域从1108×396扩大到1108×504。支持1–4倍缩放、滚轮锚点缩放、拖动、复位；内容裁剪在地图区域内，视图切换自动复位。字体仅在地图中使用MSDF以提高放大清晰度。

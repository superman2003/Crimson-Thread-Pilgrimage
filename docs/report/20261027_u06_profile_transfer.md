# U06 设置无障碍：设置方案分享导入与导出

既有六套命名方案已经支持四类设备改键、范围应用与独立确认。本项补齐原生分享窗口：导出选中的已存方案，导入先预览全部差异，再创建新命名方案。导入不立即应用、不覆盖同名方案，不包含音量或旅途存档。

分享格式版本化，最多64 KiB。逐字段校验开关、范围、动作集合、键鼠/手柄事件形状、冲突与保留按键；拒绝不完整或未来格式，不加载资源或对象。控制器浮点使用完整精度JSON，共享工作台存储同样保留精度，重载后的方案经过规范化后仍可应用。

原生窗口支持可聚焦的复制/粘贴按钮、滚动差异、手动文本编辑和两次确认。改名或改分享码必须重新预览。损坏存储、容量上限、写入失败保留已有方案及当前偏好；关闭设置或管理窗口后拒绝迟到回调。真实剪贴板仅在用户点击时访问，无剪贴板环境可手工操作。

# 实战陪练场

六区各一场两轮守路战与一场 Boss 复演，共十二个方案。只引用本章原始敌人配置与 AI；所需敌人必须已在旅途中击败，未达条件的场次与身份不展示。钟龛构筑页选择并确认后，复制当前构筑和已获能力进入独立场地。支持原有攻击、技能、战具、治疗，单敌清场后转为双敌，五分钟上限。

练习角色和构筑均为新实例；真实旅途暂停处理、隐藏画面并退出玩家/敌人战斗组，退出后按原状态恢复。陪练击败信号仅进入本场控制器，不连接掉落、图鉴、通关、交易或旅途存档。胜利、死亡、中途退出都只写独立复盘记录（最多二十条），不补充或消耗旅途资源。关闭幂等，场景异常退出也恢复原旅途，音频走既有退休路径。

验证：Godot 4.6.1 软件 OpenGL SPARRING_HALL checks=61 failures=0，含真实 AI 前摇/攻击、真实死亡推进轮次、胜败恢复、实际磁盘逐字节对照、原生命能量库存构筑与标记隔离、音频退休。实际画面检查通过。FIELD_CONTRACTS 33 项及回归运行器 32 项通过。

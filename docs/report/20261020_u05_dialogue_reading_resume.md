# U05：长字幕中断后的继续阅读

日期：2026-10-20。对应台账 U05“长文本、中断恢复”，独立基于 main 2571f891。

原来关闭对话或切换行囊后，同一段未提交对白会从第一个字重新显示，滚动条也回到顶部。现在按区域、人物、对白状态、句序与原文哈希记录已显示字数和滚动位置；重新打开同段时继续显示，字幕速度改变后按已显示比例换算新的计时，不重复播放开场拟声。

记忆只含数字，不持有人物或原文，最多 64 条，跟随本次界面/旅途生命周期，不改存档格式。不同人物、不同句序或改变后的文字不会误用旧进度。滚动在容器布局后恢复，并核对当前段落键，迟到的恢复不会挪动另一位说话者的窗口。

未读完时中断仍不提交人物/任务状态或奖励；只有原有真实存档事务成功后才移除已完成的阅读记忆。路线/心愿等不参与主线提交的题外回答也能保存自己的阅读位置；新旅途界面从空记忆开始。

默认 ui_redesign 加入 11 项真实 World/生产 UI 阅读检查及播放清理，合计 42 项。覆盖可滚动的长段落部分显示、切行囊后重开、速度变化、不同文本、真实提交、奖励不重复和历史上限；narrative_outcomes 等相关回归一并验证。最初夹具仅显示 80 字、不足形成滚动，改为确有滚动条的 800 字部分显示后，仍严格要求非零滚动位置完整恢复。

逐套结果与日志：artifacts/u05_dialogue_reading_resume/verification.json。本报告作为独立台账补记。关闭程序后未读进度不持久保存；不同字号下的阅读舒适度与实体手柄长文本操作仍待人工验收。

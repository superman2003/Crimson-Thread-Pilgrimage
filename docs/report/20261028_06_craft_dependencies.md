多件制作清单遇到尚未完成前阶时整单被拒，玩家需要自己逐项寻找前阶并分单。

新增前阶分批规划：遍历最多64个依赖、拒绝未知项和循环、共用前阶去重、跳过已完成改制；检查工匠归属，每个计划批次最多八件，同一未完成前阶与后阶分到不同事务批次。核对后只替换下一批清单，计划或构筑变化需重核。

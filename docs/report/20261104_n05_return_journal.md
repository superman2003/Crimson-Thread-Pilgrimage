# N05：结局之后的可选回访

日期：2026-11-04。接续十五段个人重逢，让已经答应的事与结局后的世界保持联系。

## 玩家看到的变化

旅记的“手册”分类新增“结局之后，还在等你的事”。必须已经选定结局，并至少知道一条委托才会出现。五条委托各有三种结局下的未完成／重逢语境，共三十段短说明。

| 记录状态 | 展示依据 | 下一步 |
|---|---|---|
| 约定还在继续 | 原委托已接、未完成 | 正式委托的首个未完成目标与当前去处 |
| 先核对原委托报酬 | 委托完成、原奖励未确认 | 找原奖励联系人核对一次性报酬 |
| 可回去确认近况 | 报酬已确认，但额外解锁／迁移未齐 | 主动交谈，不承诺新对白已经就绪 |
| 有新的重逢可听 | 正式人物解析器选中本结局的专属后续 | 到人物实际驻点自愿回访 |
| 这次重逢已确认 | 完整交谈已经保存个人后续标记 | 保留已确认状态，不承诺重复奖励 |

回访不影响已经选定的结局，未完成委托也不是新的主线门槛。简介提示本结局下值得再谈的原因，不引用尚未听过的个人后续对白。

## 数据与读取

- 结局沿用正式归一化：有效已选结局优先，唯一旧结局标记可以恢复；冲突旧标记保持无选择。
- 只接受真正布尔进度与正整数物品数量，拒绝字符串、布尔物品、负数、分数及非有限数。
- 标题、进度、当前目标与奖励来自原委托评估器；位置来自已保存的人物迁移。
- 囚徒回访到温室西门，逃旗手回访到巡礼营地；只有委托完成而没有迁移标记时仍采用原驻点。
- 不增加存档字段，不在读取时调用交谈或发奖。预留来源键仅包含已知的原委托记录。

## 验证

三结局 × 五关系逐项覆盖活动任务、待领奖励、确认、就绪、已听及必要前置缺失；遍历三结局下全部三十二种接受组合，检查只列出已接任务。覆盖损坏库存、真假进度、旧结局兼容、目录副本隔离和 JSON 恢复。

正式 World 回归在真实救援、保存结局、完整专属重逢之后打开生产旅记，核对新分类、迁移地点和已确认状态，比较前后旗标、背包、货币与存档字节。八种数据注入错误均必须被拒绝。

此验证使用既有事务夹具，不代替首次游玩的六区自然通关。文字可理解性与实机自然回访仍留在 T04 验收范围。

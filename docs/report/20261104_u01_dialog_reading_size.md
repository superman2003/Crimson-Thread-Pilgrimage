# U01／U05：所有页面对话框都跟随“阅读字号”

2026-11-04。设置里的阅读字号（字幕字号，17–26）原本只对两类窗口生效：

- 旅途工作台类窗口（JourneyDeskWindow）；
- 两个装了设置表单适配器的对话框（手柄校准、声音输出）。

在正式 World 中逐个打开四个页面（行囊、构筑、地图、设置）的全部对话框，分别在 17 号和 26 号下记录正文字号。结果有 10 个对话框在两个字号下完全一样，固定为 17–18 号：

- 资源用途核对、多件制作清单
- 地图说明、已知地点目录、钟龛回访、归途结
- 前瞻／观察、存档槽核对、浏览旧旅途、危险字幕辅助

“来源与许可”只有一行跟随字号。

## 改动

新节点 `DialogReadingAdapter`，挂在 UI 外壳下。它监听外壳内的所有 AcceptDialog，在对话框第一次弹出时按情况处理：

- 已有旅途或设置布局的：不处理，交给原布局；
- 内容列（不论是否在滚动容器里）：原地按阅读字号缩放（`journey_window_layout.apply_reading`，与旅途窗口同一比例）。滚动容器里的文字变大后在原有滚动区内滚动，不改动对话框自己的滚动区尺寸（集成时发现，改动滚动区会让手柄焦点桥刚滚到的行移出视野，见 `dialog_dpad_focus`）；
- 只有一段文字的提示框：缩放文字和按钮。

原地缩放之后：

- 如果对话框高过屏幕预算，就从本身可滚动的部件（列表、可滚动富文本、文本框）让出高度，最低保留 80px；每次重新缩放前先恢复原高度。
- 对话框打开后才加入的行（搜索结果、翻页）也会被监听，补上同样的缩放。
- 改阅读字号时，打开着的对话框立即重新缩放。

## 验证

`dialog_viewport_fit` 新增一项检查：每个页面对话框在 26 号下的正文字号必须大于 17 号下的。

- 这次共比较 21 个对话框，全部通过；
- 原有的“对话框和按钮行都在 1280×720 屏内”检查仍全部通过（共 132 项）；
- 去掉适配器后，同一套件有 10 个对话框失败。

另外跑了 46 个 UI 相关套件，43 个通过。没通过的 3 个都是本机环境问题，与本改动无关：`danger_captions`、`survey_map_knowledge` 在本机超时（不带本改动的基线上同样超时）；`tool_practice` 需要真实 GL 回读，headless 下跑不了。

## 边界

- 四个主页面本身（非弹出对话框）的固定排版不随阅读字号变化，这次没有改动。
- 小字说明保留原有层级（与旅途窗口相同的比例缩放），不会全部统一成同一字号。
- 观感与长文阅读仍需实机确认（U05）。

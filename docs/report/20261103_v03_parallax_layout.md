# V03：远景不再露出镜像拼接轴，中远景装饰不再按固定周期重复

接续台账 V03“背景远景镜像拼接与中远景装饰固定周期”（上一批 [V03 报告](20261101_v03_repetition.md) 在边界里留下的两项），起点为 main `f6fb25da`。所有 46 个任务包的最终验收仍开放。

## 改动前（实测）

`flat_map_art.gd` 的远景层（`PaintedBackdrop`，滚动系数 0.075×0.06）由一张原画和一张水平翻转的副本拼成 2 张宽的周期；两处接缝都是对称轴。中远景（`FlatMiddleDistance`，0.24×0.20）与近景边缘（`FlatNearEdges`，0.55×0.40）各是 4 个等距摆件，周期固定 2560×1440。

在正式 World 里逐区把镜头扫过整个可达范围（区域四周的镜头边界，13×7 或 21×11 个位置），从引擎的画布变换反算每一帧实际显示的图层坐标：

- 远景 16:9（1280×720）：苔钟庭、盐白书库、断弦温室在地区最右端能看到拼接轴（各 22/231 帧）；铸雨渠、黑曜巡礼道、无声王冠刚好没有。64:27 超宽屏（1706×720，“expand”拉伸下的宽屏视口）：六区 121–143/231 帧（52%–62%）都能看到。截图里就是右侧出现两口左右对称的钟、对称的柱子和银杏叶。
- 装饰层：一区在中远景层能看到的范围约 3500×1900（近景层约 5400×3000），远大于 2560×1440 的周期，同一排四个摆件会转回来；位置是等距的 `110 + j×610`，上下交替 25／925。

## 现在的做法

- **算出可见范围**：Godot 的 Parallax2D 按未缩放的屏幕偏移移动图层，视野左缘在图层里的坐标为 `scroll × (镜头中心 − 视口/2) + 视口/2 − 视野/2`（三种视口实测验证，误差 < 0.002px）。`parallax_window()` 用这个式子和 `main_level` 给镜头的区域边界（−40／−120 到 宽+80／高+70）、玩家镜头 1.25 倍缩放，算出某视口下镜头走遍全区时图层会显示的矩形；`parallax_reach()` 取 16:9、64:27、16:10、4:3 四种视口的并集。
- **远景**：把并集放进不翻转的那张原画中央，原画不够宽时等比放大（各区 1.08–1.18 倍，原先 1.02 倍；高度只会变大），竖直方向让 16:9 的范围居中。翻转副本保留，只给比 64:27 更宽的屏幕兜底，那时才会再次看到拼接。
- **装饰**：每 1280×720 一个摆件（与原先每 2560×1440 四个的密度相同），在格内随机位置、随机大小（240–320×350–460，与原先范围一致）、随机朝向和种类；左右、上下相邻格不用同一种。周期取整格并大于全区可见范围，所以正常游玩中不会看到同一布局第二次。随机数按“主题｜地区｜图层”播种，流式重建时布局完全相同。周期已大于任何视野，`repeat_times` 由 3 降为 1。
- **摆件硬切边**：装饰图集里有几格原画被格边切断（苔钟庭拱门的底边、温室银杏叶的右边，边缘不透明度达 0.4–0.6），原先在任何位置都会露出一条直线。所有摆件（含房间地标和环境摆件）加一个按自身图集格计算的 7% 边缘淡出；每个摆件种类一份材质，着色器在所有地区间共享，重建不重新编译。

## 验证

- 新默认套件 `parallax_layout`（正式 World、六区，686 项，本机无头 90 秒；按 CI 软件 GL 加 `--disable-render-loop` 88 秒，已加入不逐帧光栅化列表）：
  - 三种视口（1280×720、1706×720、1280×960）下逐帧对比引擎实际偏移与公式，最大误差 < 0.5px（实测 < 0.002px），每帧都落在 `parallax_window()` 内；
  - 远景每帧都在不翻转的原画内（0/91 帧露出拼接，三种视口六区）；原画只放大不缩小且不超过 1.25 倍；翻转副本紧接在原画右侧；
  - 两层装饰：周期覆盖全区可见范围、每格一个、摆件不出格、相邻格不同种、至少 4 种并且两种朝向都有、淡出范围正好是自身图集格；
  - 用同一份配置再建一次 FlatMapArt，三层的周期、位置、缩放、朝向、种类完全相同。
- 改动前对照用同一探针（见上节数字）；新套件依赖新增的布局函数，旧代码无法运行。
- 构建耗时：`FlatMapArt.configure()` 每区由 0.6–1.6ms 变为 1.6–3.2ms（节点 19–33 → 43–77），相对传送构建任务 24–109ms 的预算可忽略。
- 相关回归通过：`world_material`（2832）、`background_texture_contention`、`all_chapters_demo`、`cave_exploration`、`world_startup_budget`、`world_prepare_budget`、`world_config_background`、`texture_request_exit`、`world_host`（539）、`world_interaction_residency`（144）；运行器单测 34 项、`test_ci_shards` 通过。
- 真实 GL 像素探针：`STREAMING_PIXELS` 12、`PASSAGE_PIXELS` 5、`ROOM_RIM_PIXELS` 12、`WORLD_ATLAS_PIXELS` 5、`NEIGHBOR_GAMEPLAY_PIXELS` 6、`REGION_COMMIT_PIXELS` 10 均 `failures=0`（本机窗口被显示器限为 1213 宽，`PASSAGE_PIXELS` 因此打印越界读像素的引擎错误，与本改动无关，CI 的 Xvfb 为 1280 宽）。
- 真实 GL 截图（`artifacts/v03_parallax/`，上旧下新，镜头在地区最右端）：苔钟庭与断弦温室各一张只显示视差层的画面、一张正常画面。截图脚本为 `godot/scripts/capture_parallax_layout.gd`（软件 GL 下等待首区最长 180 秒）。

## 边界

远景原画放大 8%–18% 后的观感、随机散布的装饰与房间的协调性，需要 T04 实际游玩判断。比 64:27 更宽的屏幕仍会在地区两端看到拼接。远景竖直方向在 4:3 等高视口下仍会露出上下淡出带（未改，原先也是如此）。远景只有一张原画，地区内左右移动时远景内容变化很少，这是素材数量问题，本批没有处理。

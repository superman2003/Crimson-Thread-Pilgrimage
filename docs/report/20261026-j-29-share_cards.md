# 分享卡完整分页排版

## 玩家可见行为

把已经白名单与格式过滤的公开卡片完整换行和分页，提供同一行流的原生逐页预览及无需外部资源的连续分页SVG导出。

入口：设置 → 旅途工作台。在「旅途分享卡」预览页翻页核对，再选择「导出完整分页SVG」。默认未勾选的位置、任务、物资和备注均不会进入分页或文件。

## 数据及边界

- 使用当前功能已经收录的公开观察，不扩大未知内容的读取范围。
- 交互试算只改窗口副本；记录仍走原有分槽存储与严格校验。
- 保留原模块分析、原生记录库、导入导出边界及已有测试。
- 每页34行、参考72列；汉字按双列宽，保留显式换行及组合字符。总量超过4096行直接拒绝，不输出部分文档。SVG字体由查看器提供。

## 正确性验证

核对分页前后完整行流相等、中文宽度、换行、组合符号、页容量、标题/页码、XML完整性、标记转义、顺序稳定及未勾选隐私字段不可见。

新套件：`i_29_share_cards`。原套件：`i_20_share_cards`。

新套件还执行原生页面绘制、候选保存、磁盘读回、写入失败重试、撤销/重做、同槽导入及跨槽拒绝，并操作新增交互检查器确认主进度不变。

本地验证使用 Godot 4.6.1 headless 与隔离的域/原生控件夹具。它不代替实际 World 或软件 OpenGL 验收。

独立 Actions 工作流在真实项目的精确 PR 头执行资源导入、导出闭包审计、新套件、原工作台 World 与 i_live_world，分别使用 headless 和软件 OpenGL。原模块工作流及三分片整合 CI 保持启用。

## 分支协作

此 PR 以 #343 的当前头为共同基础，与本批其它功能分支互为兄弟分支。它只修改自己的功能模型和新增加强组件、套件、工作流及本说明；分享卡额外接入自身导出按钮。

10 个 PR 可独立审查，需先合入共同基础或按项目合并流程改挂基线。本次不合并任何 PR，不覆盖其它 agent 的分支。

独立分支文件组合本地结果：新套件 60 项检查、原套件 28 项检查，均为零失败。导出审计工具的19项单元测试及新增脚本引用/过滤检查通过。

# 铜蛾与钟蛾：战斗悬停不反复翻面

## 现象和改法

苔钟庭 E03 铜蛾与铸雨渠 E12 钟蛾共用短距离避让的战斗规则。玩家在避让阈值周围时，旧画面把每一次小退画成背对玩家的飞行，又立刻切回面对玩家的待机，玩家没有过身也会频繁翻面。仅在两种区域配置里启用近距离悬停表现：小退仍按原物理位移、保留原战术方向，但精灵面对威胁、与原地对峙共用原画的悬停循环。真正追近仍播放移动，攻击接管展示与朝向；不改攻击、速度、位移、敌人搜索、命中或其他飞行物种。不新增素材。

## 验证

Godot 4.6.1 云机使用实际 World 与原关卡敌人，以明确的起始定位夹具进场，再给同样的正常移动和跳跃输入。每个场景 460 个物理帧，无敌人位置写入、伤害屏蔽或自动击杀。它是两场同输入回放，不是全量试玩。

- 苔钟庭 E03：后移时背对玩家 34→0 帧，近距对峙/避让间翻面与切换动画各 1→0 次。三次完成攻击，玩家最后剩 3 生命。
- 铸雨渠 E12：后移时背对玩家 23→0 帧，近距对峙/避让间翻面与切换动画各 12→0 次。四次完成攻击，玩家最后剩 2 生命。
- 两组逐帧对比中，敌我位置、生命、战术方向与决策、攻击朝向、时钟和实际命中没有变化；攻击时使用的片段保持原样。
- 敌人 AI 63 项，旧实现 8 项失败、修后零失败；战术 303 项、动作衔接 82 项通过。后两项在已有王座前廊与冲锋边缘修复的本地组合中复验；此 PR 独立，不含那些改动。

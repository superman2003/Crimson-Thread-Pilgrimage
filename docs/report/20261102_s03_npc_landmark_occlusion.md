# S03：NPC 声音地标随遮挡切换音色

基线为 main `8f3048c0c4d8b9456b488173c8ae4700c8f0ec29`。本批对应修订方案 S03 的距离、遮挡与声音地标；所有最终游戏验收保持 OPEN。

NPC 的探索提示音此前使用普通空间播放器，隔墙只降低 12dB，音色没有变化。现在由 `npc_sound_landmark.gd` 继承原空间查询，受遮挡时经过独立的 `CrimsonLandmarkOccluded` 低通总线（2400Hz、0dB 增益），再送回 `SFXWorld → SFX`。走到墙外时恢复原总线与原始音量，再次遮挡也不累计衰减，不重启流或播放实例。

滤波总线共享创建／复用／所有权检查逻辑，但 NPC 与普通敌人的总线、效果资源和所有权标记独立。缺少父总线时回落到 SFX／Master，父总线恢复或重排时按名称修复混音顺序；同名外部总线不被接管。危险前摇、敌人警觉、死亡确认仍使用原路由。没有新增空间射线、声部名额或调度器，沿用原地标刷新预算、距离、限频和危险时让路规则。

## 初轮诊断与边界

初轮地标测试为比较“同一个播放实例”持有了强引用，导致夹具自己的退役检查超时 1 项。比较结束后清空该引用和流引用，最终无头与原生检查均零 ERROR／warning；初轮日志保留在 `artifacts/landmark_occlusion/initial/`。本地控制脚本最初未规范化 Windows 原始 CRLF，误判完成标记缺失；修正换行解析后，四组控制结果均符合预期，旧摘要也保留。

本批是受控物理墙、实际效果器和实际 NPC 播放方法的组件／集成验收。没有进行耳机／扬声器实听、自然六区游玩或整合长跑；环境床、Boss 场地持续音的遮挡和 S03 整体听感仍 OPEN。完整新 PR 头的远端 CI 以 GitHub 当前记录为准。

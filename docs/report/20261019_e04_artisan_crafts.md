# 工匠改制：战具扩容与行旅承力扣（E04，含 B04 奖励用途）

修订方案 E04 要求“以旧设施零件、职业技艺和 NPC 修复分支解锁工具／槽位；材料有明确来源，预览成本，失败消费无状态改动”。C04 批次只完成了一半（地区材料用于线术校习），台账写明“工匠解锁工具或槽位”仍由人物修复链提供。B04 的九件挑战证据也只是遗物，台账写明“与工具／成长挂钩的独有奖励（待 E04 重做）”。

## 之前的状态

- 战具携带上限只有目录写死的数字（3／2／2／2），加上针匣铭饰对投罐和绊线钉的 +1。玩家没有办法让某件战具多带一份。
- 三枚契印的扩展槽全部由“专属机制修复”一次打开。司铸和校录的机制标记与契印本身同时取得，所以它们的第三个行旅铭饰槽从拿到契印那一刻就是开的，所谓“稀有解槽”实际上不存在。
- 九件挑战证据（冠隙余响、配重余响等）只出现在旅记里，没有任何用途。
- 第五区的黑曜碎片、第六区的冠响碎片没有任何消费途径。

## 改动

### 四件战具改制：携带上限 +1

| 改制 | 制作者 | 图样（不收走） | 费用 |
|---|---|---|---|
| 铜铃投罐·双层罐腔 | 织线学徒（苔钟庭） | 证据·冠隙余响（冠隙试炼） | 60 碎钱＋3 苔壳 |
| 绊线钉·配重卷簧 | 雨铸匠（铸雨渠） | 证据·配重余响（配重试炼） | 80 碎钱＋3 湿锈甲片 |
| 盐雾瓶·蜡封瓶口 | 蜂蜡商人（断弦温室） | 证据·封蜡账册（封蜡库余响） | 90 碎钱＋3 盐晶碎片 |
| 回响诱铃·根网铃舌 | 雨铸匠（铸雨渠） | 证据·根网爪痕（根网追踪） | 90 碎钱＋3 花粉蜂蜡 |

- 图样是挑战首清得到的证据，只给工匠看，不会被收走，旅记里的证据链不受影响。
- 材料就是这件战具的补给材料，所以改制和补给争用同一份材料。
- 每件只做一次。改制后的新容量是空的，多出的那一份在钟龛按原价补给，不送次数。
- 绊线钉多带一枚，但场上仍最多两枚。
- 制作者按手艺分工：铃要铸，所以诱铃找雨铸匠；瓶口封蜡找蜂蜡商人。找错人会被告知该找谁。
- 回响诱铃的图样和材料都来自断弦温室，制作却在铸雨渠，需要回访。

### 行旅承力扣：第三个行旅铭饰槽

- 三枚契印的第三个行旅铭饰槽，现在要同时满足：该契印的专属机制已修复，以及已制作行旅承力扣。
- 承力扣由雨铸匠制作：图样是证据·军墓灯影（黑曜巡礼道军墓试炼），费用 120 碎钱＋3 黑曜碎片（第五区材料第一次有用途）。
- 雨铸匠要先修好无名工人的铜徽章（即取得司铸契印的人物委托）才会做。这是方案说的“NPC 修复分支解锁”。没修好时，工匠页写明原因。
- 一次制作，三枚契印共用。

### 工匠页（U02）

- 工匠旁的强化页同时列出校习方向和改制；标题改为“此处校习技能、改制战具”。站在哪位工匠旁，就先列出这位工匠自己能做的改制（原来十二个校习方向排在前面，改制要往下翻才看得到）。
- 列表：已做的标“已制作”；别的工匠的改制标出制作者；缺图样时标“缺图样”。
- 详情在花钱前列出：携带上限“当前 → 改制后”、图样是否已取得及取得地点、雨铸匠的修复条件、制作者、碎钱与材料的需要量和持有量。
- 钟龛构筑页里，未解锁的第三行旅槽会写明需要哪位工匠制作哪件承力扣。

### 交易规则

- 拒绝的顺序：不在工匠旁 → 找错工匠 → 修复条件 → 缺图样 → 碎钱或材料不足。每一种拒绝都不改构筑和钱包。
- 购买沿用既有事务：存档写入失败时，碎钱、材料、构筑全部回滚，生命和绯线不受影响。

### 存档

- 构筑存档新增 `crafted`（已制作的配方 id 列表）。读取时逐项检查：只能是改制或承力扣、不能重复；未知 id 整份拒绝，不部分应用。
- 战具次数的上限检查把已做的改制计入；没有改制的存档带着超额次数会被拒绝。
- 旧存档（没有 `crafted`）：只要修复过任何一枚契印的机制，就补给承力扣。所以旧存档里已经开着的第三行旅槽仍然开着，槽里的铭饰仍然生效；新增的“该契印的机制”条件保证原来没开的槽也不会因此打开。旧存档不会获得任何战具改制。

### 顺带修复：换到没有可用战具的契印后，存档读不回来

写测试时发现：开局只带铜铃投罐，修好司铸后在钟龛换到司铸，司铸的第一个战具槽不收投罐，投罐休眠，第二个槽空着。此时构筑把活动槽退回到 0，游戏照常保存；但读档校验要求活动槽必须有可用的战具，于是**下次启动时整份构筑被拒绝，自动保存暂停**。同一原因也让这种状态下的交易回滚失败（回滚调用同一个读档校验，结果被忽略）。

现在读档校验接受与运行时相同的退回规则：只有当这一类确实没有任何可用条目时，活动槽才可以是 0。`artisan_crafts` 新增两项检查覆盖这个场景（能保存、能读回）；去掉修复后，读回检查和另外五项依赖读档或回滚的检查共 6 项失败。

## 经济

`audit_economy.py` 把改制与承力扣计入一次性消费，并新增四条规则：每件改制的图样必须是某处可选挑战的奖励；材料必须在某个地区掉落；战具改制只用这件战具自己的补给材料；承力扣对每枚契印恰好开一个原本就要求机制的槽。另有一条：拥有全部扩容时，一次补满不超过三只普通敌人的碎钱（原规则“不超过两只”仍按不含改制的容量检查）。

| | 改动前 | 改动后 |
|---|---|---|
| 一次性收入 | 2840 | 2840 |
| 一次性消费 | 1010 | 1450（新增改制 440） |
| 消费占比 | 35.6% | 51.1% |
| 收入／消费 | 2.8 倍 | 1.96 倍（下限 1.5） |

改制全部可选；即使全做，收入仍接近消费的两倍，不需要刷钱。

## 验证

- 新增 `artisan_crafts` 套件（正式 World，46 项、0 失败，默认 CI）：
  - 三枚契印的第三行旅槽都要求机制＋承力扣；只有机制时装不上罗盘，槽位条目指向承力扣配方。
  - 司铸下投罐休眠时存档能保存，且能读回。
  - 不在工匠旁、找错工匠（雨铸匠指向织线学徒）、缺配重余响时，购买被拒绝，构筑和钱包不变。
  - 存档写入失败：容量、碎钱、材料回滚，生命和绯线不变。

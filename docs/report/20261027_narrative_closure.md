# 世界观、人物线与结局回收升级

基线：`main a559a1b8`，包含 #397–#403。独立分支 `codex/narrative-world-closure`。

## 玩家可见的变化

- 新旅途先说明当下目标，不在开头直接讲完“自愿被改成世袭”的真相。旅记随实际取得的证词逐步出现九段故事梳理，包含单证、双证互证、支线回收与六证总结；不改变证词、能力或结局条件。
- 五条已交付人物线各增加一次短重逢：学徒、囚徒、商人、修女、逃旗手谈到完成委托后怎样改变自己的生活；主角以交还线端、留出退路等短动作的文字回应。原有奖励成功提交才出现，完整读完才记录，不额外发钱、物品或能力，结局后的原有回应保留优先级。
- 结局门先展示行动、收益与代价，玩家再次明确确认才提交。取消返回探索，条件变化重新核对，保存失败完整回滚并保留重试。旧存档与再次交互可回看选定结局。
- 三种结局有可自行推进的文字尾声，支线人物片段仅在对应任务与奖励已提交时出现；旅记保留尾声正文。尾声说明代价仍需承担，避免将改写表现为无代价的大团圆。
- 统一钟哑六十五年的年代、总校书素与螳将、歌守徽与铜根主教的身份，以及改写结局的实际条件；旧创作稿明确标记未交付的任务/分镜方案。见 [当前定稿](../NARRATIVE_CANON.md)。

## 按项目方反馈撤销的内容

试做的 Boss 战后动态分镜已整体删除，包括数据、绘制播放器、自动触发、重播按钮、捕获脚本及预览文件；未提交或保留占位动画。Boss 战后沿用原有奖励与通路反馈，正式视频资源由项目方制作后另行接入。本批文字尾声属于结局阅读界面，不是视频资源交付。

# S03 环境混音：房型混响基准与跨区交接

2026-10-27，基于 main `fdf43b5d7c112199b12fdcdbb6ee018f55ab8103`。推进 S03 的房型混响与生命周期子项，S03 整包保持 OPEN。

同一 AudioDirector 重复 set_chapter 会把当前房型调整后的 wet 再读成基准；旧导演的淡化与退出也缺少共享效果器所有权。初始四项复现检查在旧代码全部失败。Main 原本会按地区设置新的混响参数，所以不能将该复现说成普通跨区必然累积；交接还需明确区分地区原始参数与房型临时偏移，并取消旧淡化。

## 实现

新增 room_reverb_mix.gd。每个实际 AudioEffectReverb 保存当前所有者、未被房型修改的基准和淡化的弱引用。重复捕获不累加偏移；接手时取消旧淡化，从当前 wet 继续原有 0.6 秒过渡。旧区域的迟到通知不能抢回所有权，旧区域退出不能还原新区域的效果；最后持有者退出恢复原始 wet 并清理元数据。

Main 的实际 _apply_chapter_reverb 通过 set_baseline 安装地区参数，同时结束旧房型租约。六区原有 room_size、damping、predelay 等参数仍由原方法设置。更换或移除效果器会释放旧目标；总线元数据只有弱引用，不持有场景。房型偏移、淡化时长、音量、静音、播放、危险声优先级和用户文件规则保持原样。

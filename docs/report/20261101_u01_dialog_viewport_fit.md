# U01／U06：对话框都在一屏之内，“浏览旧旅途”不再高出屏幕一倍

接续台账 U01“所有页面字体颜色间距统一”与 U06 不同字号的要求。起点为 main。所有 46 个任务包的最终验收仍开放。

## 怎么发现的

在真实 World 里把阅读字号分别设为最小 17 和最大 26，依次打开行囊、构筑、地图、设置四个页面的按钮所弹出的全部对话框（每种字号 21 个），检查每个窗口是否完整落在 1280×720 逻辑屏幕内，按钮行是否在窗口内。项目拉伸方式为 `canvas_items` 加 `expand`，任何窗口比例下可见高度都不少于 720。

## 问题与修复

- 设置页的“浏览旧旅途”第一次打开时窗口是 900×1414，高度约两屏，底部的“返回设置”和下半部分内容都在屏幕外，与字号无关。第二次打开时排版已经稳定，所以平时不容易察觉。原因是顶部那段自动换行的说明 Label 没有设宽度：容器第一次排版时它按每行一个字计算最小高度，把整个对话框撑高。给它指定 840px 宽度后，窗口回到 900×620。
- 其余 20 个对话框在两种字号下都在屏幕内，按钮也都在窗口内。

## 验证

- 新默认套件 `dialog_viewport_fit`（正式 World）110 项、42 次对话框打开（两种字号各 21 个），确认逻辑屏幕为 1280×720，每个窗口完整在屏内，按钮行在窗口内。
- 反向：用 main 的 `journey_history_browser.gd`，“浏览旧旅途”在 17 号字下越界（900×1414），1 项失败。
- `ui_redesign`、`save_product`、`ui_world_integration`、`run_journey_comparison_contract.py`（41 项）通过。

## 边界

只覆盖新存档里页面按钮直接打开的对话框；对话框内再弹出的确认框、需要特定进度才出现的窗口没有逐个打开。只检查窗口和按钮的几何位置，文字是否截断、是否需要滚动没有逐项判断。

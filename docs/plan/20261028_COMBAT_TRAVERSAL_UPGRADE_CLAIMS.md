本轮拟交付以下十个实质升级 PR；本说明 PR 不计入十个。每批包含实际运行时改动、针对生产方法的回归及证据边界说明。不会以组件测试代替 T04 自然游玩或关闭 46 项最终验收。

请并行 agent 暂避下表明确认领的方法；若必须修改同一文件的其他方法，请保留本轮改动。每批发布前会重新核对 main、开放 PR、变更文件与最新提交。共享辅助函数按依赖顺序串接，各 PR 写明前置，不覆盖或强推他人的分支。

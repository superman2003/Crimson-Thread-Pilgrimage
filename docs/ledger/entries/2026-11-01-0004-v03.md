## 2026-11-01：同材质平台不再一模一样，岩体去掉镜像万花筒（V03 子项）

普通岩台原本全部落到同一切片、同一朝向，关卡数据里作者写的整块 `flip_h` 也没有生效；大块岩体的两格镜像平铺在折叠轴交叉处出现四向对称花纹。现在每个地区按图集手工挑出一组可互换的岩台切片，按平台 id 选择切片和朝向（作者朝向优先，重建后外观不变，仍然一块平台只用一种切片；桥与首领地面不翻转）；岩体改为两层错位镜像按低频噪声混合，再加连续扭曲，不引入新接缝。洞穴边缘、通道壁柱与岩体共用逐字相同的采样代码。`world_material` 2825→2832 项，用旧选择逻辑的反向检查 492 项失败；GPU 岩体探针 12→20 项，真实墨岩折叠交叉处的镜像差异从 0 升到 0.057；其余五组 GPU 像素探针通过，真实 GL 前后对比图已存。各房间切片是否协调、低端显卡的帧时间待 T04。见[报告](report/20261101_v03_repetition.md)。

## 2026-11-07：任何能到的房间都能回到钟龛（W04）

- **审计**：新增 `tools/audit_stranding.py`，已接进 `npm run test:campaign`。它复用 `audit_shortcut_bypass` 的全世界房间图（区域连接、单向落差、能力门、拉杆捷径、世界传送口、工房奖励）。
  - **模型**：只持有能力组合 T 的玩家，所走的路线不能经过 T 以外能力的拾取房间，否则他已经捡起了那个能力。
  - **检查**：对每种能按某个顺序取得的 T（共 100 种），以及这样能到达的每个房间，要求从该房间出发（沿途可以捡起找到的能力）能回到某个钟龛。
  - 自检覆盖：单向坑底出口要靠未取得的能力时判为被困；出口能力就在坑里时不算被困；拾取房间挡在坑前时不算被困；坑里有拉杆能打开出路时不算被困。
- **发现并修正**：图里苔钟庭的钟髓密室（`bell_marrow_cell`）只有一条入口，就是从半钟平台用棘线下劈击穿地板，没有出口。所以即使八种能力全有，进去也出不来（96 种组合被判被困）。用正式关卡物理实测：
  - 不带任何能力，从坑底按左加跳就能走回钟楼攀道（`bell_ascent`）；
  - 在下劈地板完好时，从钟楼攀道的台阶向右也能直接走进密室。
  
  两个房间的范围本来就有重叠，图里漏了这条连接。已在 `demo_ch01_moss_bell_court.json` 补上 `bell_ascent ↔ bell_marrow_cell` 双向通路，之后审计结果为 0 处被困。`validate_world_routes`、`audit_shortcut_bypass`（256 种组合 0 次绕门）、章节校验照常通过。
- **排除的疑点**：黑曜巡礼道的缆降索道（`cable_descent` 往下到 `silent_gate`）是单向的：每层平台落差约 295px，而跳跃加二段跳理论上最高约 250px，确实爬不回去；`silent_gate` 唯一出口要灯影相位。不过所有通往索道的路都要经过灯影相位的拾取房间 `pilgrim_camp`，还要先通过本区守门者的门，所以不会出现“没有灯影相位就下了索道”的情况。
- **待定（交给设计）**：钟髓密室的侧面开口让“下劈击穿地板”不再是进入密室的唯一方式，这道能力门形同捷径。要么接受它只是从上方下来的捷径，要么封住侧面；但封住侧面就必须另开出口，否则坑底会真的变成死路。

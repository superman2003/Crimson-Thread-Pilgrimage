## 2026-11-15：W00 共享洞口与邻区驻留的分阶段方案

只写方案，不改代码。见 [`docs/W00_SEAMLESS_RESIDENCY_PLAN.md`](../../W00_SEAMLESS_RESIDENCY_PLAN.md)。

- **现状**：宿主本身代表“当前区”，144 个变量里除 22 个会话字段外，每次换区都会重置。区域节点直接挂在宿主下，使用本地坐标。过通道时冻结源区，走到终点再整区加载。
- **建议的做法**：
  - 当前区保持在本地原点，邻区按原点差平移后放置，越过交接线时整体平移一次原点。
  - 区域变量逐组搬进 `RegionState`。
  - 邻区只驻留开口附近的只读外壳（碰撞、平台、画面）。
  - 目的区在玩家走管道时构建进一个停用的第二容器，到管道中点再交接。
- **八个阶段**：盘点与量尺 → 区域容器 → 区域状态对象 → 邻区外壳 → 边走边构建 → 交接与原点平移（在排水钟管试点）→ 推广到其余四条通道 → 收尾与 Windows 真机长跑。每阶段一个 PR；前五个阶段都保留整区加载作为回退。
